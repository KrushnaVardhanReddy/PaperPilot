CONTEXT & USER PROBLEM
--------------------------------------------------------------------------------
In the PaperPilot Desktop viewer, the bottom floating action pill features a "Sign / Annotate" (✍) button (`apps/desktop/src/routes/+page.svelte:477`).
Currently, clicking this button merely toggles an internal state `activeTool = 'sign'`, but fails to prompt the user to type their name/initials, draw a signature, or click on the page to place it.

Users require an authentic DocuSign / macOS Preview signature experience:
1. Clicking ✍ opens a Signature Modal allowing them to:
   - Type their name/initials in stylized cursive script fonts.
   - Draw their signature on a canvas pad with a stylus/mouse.
   - Upload a signature image.
2. Clicking "Adopt & Sign" arms the signature.
3. Clicking anywhere on the PDF page places the signature at that exact position.
4. The user can drag, resize, and delete the placed signature.
5. An "Apply Signature" button bakes the signature into the document using `pdf_stamp`.
