## 2. Technical Context & Requirements
Location: `paperpilot-pdf/tests/malformed_regression.rs`
Dependencies to use:
- `paperpilot_core::traits::{PdfDocument, PdfOperation}`
- `paperpilot_core::error::PdfError`
- `paperpilot_pdf::document::LopdfDocument`
- Core operations: `paperpilot_pdf::operations::{extract_text, split, page_count, delete, compress, merge, pdf_posterize}`

### Attack Scenarios to Cover:
1. **Truncated / Random Corrupt Byte Streams**:
   - Empty byte slice `b""`.
   - Partial magic headers: `b"%PDF"`, `b"%PDF-1.7\n"`.
   - Random non-printable binary garbage, high-byte sequences (`0xFF, 0xFE, 0x00`).
   - Missing `startxref` or broken `%%EOF` markers.
   - Assert `LopdfDocument::from_bytes` or operations reject without panicking.

2. **Circular Reference & Infinite Tree Loops**:
   - Synthetic PDF where a `/Pages` node references itself as both `/Parent` and `/Kids` (`/Kids [2 0 R] /Parent 2 0 R`).
   - Synthetic circular indirect reference chains (`1 0 R -> 2 0 R -> 1 0 R`).
   - Execute tree-traversing operations like `PageCountOperation`, `SplitOperation`, and `ExtractTextOperation`.
   - Assert the operations terminate cleanly and do NOT hang in an infinite loop or cause stack overflow.

3. **Stream Length Bombs & Memory Exhaustion Guards**:
   - Synthetic PDF declaring `/Length 1073741824` (1 GiB) or `2147483647` but providing only a few bytes in the stream body.
   - Assert the parser bounds allocations or fails with `Err`, never attempting unbounded memory allocation (OOM panic).

4. **Deeply Nested Structures**:
   - Deeply nested dictionaries/arrays (100+ nested levels: `<< /Nested << /Nested ... >> >>`).
   - Verify parser handles deep recursion with error/depth limits rather than crashing.

5. **Corrupted Cross-Reference (XRef) Tables**:
   - Invalid xref entry types, out-of-bounds byte offsets, negative object numbers, overlapping object IDs.
   - Assert parser returns `Err(PdfError::ParseError)` gracefully.

6. **Operations Stress on Malformed Documents**:
   - When a malformed document is loaded (or partially loaded), verify executing multiple operations (`ExtractTextOperation`, `SplitOperation`, `DeletePagesOperation`, `PageCountOperation`) handles invalid page indices and broken streams with standard `PdfError::InvalidInput` or `PdfError::ParseError`.
