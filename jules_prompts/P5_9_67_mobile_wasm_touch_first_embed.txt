## 🏛️ ARCHITECTURE & GOAL
Mobile users perform **emergency on-the-go micro-tasks** (e.g. camera-scan a receipt to PDF, emergency contract signature, merge two documents, rotate an upside-down page, strip blank pages, compress for email).
Heavy enterprise batch pipelines and native mobile cross-compilation with Android scoped storage (`content://`) are error-prone and unnecessary.

**Objective**:
1. Route mobile operations directly to the pure in-memory `paperpilot-wasm` engine (`WasmPdfEngine`), operating 100% locally in-memory on `Uint8Array` buffers with zero network overhead.
2. Adapt the **PaperPilot Embed / Mobile Touch Widget** (`apps/embed/src/Widget.svelte` and `apps/desktop/src/lib/components/layout/OperationsPanel.svelte`) into a responsive, touch-first mobile interface:
   - Touch targets satisfying ≥48px minimums.
   - Smooth bottom-sheet parameter drawer with tactile drag pill for mobile screens (`max-width: 480px`).
   - Emergency tool filter chip bar: **Scan to PDF**, **Sign**, **Merge**, **Rotate**, **Clean / Remove Blank**, **Compress**, **Sanitize**.
   - **Camera Scanner with Document Edge Crop (ImageCropModal)**: Preserve and integrate the existing `CameraScannerModal.svelte` and `ImageCropModal.svelte` (Kaagaz-style arbitrary quad / multi-corner pin polygon drag crop). Do NOT replace it with a plain generic file input.
   - Built-in HTML5 camera stream intake with live video canvas, touch corner handles, and native mobile `navigator.share({ files: [...] })` with standard fallback.

### 2. Mobile-First Touch UI in `apps/embed/src/Widget.svelte`
- Wrap parameters in a responsive bottom drawer for mobile viewports (`@media (max-width: 640px)`):
  - Fixed bottom positioning with `border-top-left-radius: 16px; border-top-right-radius: 16px;`.
  - Tactile drag handle pill (`width: 36px; height: 4px; background: rgba(255,255,255,0.25); border-radius: 2px; margin: 8px auto;`).
  - Safe-area bottom padding (`padding-bottom: env(safe-area-inset-bottom, 16px);`).
- Ensure all buttons, tool pills, and inputs have `min-height: 48px; min-width: 48px;`.
- Implement `Share Result` button using `navigator.share`:
  ```ts
  async function shareOutput(file: File) {
    if (navigator.share && navigator.canShare && navigator.canShare({ files: [file] })) {
      try {
        await navigator.share({
          files: [file],
          title: file.name,
          text: 'Processed securely with PaperPilot'
        });
        return;
      } catch (err) {
        if ((err as Error).name !== 'AbortError') {
          console.warn('Native share failed, falling back to download:', err);
        } else {
          return;
        }
      }
    }
    // Fallback: standard anchor download
    triggerDownload(file);
  }
  ```
