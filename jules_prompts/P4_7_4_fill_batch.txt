# Jules Task — Implement `paperpilot fill-batch` (Batch AcroForm Mail Merge)

## Branch
`feat/cli-fill-batch-task-4-7-4` (already created, based on `feature/dev`)

## Goal
Add a new `fill-batch` subcommand to the `paperpilot-cli` crate that performs
CSV/JSON-driven mail merge on AcroForm PDF templates. One output PDF is produced
per data row, named according to a configurable token pattern.

---

## Context: Existing Infrastructure to Reuse

These already exist — **do not re-implement them**:

1. **`paperpilot_pdf::operations::form::FillFormOperation`**
   - File: `paperpilot-pdf/src/operations/form.rs`
   - Takes `HashMap<String, String>` of AcroForm field values, fills them into a
     `LopdfDocument`.

2. **`paperpilot_pdf::operations::flatten::FlattenOperation`**
   - File: `paperpilot-pdf/src/operations/flatten.rs`
   - Removes interactivity from all AcroForm fields (flattens to static content).

3. **Existing single-fill handler**
   - File: `paperpilot-cli/src/commands/group_e.rs` → `handle_form_fill()`
   - Use the same pattern (load template → execute op → save) per row.

4. **`LopdfDocument::load(path)` / `doc.save(path)`**
   - Load a fresh copy of the template for each row to avoid state bleed.

Add a new variant to the `Commands` enum (in the top-level `#[derive(Subcommand)]` enum):

```rust
/// Fill AcroForm fields in batch from CSV or JSON data
FillBatch {
    /// AcroForm template PDF path
    #[arg(long)]
    template: PathBuf,

    /// Data file path (.csv or .json)
    #[arg(long)]
    data: PathBuf,

    /// Output directory for generated PDFs
    #[arg(long)]
    output_dir: PathBuf,

    /// Filename token pattern (supports {_index}, {_row}, {_date}, {_time}, {<column>})
    #[arg(long, default_value = "{_index}.pdf")]
    name_pattern: String,

    /// Flatten (make non-interactive) each filled PDF
    #[arg(long)]
    flatten: bool,

    /// Abort the entire batch on first error (default: skip and warn)
    #[arg(long)]
    fail_fast: bool,

    /// Print resolved output paths without writing any files
    #[arg(long)]
    dry_run: bool,
},
```

### 2. `paperpilot-cli/src/commands/group_e.rs`

Add two items:

**A) Private token resolver:**

```rust
fn resolve_pattern(pattern: &str, row: &HashMap<String, String>, index: usize) -> String {
    let now = chrono::Local::now();
    let date = now.format("%Y%m%d").to_string();
    let time = now.format("%H%M%S").to_string();
    let mut result = pattern.to_string();
    result = result.replace("{_index}", &format!("{:04}", index));
    result = result.replace("{_row}",   &(index + 1).to_string());
    result = result.replace("{_date}",  &date);
    result = result.replace("{_time}",  &time);
    for (k, v) in row {
        result = result.replace(&format!("{{{}}}", k), v);
    }
    result
}
```
