Requirements:
1. Core Implementation (`paperpilot-pdf/src/operations/pdf_to_epub.rs`):
   - Update `PdfToEpubOptions` struct:
     ```rust
     #[derive(Debug, Clone, Serialize, Deserialize, Default)]
     pub struct PdfToEpubOptions {
         pub title: Option<String>,
         pub author: Option<String>,
         pub language: Option<String>,
     }
     ```
   - In `pub fn pdf_to_epub_bytes(input_bytes: &[u8], options: &PdfToEpubOptions) -> Result<Vec<u8>, PdfError>`:
     - Load document using `lopdf::Document::load_mem(input_bytes)`. Return `PdfError::InvalidPdf` or appropriate error if corrupted.
     - Extract text from each page. Unwrap lines and soft hyphens (`-\n`) into continuous paragraphs `<p>`.
     - Chapter detection:
       - Check if `/Outlines` dictionary exists in the PDF catalog. If so, traverse bookmarks to detect chapter breaks.
       - If no outlines, partition into chapters based on major font size headings or group pages into logical chapters.
     - Build compliant EPUB 3.0 OCF archive in-memory using `zip::ZipWriter::new(std::io::Cursor::new(Vec::new()))`:
       - `mimetype`: MUST be the first file entry in the ZIP archive, MUST be stored uncompressed with `zip::CompressionMethod::Stored`, containing exact bytes `application/epub+zip` (no newline).
       - `META-INF/container.xml`: Points to `OEBPS/content.opf`.
       - `OEBPS/content.opf`: Package file with `<metadata>` (title fallback to "Untitled Document", author, language "en", unique-identifier), `<manifest>` listing all items, and `<spine>` listing reading order.
       - `OEBPS/toc.xhtml`: EPUB 3 navigation document with `<nav epub:type="toc">`.
       - `OEBPS/toc.ncx`: EPUB 2 NCX file for backward compatibility.
       - `OEBPS/styles.css`: Clean, readable CSS typography.
       - `OEBPS/chapter_*.xhtml`: Valid XHTML5 documents with `<?xml version="1.0" encoding="utf-8"?>`.
     - Return the finished bytes `Vec<u8>` on success.
