Context:
PaperPilot is an air-gapped, zero-cloud PDF & document intelligence suite written in Rust with Svelte/Vite web and Tauri desktop interfaces.
Users reading technical PDFs on e-readers (Kindle, Kobo) or mobile phones need reflowable EPUB 3.0 eBooks.

Requirements:
1. Core Operation (`paperpilot-pdf/src/operations/pdf_to_epub.rs`):
   - Define `PdfToEpubConfig`:
     - `pub title: Option<String>`
     - `pub author: Option<String>`
     - `pub language: Option<String>` (defaults to "en")
   - Text & Paragraph Extraction:
     - Read PDF via `lopdf::Document::load_mem(input_bytes)`.
     - Extract text from pages, unwrap broken lines and soft hyphens (`-\n`), and group into paragraphs `<p>`.
   - Chapter Segmentation:
     - Check document outline bookmarks (`/Outlines`). If bookmarks exist, partition pages into named chapters.
     - Fallback: Split by major font size changes or page boundaries if no outline is present.
   - EPUB 3.0 OCF Packaging using the Rust `zip` crate:
     - `mimetype` file MUST be the first entry in the ZIP archive and MUST be stored UNCOMPRESSED (`zip::CompressionMethod::Stored`) with content `application/epub+zip`.
     - `META-INF/container.xml` pointing to `OEBPS/content.opf`.
     - `OEBPS/content.opf` with `<metadata>`, `<manifest>`, and `<spine>` listing all XHTML documents in reading order.
     - `OEBPS/toc.xhtml` (EPUB 3 Navigation Document with `epub:type="toc"`).
     - `OEBPS/toc.ncx` (EPUB 2 NCX table of contents for backward compatibility).
     - `OEBPS/styles.css` containing clean typography styles for e-readers.
     - `OEBPS/chapter_*.xhtml` containing valid XHTML5 markup (`<?xml version="1.0" encoding="utf-8"?>`).
   - Implement function:
     `pub fn run_pdf_to_epub_bytes(input_bytes: &[u8], config: &PdfToEpubConfig) -> Result<Vec<u8>, OperationError>`
   - Export module in `paperpilot-pdf/src/operations/mod.rs`.

   - MCP (`paperpilot-mcp/src/server.rs`):
     - Register `pdf_to_epub` tool with parameters `input_path`, `output_path`, `title`, `author`.
   - REST Gateway (`paperpilot-gateway/src/handlers.rs`):
