[Task 4.7.8 / Spec 142: Desktop Real Watched Folders Daemon & Document Smart Filter Tabs]

Objective:
Implement Spec 142 (`specs/142-desktop-watched-folders-and-smart-filters/spec.md`) and Task 4.7.8 across `apps/desktop/src-tauri` and `apps/desktop/src`.
Connect the backend hot folder watcher daemon (`paperpilot_pdf::operations::watch`) to the Desktop Tauri GUI and replace the previously mocked categories with real, reactive document filter pills in `DocumentList.svelte`.

Critical Guardrails & Guidelines:
1. Pure Rust + Tauri IPC: Do not mock watched folders. Connect directly to `paperpilot_pdf::operations::watch::handle_watch` using tokio background tasks and oneshot cancellation channels.
2. Real Data Only: Do not hardcode document counts. Smart filter pills must calculate counts dynamically from `appState.documents` and filter the rendered list reactively.
3. Dark Theme & Svelte 5 Runes: Match existing dark mode design system (`--bg-surface`, `--text-primary`, `--border-color`, `--accent-color`). Use Svelte 5 runes (`$state`, `$derived`, `$props`).
4. Test Verification: All tests must continue to pass cleanly via `pnpm --dir apps/desktop test`.

### Step-by-Step Implementation Details

#### Step 1: Tauri IPC Commands in `apps/desktop/src-tauri`
1. Create `apps/desktop/src-tauri/src/watch_commands.rs`:
   - Structure `WatchedFolderConfig`: `{ id: String, path: String, recipe_id_or_path: String, output_dir: Option<String>, is_active: bool }`.
   - Maintain global thread-safe state `WATCHER_HANDLES: Arc<Mutex<HashMap<String, oneshot::Sender<()>>>>`.
   - Implement `start_watch_folder`:
     - Spawns an asynchronous tokio task invoking `paperpilot_pdf::operations::watch::handle_watch`.
     - Passes cancellation receiver.
   - Implement `stop_watch_folder(folder_id: String)`:
     - Signals cancellation channel.
   - Implement `list_watched_folders()`:
     - Returns current registered watcher configurations.
2. In `apps/desktop/src-tauri/src/lib.rs`:
   - Declare `pub mod watch_commands;`.
   - Register `watch_commands::start_watch_folder`, `watch_commands::stop_watch_folder`, `watch_commands::list_watched_folders` in `tauri::generate_handler![]`.

#### Step 4: Real Document Smart Filter Pills in `apps/desktop/src/lib/components/ui/DocumentList.svelte`
1. Add reactive filter pills at the top of the document list:
   - `All` (count: `appState.documents.length`)
   - `Scanned` (count: documents where `doc.isScanned === true`)
   - `Signed` (count: documents where `doc.isSigned === true`)
   - `Forms` (count: documents where `doc.hasFormFields === true`)
   - `Multi-Page` (count: documents where `(doc as any).pageCount > 1`)
2. Filter the rendered `{#each filteredDocuments as doc, index}` based on the selected active pill.
3. Style the pills with glassmorphic dark buttons, subtle active borders, and count badges.
