## 🎯 OBJECTIVES & REQUIREMENTS

### 1. Pure-Rust Spatial Text & Table Extraction (`paperpilot-pdf/src/operations/table.rs`)
- Extract real page text from `lopdf::Document` (or `unpdf` / `pdf_oxide` already present in `Cargo.toml`).
- Extract word/text elements with their bounding boxes `[x, y, width, height]`.
- **Row Clustering Algorithm**:
  - Group text elements sharing overlapping $Y$-coordinates (within standard line height tolerance ~4–8pt) into rows.
  - Sort rows top-to-bottom ($Y$ descending in standard PDF coordinate space).
- **Column Detection Algorithm**:
  - Project $X$-coordinates to identify column boundaries / gutters.
  - Form an $M \times N$ cell matrix: assign each word to column $k$ based on its $X$-interval.
  - Merge multi-word tokens inside the same cell.
- **Header Detection**:
  - Treat the first detected row of the table as `headers`.
  - Rows 2..$N$ form `data: Vec<Vec<String>>`.
- **Options Compliance**:
  - Respect `options.pages` ("all", "1", "1-3,5").
  - Respect `options.min_confidence`.
  - Respect `options.format`: Output structured `JSON` or RFC 4180 `CSV` (escaped commas, quotes, and newlines).
- When a document or page has no tabular data, gracefully return `total_tables: 0, tables: [], csv_output: None`.
