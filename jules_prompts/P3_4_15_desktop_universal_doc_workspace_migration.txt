[Task 3.4.15 / Spec 143: Universal Document Workspace & Consumer-Friendly Studio Migration]

Objective:
Implement Spec 143 (`specs/143-desktop-universal-doc-workspace-migration/spec.md`) and Task 3.4.15 in `apps/desktop`.
Migrate the desktop UI from an administrative PDF-only form into a modern, consumer-friendly Universal Document Workspace (PDF, Word, Excel, CSV, Markdown) connected directly to real data stores (`appState.documents`, `pipelineState`, `OperationsPanel.svelte`).

🚨 CRITICAL MANDATE — ZERO MOCKING:
1. Do NOT create mocked shells, static dummy folder arrays, or hardcoded document counts.
2. All document lists, format filters, and page counts MUST be dynamically computed from `appState.documents` and `appState.documentPaths`.
3. All 75+ tools in `OperationsPanel.svelte` MUST remain accessible and fully functional.
4. Existing viewers (`PdfViewer.svelte` for PDFs, `SpreadsheetViewer.svelte` for XLSX/CSV, `PdfVisualDiff.svelte`) MUST be preserved and rendered dynamically based on `fileType.ts`.
5. Strictly use Svelte 5 runes syntax (`$state`, `$derived`, `$props`). Enforce dark theme CSS variables (`--bg-surface`, `--text-primary`, `--border-color`, `color-scheme: dark`). Never introduce unstyled light backgrounds.

#### Step 2: Real Smart Format Filter Pills in `apps/desktop/src/lib/components/ui/DocumentList.svelte`
1. Use `getFileTypeInfo` from `$lib/utils/fileType` to dynamically derive format counts from `appState.documents`:
   ```typescript
   let formatCounts = $derived({
     all: appState.documents.length,
     pdf: appState.documents.filter(d => getFileTypeInfo(d.name).isPdf).length,
     sheets: appState.documents.filter(d => getFileTypeInfo(d.name).category === 'spreadsheet').length,
     word: appState.documents.filter(d => getFileTypeInfo(d.name).category === 'document').length,
     scanned: appState.documents.filter(d => !!(d as any).isScanned).length,
   });
   ```
2. Render horizontal filter pills above the document list:
   - `All (${formatCounts.all})`
   - `📄 PDF (${formatCounts.pdf})`
   - `📊 Sheets (${formatCounts.sheets})`
   - `📝 Docs (${formatCounts.word})`
   - `📷 Scanned (${formatCounts.scanned})`
3. Reactively filter the rendered items so users can isolate file types without mock data.
