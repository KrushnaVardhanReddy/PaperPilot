#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DigitalSignatureInfo {

### 2. Core Verification Algorithm (`pdf_validate_signatures_bytes`)
Implement `pub fn pdf_validate_signatures_bytes(input_bytes: &[u8], options: &PdfValidateSignaturesOptions) -> Result<Vec<u8>, PdfError>`:
1. **Load Document**: Load `lopdf::Document::load_mem(input_bytes)`.
2. **Scan Signature Fields**:
   - Inspect `/Root` dictionary $\to$ `/AcroForm` $\to$ `/Fields`.
   - Also scan page dictionaries (`doc.get_pages()`) for `/Annots` containing `/Subtype /Widget` with `/FT /Sig`.
   - For each signature dictionary (either direct or indirect via `/V`):
     - Extract field name (`/T`).
     - Extract `/SubFilter` (e.g. `adbe.pkcs7.detached`, `adbe.pkcs7.sha1`).
     - Extract `/Name` or `/M` (signer / date string).
     - Extract `/ByteRange`: array of 4 integers `[offset1, len1, offset2, len2]`.
     - Extract `/Contents`: hex/binary PKCS#7 container string.
3. **ByteRange Integrity & Tamper Check**:
   - Check that `offset1 == 0`.
   - Check that `offset1 + len1 < offset2`.
   - Check that `offset2 + len2 <= input_bytes.len() as i64`.
   - If there are trailing bytes after `offset2 + len2`, check if they contain incremental xref tables modifying previous objects. If unexpected revisions are detected, flag `is_tampered = true`.
4. **Validation Logic**:
   - If valid signature structures exist, set `is_valid = true, is_tampered = false`.
   - If document is unsigned (no `/Sig` fields found), return:
     ```json
     {
       "total_signatures": 0,
       "valid_signatures": 0,
       "all_valid": true,
       "signatures": []
     }
     ```
5. **Serialize to JSON**:
   - Serialize the `SignatureValidationReport` into pretty JSON bytes (`serde_json::to_vec_pretty(&report)`).
