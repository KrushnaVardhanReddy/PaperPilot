Jules Task Prompt: Spec 131 / Task 131A — Dynamic Public Roadmap UI & Automated Milestone Synchronization

Context:
PaperPilot is an air-gapped, zero-cloud PDF & document intelligence suite written in Rust with Svelte/Vite web and Tauri desktop interfaces.
The user wants an interactive, visually stunning, dynamic public Roadmap modal on usepaperpilot.com (apps/web).
Crucially, this roadmap MUST BE DYNAMIC: whenever a feature is merged or closed in phases/*.md, it automatically updates without manual UI maintenance.

Requirements:
1. Extraction Script: Create `scripts/sync_roadmap.ts` (Pure TypeScript / Node.js, ZERO Python dependency)
   - Iterate through all markdown files in `phases/` (e.g. `phases/phase-01-rust-core.md` to `phases/phase-13-universal-document-os.md`).
   - Parse markdown tables and text blocks using Node.js `fs` and regular expressions to extract:
     - `id`: e.g. "5.9.98", "Task 129A", "10.4"
     - `phase`: Phase number and name
     - `title`: Short task title
     - `summary`: Description or notes
     - `status`: One of "shipped" (marked with ✅ / Completed / Merged), "in_progress" (marked with 🚀 / In Progress), or "planned" (marked with 📋 / Planned / Backlog)
     - `pr`: Extracted PR link or number if available (e.g. "PR #276")
   - Output structured JSON to `apps/web/public/roadmap.json`.
   - Update `apps/web/package.json` scripts:
     - `"prebuild": "pnpm tsx ../../scripts/sync_roadmap.ts"`
     - `"sync-roadmap": "pnpm tsx ../../scripts/sync_roadmap.ts"`

2. Visual Component: Create `apps/web/src/components/RoadmapModal.svelte`
   - Use Svelte 5 runes (`$state`, `$derived`, `$props`).
   - Rich aesthetics: Glassmorphic dark theme (`--bg-surface`, `--border-color`, vibrant status accents).
   - Top Header Bar:
     - Modal title: "PaperPilot Live Roadmap"
     - Metrics pill: "78 Verified Tools" | "Zero Cloud / Air-Gapped"
     - Search input to filter tasks by keyword.
     - Category pills: "All", "Core Engine", "AI & Agents", "Web & WASM", "Desktop", "Security".
   - 3-Column Kanban Board:
     - Column 1: "🟢 Shipped & Verified" (shows completed tasks with PR tags).
     - Column 2: "🟡 In Active Progress" (shows current in-flight focus).
     - Column 3: "🔵 Planned / Community Backlog":
       - Each planned card includes a button: "👍 Vote / Request on GitHub".
       - Clicking opens: `https://github.com/KrushnaVardhanReddy/PaperPilot/issues/new?template=feature_request.yml&title=[FEATURE]:+<task_title>` in a new tab.
   - Close button (X) and backdrop click to dismiss.

3. App Integration:
   - In `apps/web/src/App.svelte`:
     - Add a "Roadmap" nav button in `app-header` next to `Download Desktop`.
     - Add a "Roadmap" link in `app-footer`.
     - Wire modal trigger state: `let showRoadmap = $state(false)`.

Verification in Jules:
1. Run `pnpm tsx scripts/sync_roadmap.ts` and verify `apps/web/public/roadmap.json` is generated with valid JSON containing shipped, in_progress, and planned items.
2. Run `pnpm --dir apps/web build` and verify 100% clean production build with zero errors.
3. Open PR targeting `feature/dev`.
