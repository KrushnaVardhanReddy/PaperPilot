## 3. Implementation Steps

### Step 1: Desktop Backend Wiring (`apps/desktop/src-tauri/`)
1. In `apps/desktop/src-tauri/src/ai_commands.rs`:
   - Implement `resolve_dynamic_query(query: &str, context: &paperpilot_nlp::traits::ResolverContext) -> Result<serde_json::Value, String>`:
     - Check `GLOBAL_AI_MODE.lock().await`.
     - When `OfflineNlp`: invoke `paperpilot_nlp::resolver::OfflineNlpResolver::new()`.
     - When `Llamafile`:
       - Check if local model (`paperpilot-qwen-0.5b-q4_k_m.gguf` or selected model) is downloaded in `~/.local/share/paperpilot/models/`.
       - If model is available and supervisor / port 8080 is reachable, initialize `LlmNlpResolver` pointing to `http://127.0.0.1:8080/v1`.
       - Run with `DynamicRouter::new(RouterMode::LlmWithFallback(llm_resolver))`.
       - If no model is downloaded or server is offline, cleanly fall back to `OfflineNlpResolver` (do not panic or error).
     - When `Universal` or `Byok`:
       - Read endpoint URL and API key from OS keyring.
       - Run with `DynamicRouter::new(RouterMode::LlmWithFallback(llm_resolver))`.
     - Return JSON value containing the plan plus `resolved_by: "llm" | "offline"` and `active_mode`.
   - Add Tauri command `get_ai_execution_status() -> Result<AiExecutionStatus, String>`.

2. In `apps/desktop/src-tauri/src/lib.rs`:
   - Update `resolve_natural_language` to call `ai_commands::resolve_dynamic_query`.
   - Register `get_ai_execution_status` in the Tauri invoke handler.
   - Hook supervisor cleanup on Tauri window destruction.

### Step 2: Desktop Chat UI Integration (`apps/desktop/src/lib/components/PdfChatPanel.svelte`)
1. Fetch active AI config (`get_ai_config`) on mount and when `AiSettingsModal` closes.
2. In the chat header or footer toolbar, display an interactive AI mode pill:
   - `🔒 Offline Rules` (green)
   - `⚡ PaperPilot Qwen 0.5B` (purple)
   - `🌐 Universal LLM` (blue)
   - `🔑 Cloud BYOK` (orange)
3. Clicking the pill opens `AiSettingsModal.svelte`.
4. If a response includes `resolved_by === 'offline'` when in LLM mode, show a subtle badge:
   - *"Resolved via Offline Rules (Fallback)"*.

1. **Mock HTTP Server via `wiremock`**:
