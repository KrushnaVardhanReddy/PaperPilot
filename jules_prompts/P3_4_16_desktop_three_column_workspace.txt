### Step-by-Step Implementation Details

#### Step 1: Slim Activity Rail in `apps/desktop/src/lib/components/layout/Sidebar.svelte`
- Slim down the sidebar into an activity bar ~48px wide:
  - Vertical icon buttons:
    - 📁 **Library / Files** (`id: 'documents'`)
    - 🔗 **Pipeline Studio** (`id: 'pipeline'`)
    - ⚡ **API Gateway** (`id: 'api'`)
    - ⚙️ **Settings** (`id: 'settings'`)
  - Tooltips on hover, active glowing pill on selected tab.
  - Clicking the currently active tab toggles Column 2 (Contextual Drawer) open or closed.

---

#### Step 2: Contextual Column 2 in `apps/desktop/src/routes/+page.svelte`
- Column 2 (~240px wide, collapsible) is placed between the Activity Rail and the Main Stage:
  - **State A (Library Mode)**:
    - When `selectedDocumentIndex === null`: renders `DocumentList.svelte` with the real smart format filter pills (`All`, `Scanned`, `Signed`, `Forms`, `Multi-Page`).
    - Selecting a document opens it in Column 3 and switches Column 2 into State B.
  - **State B (Thumbnails Mode)**:
    - When a PDF document is active (`selectedDocumentIndex !== null` and `isPdfFile`): renders `PdfThumbnails.svelte` with page numbers and reordering capabilities.
    - Clicking a thumbnail jumps to that page (`pageNum = p`).
  - Collapse button at the top header of Column 2 (`‹` icon, or `Ctrl + B`) to collapse it and expand Column 3 to maximum width.

---

#### Step 3: Main Stage Hero Canvas in `apps/desktop/src/routes/+page.svelte`
- Column 3 occupies 75%–85% of screen width with dark-neutral canvas:
  - If a spreadsheet is selected (`isSpreadsheetFile`): renders `<SpreadsheetViewer file={selectedDoc} />`.
  - If a PDF is selected (`isPdfFile`): renders `<PdfViewer ... />` and `<PdfFormLayer ... />`.
  - If diff view is active: renders `<PdfVisualDiff ... />`.
- **Floating Action Pill** (centered at the bottom of the canvas):
  - Sleek frosted glass pill with icons:
    - `🔍 Zoom In/Out` (dispatches `paperpilot:zoom-in` / `paperpilot:zoom-out`)
    - `↻ Rotate 90°` (dispatches `paperpilot:rotate-single-page`)
    - `✍ Sign / Annotate` (activates annotation toolbar)
    - `⚙️ More Tools` (toggles the right-hand slide-out drawer)

---

#### Step 4: Slide-Out Operations Drawer for `OperationsPanel.svelte`
- Wrap `OperationsPanel.svelte` inside an expandable slide-out drawer on the right edge:

  - Opens smoothly when clicking "More Tools" or selecting a tool.
  - Features a prominent close button (`✕`) at the top right to dismiss it.
  - Contains all 75 tool parameters and run buttons.
