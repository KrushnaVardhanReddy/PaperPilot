## Detailed Implementation Tasks

### 1. Register Missing MCP Tools
In `paperpilot-mcp/src/server.rs`:
- Register `pdf_extract_tables`:
  - Define schema in `list_tools`.
  - In `execute_call_tool`: call `paperpilot_pdf::operations::extract_tables` or return extracted table markdown/json.
- Register `semantic_search`:
  - Define schema in `list_tools` accepting `"query": String`, `"input": Option<String>`, `"limit": Option<usize>`.
  - In `execute_call_tool`: call vector similarity search or keyword semantic search.

### 2. Flexible Parameter Parsing
Support optional parameters and aliases across tool handlers:
- **`pdf_extract_text`**: If `"output"` parameter is not provided or null, do not fail. Extract text and return it directly in `ContentBlock::Text(serde_json::json!({"success": true, "text": text}).to_string())`.
- **`pdf_rag_chunks`**: If `"output"` is not provided, return chunks directly in the JSON response payload.
- **`pdf_bates`**: Default `"start_number"` to `1` if omitted or not provided.
- **`pdf_merge` & `pdf_merge_alternate`**: Accept both `"inputs": [...]` array and single `"input"` (array or comma-delimited string).
- **`pdf_reorder_pages`**: Accept both `"order": [...]` and `"page_order": [...]`.
- **`pdf_fill_form`**: Parse `"values"` whether supplied as a JSON object `{"field1": "val1"}` or serialized string.
- **`pdf_create_form_field`**: Accept `"field_name"`, `"field_type"`, `"page"`, `"rect"`.
- **`pdf_redact`**: Accept `"page"` (integer), `"rect"` `[x, y, w, h]`, and optional `"color"`.
- **`pdf_encrypt`**: Accept `"password"` (or `"user_password"`) with default AES-256 permissions.
- **`pdf_timestamp`**: If timestamp server is unreachable or unconfigured, return a valid offline timestamp or structured response without error.
