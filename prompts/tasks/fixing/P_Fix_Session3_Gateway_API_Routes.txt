### 2. Request Payload Alignment in `handlers.rs`
In `paperpilot-gateway/src/routes/handlers.rs`:
- `pdf_encrypt`: Accept both `"password"` and `"user_password"`.
- `pdf_redact`: Accept `"page"` as optional with default `1`, plus `"rect"`.
- `pdf_fill_form`: Accept `"values"` as JSON object or key-value map.
- `pdf_create_form_field`: Accept `"field_name"`, `"field_type"`, `"rect"`.
- `pdf_bates`: Default `"start_number"` to `1` when omitted.
- `pdf_validate_signatures`: Do not require an `"output"` file path (signature verification returns verification status/metadata, output path is optional).

### 3. Response Standardization
- When an operation succeeds, return HTTP 200 with JSON payload:
  `{ "success": true, "message": "...", "output": "..." }`
- When client payload validation fails, return HTTP 400 with:
  `{ "success": false, "error": "Human readable message" }`
