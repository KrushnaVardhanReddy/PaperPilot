## Detailed Implementation Tasks

### 1. `pdf_comic_archive` (CBZ Packaging)
In `paperpilot-pdf/src/operations/comic.rs` or `paperpilot-core/`:
- When converting PDF to CBZ archive:
  - Extract each page as PNG/JPEG.
  - Create a valid zip archive using `zip::ZipWriter`.
  - Add each image entry with standard naming (`page_001.png`, `page_002.png`, etc.).
  - Ensure the writer is properly finished (`zip.finish()`) and flushed so the resulting `.cbz` file starts with valid magic bytes `[0x50, 0x4B, 0x03, 0x04]` (PK ZIP header).

### 2. `pdf_split_by_outline`
In `paperpilot-pdf/src/operations/` (split by outline/bookmarks):
- Inspect the `/Outlines` dictionary in the PDF catalog.
- If the document does not contain an `/Outlines` dictionary or has zero outline items:
  - Do not panic or fail with an unhandled exception.
  - Gracefully fallback to splitting by top-level section, single pages, or return `{ "success": false, "error": "Document contains no outlines/bookmarks to split by" }` without panicking.

### 3. `pdf_render`
In `paperpilot-pdf/src/operations/render.rs`:
- When rendering pages to PNG/JPEG:
  - Ensure the raster image is encoded and explicitly saved to the target `output` file path.
  - Flush the file stream so that `std::fs::metadata(&output)` immediately returns `len > 0`.
