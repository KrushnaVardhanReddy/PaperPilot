Implement Spec 160 to provide comprehensive environment and system diagnostics across CLI, REST Gateway, and Desktop UI.

- `crates/paperpilot-core/src/diagnostics.rs` (new diagnostic probes)

### 2. CLI `paperpilot doctor` Command (`paperpilot-cli/src/commands/doctor.rs`)
- Render ANSI-colored checklist:
  - `[✓] Temp Directory: /tmp (writable & ephemeral cleanup verified)`
  - `[✓] OCR Models: models/ocr/ppocrv4 (det.onnx, rec.onnx found)`
  - `[✓] Gateway Port: 7823 available`
  - `[✓] Disk Space: > 5 GB available`
- Support `--json` flag to emit raw `DiagnosticReport` as JSON.

### 3. Gateway Health & Diagnostics Endpoints (`paperpilot-gateway`)
- `GET /health`: Fast 200 OK lightweight probe `{"status": "ok", "version": "1.0.0"}`.
- `GET /api/v1/doctor`: Executes `run_diagnostics()` and returns full `DiagnosticReport`.

### 4. Desktop Diagnostics Panel
- Add "Run Diagnostics" button in Settings that opens `SystemDoctorModal.svelte`, displaying real-time probe statuses with green/amber/red indicators.
