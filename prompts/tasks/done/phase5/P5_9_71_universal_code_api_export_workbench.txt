## Objective
Implement Phase 2 of Spec 082: Bring the **"Export as Code / API / MCP Prompt" Workbench** to individual tools in the Desktop UI (`apps/desktop`). Users configuring tools in `EditableActionCard.svelte` should be able to click a `</> Code / API` button to immediately view copyable, live snippets for:
1. **cURL (Gateway REST API)**: `curl -X POST http://localhost:8080/api/v1/...`
2. **Native CLI Command**: `paperpilot <subcommand> ...`
3. **AI Agent MCP Prompt & Tool Call**: Ready-to-paste prompt for Claude/ChatGPT/Gemini with tool arguments
4. **JavaScript / TypeScript (Embed API)**: `await window.PaperPilot.executeTool(...)`

All code generation logic must be centralized in a clean, pure TypeScript utility module `snippetGenerator.ts`, with 100% test coverage and Playwright E2E verification.

## 1. Centralized Snippet Engine: `apps/desktop/src/lib/utils/snippetGenerator.ts`
Implement a pure, headless snippet generation engine exporting:

```typescript
export interface SnippetTarget {
  toolId: string; // e.g. 'pdf_rotate', 'pdf_bates', 'pdf_watermark', 'pdf_compress', 'pdf_encrypt', 'pdf_decrypt', 'pdf_redact', 'pdf_split', 'pdf_merge', etc., or 'document_workflow'
  intent?: string; // e.g. 'Rotate', 'Bates', 'Watermark', 'Compress', 'Encrypt', etc.
  params: Record<string, any>;
  inputFile?: string;
  outputFile?: string;
  inputs?: string[];
}

export interface GeneratedSnippets {
  cli: string;
  curl: string;
  mcpToolCall: string;
  mcpAgentPrompt: string;
  embedJs: string;
}

export function generateSnippets(target: SnippetTarget): GeneratedSnippets;
```

### Generation Rules:
- Support common intents and tool IDs:
  - `Rotate` / `pdf_rotate`:
    - CLI: `paperpilot rotate --input "${input}" --angle ${angle} --output "${output}"` (include `--pages "${pages}"` if not "all")
    - cURL: `curl -X POST http://localhost:8080/api/v1/tools/rotate -F "file=@${input}" -F "angle=${angle}"`
    - MCP Tool Call: `{ "name": "pdf_rotate", "arguments": { "input": "${input}", "angle": ${angle}, "output": "${output}" } }`
    - MCP Prompt: `Please rotate "${input}" by ${angle} degrees and save to "${output}".`
    - Embed JS: `await window.PaperPilot.executeTool('pdf_rotate', { input: '${input}', angle: ${angle}, output: '${output}' });`
  - `Bates` / `pdf_bates`:
    - CLI: `paperpilot bates --input "${input}" --prefix "${prefix}" --start ${start} --padding ${padding} --output "${output}"`
    - cURL: `curl -X POST http://localhost:8080/api/v1/tools/bates -F "file=@${input}" -F "prefix=${prefix}" -F "start=${start}"`
    - MCP Tool Call: `{ "name": "pdf_bates", "arguments": { "input": "${input}", "prefix": "${prefix}", "start_number": ${start}, "output": "${output}" } }`
    - MCP Prompt: `Apply Bates numbering to "${input}" starting with prefix "${prefix}" and save to "${output}".`
    - Embed JS: `await window.PaperPilot.executeTool('pdf_bates', { input: '${input}', prefix: '${prefix}', start_number: ${start}, output: '${output}' });`
  - `Watermark` / `pdf_watermark`:
    - CLI: `paperpilot watermark --input "${input}" --text "${text}" --opacity ${opacity} --output "${output}"`
    - cURL: `curl -X POST http://localhost:8080/api/v1/tools/watermark -F "file=@${input}" -F "text=${text}"`
    - MCP Tool Call: `{ "name": "pdf_watermark", "arguments": { "input": "${input}", "text": "${text}", "output": "${output}" } }`
    - Embed JS: `await window.PaperPilot.executeTool('pdf_watermark', { input: '${input}', text: '${text}', output: '${output}' });`
  - `Encrypt` / `pdf_encrypt`:
    - CLI: `paperpilot encrypt --input "${input}" --password "${password}" --output "${output}"`
    - cURL: `curl -X POST http://localhost:8080/api/v1/tools/encrypt -F "file=@${input}" -F "password=${password}"`
    - MCP Tool Call: `{ "name": "pdf_encrypt", "arguments": { "input": "${input}", "user_password": "${password}", "output": "${output}" } }`
    - Embed JS: `await window.PaperPilot.executeTool('pdf_encrypt', { input: '${input}', password: '${password}', output: '${output}' });`
  - `Compress` / `pdf_compress`:
    - CLI: `paperpilot compress --input "${input}" --quality 80 --output "${output}"`
    - cURL: `curl -X POST http://localhost:8080/api/v1/tools/compress -F "file=@${input}" -F "quality=80"`
    - MCP Tool Call: `{ "name": "pdf_compress", "arguments": { "input": "${input}", "output": "${output}" } }`
    - Embed JS: `await window.PaperPilot.executeTool('pdf_compress', { input: '${input}', output: '${output}' });`
  - Default Fallback for other tools (e.g. `pdf_split`, `pdf_merge`, `pdf_to_docx`, `img_to_pdf`, etc.):
    - CLI: `paperpilot ${subcommand} --input "${input}" --output "${output}"`
    - cURL: `curl -X POST http://localhost:8080/api/v1/tools/${subcommand} -F "file=@${input}"`
    - MCP Tool Call: `{ "name": "${toolId}", "arguments": { ... } }`
    - Embed JS: `await window.PaperPilot.executeTool('${toolId}', { ... });`
