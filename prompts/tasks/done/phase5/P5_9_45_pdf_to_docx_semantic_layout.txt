## 1. Concrete Implementation Guidance

### A. Extract Structured Blocks (Avoid Flat `lopdf::extract_text()`)
When extracting text from the PDF, use structured extraction or line parsing that respects headings and paragraphs (e.g. from `pdf_oxide::api::Pdf::to_markdown` or markdown block parsing):
1. **Title**: `"Welcome to Smallpdf"` $\to$ Centered heading, bold, size 44 (22pt), color `1F242E`.
2. **Subtitle**: `"Ready to take document management to the next level?"` $\to$ Centered paragraph, size 22 (11pt), color `757E8A`.
3. **4 Feature Cards**: Group the 4 distinct feature cards:
   - "Digital Documents—All In One Place" + Body
   - "Enhance Documents in One Click" + Body
   - "Access Files Anytime, Anywhere" + Body
   - "Collaborate With Others" + Body

### B. Construct 2-Column Tables with `docx_rs`
For each of the 4 feature cards, create a 2-column borderless table (`docx_rs::Table` with `TableBorders::new().clear_all()`):
- Alternating left/right arrangement:
  - Card 1: Left column graphic cell (width 2600 dxa), Right column text cell (width 5000 dxa).
  - Card 2: Left column text cell (width 5000 dxa), Right column graphic cell (width 2600 dxa).
  - Card 3: Left column graphic cell (width 2600 dxa), Right column text cell (width 5000 dxa).
  - Card 4: Left column text cell (width 5000 dxa), Right column graphic cell (width 2600 dxa).
- Inside the text cell:
  - Paragraph 1: Card Title (bold, size 24 = 12pt).
  - Paragraph 2: Card Description (size 19 = 9.5pt, space after 120 dxa).
- Inside the graphic cell:
  - If a raster image is extracted, embed `Pic::new(&png_bytes)`. If vector / Form XObject, embed a styled graphic placeholder / illustration badge run.

### C. Margins & Spacing
- Page Margins: `720 dxa` (0.5 in) top, bottom, left, right.
- Ensure the document opens as **1 single page** in LibreOffice and Word without spilling onto a second page.
