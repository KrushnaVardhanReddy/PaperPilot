You are implementing the client-side declarative workflow and headless pipeline runner in `apps/embed`.
Follow these exact instructions and architecture:

---

### Step 1: Create `apps/embed/src/pipeline.ts`
Implement the sequential PDF transformation engine using `pdf-lib` (already in `apps/embed/package.json`):

```typescript
import { PDFDocument, degrees, rgb, StandardFonts } from 'pdf-lib';

export interface PipelineStep {
  tool: string;
  [key: string]: any;
}

export interface PipelineOptions {
  file: File | Uint8Array;
  steps: PipelineStep[];
  onProgress?: (stepIndex: number, step: PipelineStep, progressPercent: number) => void;
}

export interface PipelineResult {
  success: boolean;
  data: Uint8Array;
  filename: string;
  stepsExecuted: number;
  durationMs: number;
}
```

Implement `executePipelineStep(inputBytes: Uint8Array, step: PipelineStep): Promise<Uint8Array>` supporting:
- `rotate`: Rotates pages by `angle` (90, 180, 270) for `pages` ('all' or '1,2-4').
- `watermark`: Stamps `text` (default 'CONFIDENTIAL') with `opacity` (default 0.35) and `angle` (45) using `StandardFonts.HelveticaBold`.
- `extract` / `extract_pages` / `split`: Extracts specified pages via `newDoc.copyPages`.
- `delete` / `delete_pages`: Removes specified pages in descending order.
- `reorder` / `reorder_pages` / `reverse`: Reorders or reverses page order.
- `compress` / `optimize`: Re-saves with `{ useObjectStreams: true }`.
- `crop`: Adjusts `page.setCropBox`.
- `flatten`: Calls `doc.getForm().flatten()`.

Implement `runPipeline(options: PipelineOptions): Promise<PipelineResult>`:
- Accepts `File` or `Uint8Array`.
- Passes the resulting `Uint8Array` from step `N` directly as input to step `N+1`.
- Invokes `onProgress?.(stepIndex, step, progressPercent)` at each step.
- Returns `{ success: true, data: finalBytes, filename, stepsExecuted, durationMs }`.

1. Add `pipeline?: string | PipelineStep[]` and `autoDownload?: boolean` to `Props`.
2. Parse `parsedPipelineSteps = $derived(...)`: If `pipeline` is a string, `JSON.parse(pipeline)`. If array, use as-is.
3. When `parsedPipelineSteps && parsedPipelineSteps.length > 0`:
   - Display a **Visual Stepper View** instead of the individual tool cards:
     - Header: "Automated Document Pipeline"
     - Stepper items: `[1] StepName ➔ [2] StepName ➔ [3] StepName`
     - Status badges: Pending (○), Active (🔄), Done (✓), Error (✗).

     - Automatically execute `runPipeline({ file, steps: parsedPipelineSteps, onProgress })`.

     - If `autoDownload` is true, trigger browser download of the resulting PDF blob.
     - Display a "Download Processed PDF" button upon completion.
