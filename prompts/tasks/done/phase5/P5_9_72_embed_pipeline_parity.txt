# Task 5.9.72: Embed Pipeline 1-to-1 Desktop Parity — Dropzone Polish, Interactive Step Customization, and Flow Management (Save/Export/Import)
# Base Branch: main
# Related Spec: specs/083-embed-pipeline-parity-and-step-customization/spec.md
# Priority: MEDIUM (Full Desktop Pipeline Parity inside Web Embed)

## Objective
Bring the Web Embed Pipeline (`apps/embed`) to complete 1-to-1 feature parity with the Desktop visual pipeline builder:
1. **Explicit File Browsing**: Add a prominent `📁 Browse Files` button and selected file card (icon, name, size, `✕ Change File`) in the embed dropzone.
2. **Interactive Step Management**: When customization is enabled (`data-allow-customization="true"` or `allowCustomization: true`), allow users to remove steps (`✕`) and dynamically append steps (`+ Add Step`) from in-browser tools (`Rotate`, `Watermark`, `Compress`, `Extract`, `Split`).
3. **Flow Management Toolbar (Save, Presets, Export, Import)**:
   - Preset & Saved Flow `<select>` dropdown (using `DEFAULT_PRESETS` and `localStorage['paperpilot_saved_flows']`).
   - `💾 Save Flow` button with lightweight modal/prompt saving custom recipes.
   - `⬇️ Export JSON` button downloading portable `flow.json`.
   - `⬆️ Import JSON` button loading portable `flow.json`.
4. **Execution Controls**: Explicit `"⚡ Run Pipeline"` button when `autoExecute === false` (or when customizable).

## 2. Flow Management Toolbar (`Widget.svelte`)
Add a clean toolbar directly above or below the pipeline stepper:
```svelte
{#if allowCustomization}
  <div class="pp-flow-toolbar">
    <div class="pp-flow-selector">
      <label for="pp-flow-select">Flow:</label>
      <select id="pp-flow-select" bind:value={selectedFlowId} onchange={handleFlowChange} class="pp-select">
        <optgroup label="Standard Presets">
          {#each DEFAULT_PRESETS as preset}
            <option value={preset.id}>{preset.name}</option>
          {/each}
        </optgroup>
        {#if savedFlows.length > 0}
          <optgroup label="My Saved Flows">
            {#each savedFlows as flow}
              <option value={flow.id}>{flow.name}</option>
            {/each}
          </optgroup>
        {/if}
      </select>
    </div>

    <div class="pp-flow-actions">
      <button type="button" class="pp-btn-sm" onclick={() => isSaveModalOpen = true} disabled={customSteps.length === 0}>
        💾 Save Flow
      </button>
      <button type="button" class="pp-btn-sm" onclick={handleExportJson} disabled={customSteps.length === 0}>
        ⬇️ Export JSON
      </button>
      <button type="button" class="pp-btn-sm" onclick={() => importFileInput?.click()}>
        ⬆️ Import JSON
      </button>
      <input type="file" accept=".json" bind:this={importFileInput} onchange={handleImportJson} style="display: none;" />
    </div>
  </div>
{/if}
```

## 3. Interactive Stepper & Step Picker (`Widget.svelte`)
- Display steps in `.pp-pipeline-stepper`:
  - Show a remove button (`✕`) on each step chip when `allowCustomization` is true.
  - Render an `[+ Add Step]` button at the end of the stepper.
  - Clicking `[+ Add Step]` opens a clean inline picker with tools:
    - `rotate` (angle: 90)
    - `watermark` (text: 'CONFIDENTIAL', opacity: 0.3)
    - `compress`
    - `extract` (pages: '1')
    - `split` (pages: '1-2')
  - Selecting an operation appends it to `customSteps`.
