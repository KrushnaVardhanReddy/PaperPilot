## Objective
Build and execute a **100% pure-Rust, zero-Python E2E Test Suite** in `tools/tri-interface-e2e/`.

This crate must execute **independent, rigorous 3rd-party semantic assertions** across **ALL 44 tools** and cover all **5 PaperPilot Interfaces**:
1. **💻 CLI**: invoking `target/debug/paperpilot-cli` (or release) subprocess.
2. **🤖 MCP**: stdio JSON-RPC 2.0 communication with `target/debug/paperpilot-mcp`.
3. **🌐 REST API**: spawning `paperpilot serve --port 7823` in background, polling `/health` until ready, and sending HTTP requests to the REST endpoints.
4. **⚡ WASM (Browser)**: in-browser client engine target parity documentation & invocation schema (`WasmPdfEngine.<op>`).
5. **☁️ Cloudflare Edge**: edge microservice target parity documentation & endpoint schema (`POST /api/v1/<op>`).

Every single one of the 44 tools **MUST** define and test:
1. **Tier 1: Simple**
2. **Tier 2: Medium**
3. **Tier 3: Complex / Hard**
4. **Negative Case**

No tool may have only 1 positive test case. Assert exact page content, structure, and metadata without any lazy shortcuts or bypassed checks.

## 2. Global Semantic Verification Rules

1. **Input Immutability**:
   - Before any test executes, compute SHA-256 of all input fixtures.
   - After the test completes, verify all input files retain their exact original hash.
2. **Output Non-Identity**:
   - For tools producing a new document (merge, split, rotate, watermark, encrypt, etc.), verify the output SHA-256 does NOT match any input file's SHA-256.
   - **Crucial Rule**: ONLY compare the output hash against actual INPUT files. Do NOT hash the output destination path beforehand!
3. **Gateway Server Lifecycle**:
   - Spawn `paperpilot serve --port 7823`.
   - Poll `http://127.0.0.1:7823/health` with exponential backoff / retry up to 15 seconds until HTTP 200 is received before invoking any REST endpoint.
   - Cleanly terminate the gateway child process upon test suite completion.
4. **5-Interface Parity Documentation**:
   - For every tool, the scorecard MUST document all 5 interfaces:
     1. **💻 CLI**
     2. **🤖 MCP**
     3. **🌐 REST API**
     4. **⚡ WASM (Browser)**
     5. **☁️ Cloudflare Edge**

## 3. Explicit 3-Tier Positive + Negative Matrix for ALL 44 Tools

### A. Page Operations (9 Tools)
1. `pdf_merge`:
   - **Simple**: 2 files: `merge_a.pdf` ("AAA") + `merge_b.pdf` ("BBB") -> 2 pages, P1="AAA", P2="BBB".
   - **Medium**: 2 files: `merge_a.pdf` ("AAA") + `multi_page.pdf` (5p) -> 6 pages, P1="AAA", P2-P6="PAGE_TEXT_P1"..P5.
   - **Complex**: 3 files: `merge_a.pdf` ("AAA") + `merge_b.pdf` ("BBB") + `merge_c.pdf` ("CCC") -> 3 pages with exact text order.
   - **Negative**: Missing input file -> non-zero exit code or error JSON.
2. `pdf_split`:
   - **Simple**: Split `multi_page.pdf` range `"1,2"` -> 2 pages, P1="P1", P2="P2", no "P3".
   - **Medium**: Split range `"3-5"` -> 3 pages, P1="P3", P2="P4", P3="P5".
   - **Complex**: Non-contiguous split `"1,3,5"` -> 3 pages with exact respective text.
   - **Negative**: Out-of-bounds range `"99-100"` -> error.
3. `pdf_extract_pages`:
   - **Simple**: Extract single page `"1"` -> 1 page with "P1".
   - **Medium**: Extract pages `"1,3"` -> 2 pages with "P1" and "P3".
   - **Complex**: Extract range `"2-4"` from 5-page doc -> 3 pages with "P2", "P3", "P4".
   - **Negative**: Extract page `"0"` or `"99"` -> error.
4. `pdf_delete_pages`:
   - **Simple**: Delete page `"2"` -> 4 pages remaining, "P2" absent.
   - **Medium**: Delete non-adjacent `"2,4"` -> 3 pages remaining ("P1", "P3", "P5").
   - **Complex**: Delete range `"1-3"` -> 2 pages remaining ("P4", "P5").
   - **Negative**: Delete all pages -> error.
5. `pdf_reorder_pages`:
   - **Simple**: Swap 2 pages `[2, 1]` -> P1 has "P2", P2 has "P1".
   - **Medium**: Custom permutation `[2, 1, 3, 4, 5]` -> exact order verified per page.
   - **Complex**: Full reversal `[5, 4, 3, 2, 1]` -> 5 pages in exact reversed sequence.
   - **Negative**: Invalid index in permutation list -> error.
6. `pdf_rotate`:
   - **Simple**: Rotate 1 page by 90° -> `/Rotate` == 90.
   - **Medium**: Rotate page 3 by 180° in 5-page doc -> only page 3 `/Rotate` == 180.
   - **Complex**: Rotate all pages by 270° -> all pages `/Rotate` == 270.
   - **Negative**: Invalid angle (e.g. 45°) -> error.
7. `pdf_crop`:
   - **Simple**: Crop 1 page to rect `[50, 50, 400, 400]` -> `MediaBox`/`CropBox` matches rect.
   - **Medium**: Crop page 2 of multi-page doc -> only target page cropped, others intact.
   - **Complex**: Crop all pages with custom margins -> all pages updated.
   - **Negative**: Inverted rect coordinates (`[400, 400, 50, 50]`) -> error.
8. `pdf_burst`:
   - **Simple**: Burst 2-page document -> exactly 2 single-page PDFs created.
   - **Medium**: Burst 5-page document -> exactly 5 single-page PDFs created with respective "P1".."P5".
   - **Complex**: Burst 10-page document -> exactly 10 single-page PDFs created in sequence.
   - **Negative**: Target directory invalid/unwritable -> error.
9. `pdf_remove_blank`:
   - **Simple**: 2-page doc with 1 blank page -> output has 1 page.
   - **Medium**: `with_blank.pdf` (5 pages: text, blank, text, whitespace, text) -> output has 3 pages in order.
   - **Complex**: Multi-page doc with varying whitespace/near-blank thresholds -> blanks stripped, content preserved.
   - **Negative**: All-blank document -> handled gracefully without panic.
