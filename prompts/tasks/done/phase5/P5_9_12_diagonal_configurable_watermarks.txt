## Requirements

### 1. Engine Core (`paperpilot-pdf/src/operations/watermark.rs`)
1. Extend `WatermarkOperation`:
   ```rust
   pub struct WatermarkOperation {
       pub text: String,
       pub angle: f32,                // Default: 45.0 (degrees)
       pub opacity: f32,              // Default: 0.2 (0.0 to 1.0)
       pub font_size: Option<f32>,    // Default: None (auto-calculated or 54.0)
       pub color: Option<String>,     // Default: None (light gray #888888 / [0.5, 0.5, 0.5])
       pub pages: Option<Vec<u32>>,   // Default: None (all pages)
   }
   ```
2. Dynamic Center & Diagonal Matrix:
   - Calculate page width $W$ and height $H$ from `MediaBox` (default to 612x792 if missing).
   - Compute center point $(x_c, y_c) = (W/2, H/2)$.
   - Rotate by `angle` (default 45°):
     $$\cos(\theta) = \cos(\text{angle} \times \pi / 180), \quad \sin(\theta) = \sin(\text{angle} \times \pi / 180)$$
   - Calculate approximate text width offset to center the text on the page.
3. PDF Transparency (`ExtGState`):
   - Add `/ExtGState` with `/ca` and `/CA` set to `opacity` (default `0.2`) in `/Resources`.
   - Apply `/GS1 gs` in the content stream so document text underneath remains readable.
4. Unit Tests in `watermark.rs`:
   - Verify default 45° diagonal angle and opacity in stream output.
   - Verify horizontal (0°) orientation when `angle = 0.0`.
   - Verify custom color and custom font size.

### 2. The 5 Deployment Surfaces (Penta-Interface Mandate)
1. **💻 CLI (`paperpilot-cli`)**:
   - In `Commands::Watermark`:
     - `--text <TEXT>` (required)
     - `--angle <FLOAT>` (default `45.0`)
     - `--opacity <FLOAT>` (default `0.2`)
     - `--color <STRING>` (optional, e.g. "gray", "red", "blue")
     - `--font-size <FLOAT>` (optional)
2. **🤖 MCP (`paperpilot-mcp`)**:
   - In `execute_list_tools()`: update `pdf_watermark` JSON schema with optional properties:
     `angle` (number), `opacity` (number), `color` (string), `font_size` (number).
   - In `execute_call_tool()`: extract optional params and pass to `WatermarkOperation`.
3. **🌐 REST API (`paperpilot-gateway`)**:
   - Update `WatermarkRequest` in `paperpilot-gateway/src/handlers.rs` to parse `angle`, `opacity`, `color`, `font_size`.
   - Update OpenAPI definition.
4. **⚡ WASM (`paperpilot-wasm`)**:
   - Support `watermark(pdf_bytes: &[u8], text: &str, angle: Option<f32>, opacity: Option<f32>) -> Result<Vec<u8>, JsValue>`.
5. **☁️ Cloudflare Edge (`apps/edge`)**:
   - Accept `angle` and `opacity` in `POST /api/v1/watermark`.
