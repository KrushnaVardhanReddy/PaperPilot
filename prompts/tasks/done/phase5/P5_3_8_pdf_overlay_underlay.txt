### Step 2: Implementation Details (`paperpilot-pdf/src/operations/pdf_overlay_underlay.rs`)

```rust
use lopdf::{Document, Object, Dictionary, Stream};
use paperpilot_core::error::PdfError;
use paperpilot_core::traits::{PdfDocument, PdfOperation};
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PdfOverlayUnderlayOptions {
    /// Path to the template PDF to overlay or underlay (e.g. stationery letterhead)
    #[serde(default)]
    pub template_path: Option<String>,
    /// Inline base64 template PDF data
    #[serde(default)]
    pub template_data: Option<String>,
    /// Mode: "overlay" (foreground) or "underlay" (background / watermark behind text)
    #[serde(default = "default_mode")]
    pub mode: String,
    /// Target pages: "all", "1", "1,3,5", "first", "last" (default: "all")
    #[serde(default = "default_pages")]
    pub pages: String,
    /// Opacity between 0.0 and 1.0 (default: 1.0)
    #[serde(default = "default_opacity")]
    pub opacity: f32,
}

fn default_mode() -> String { "underlay".to_string() }
fn default_pages() -> String { "all".to_string() }
fn default_opacity() -> f32 { 1.0 }

impl Default for PdfOverlayUnderlayOptions {
    fn default() -> Self {
        Self {
            template_path: None,
            template_data: None,
            mode: default_mode(),
            pages: default_pages(),
            opacity: default_opacity(),
        }
    }
}
```

#### Core Algorithm:
1. Parse input PDF bytes using `Document::load_mem(input_bytes)`. Return `Err(PdfError::InvalidInput(...))` if empty.
2. Load template PDF bytes from `options.template_path` (supporting relative fallback `../`), `options.template_data` (base64 decode), or fallback to `tests/e2e_fixtures/real/single_page.pdf` if unspecified.
3. Load template document: `Document::load_mem(&template_bytes)`.
4. Import template page 1 into target document as a form XObject (`/Type /XObject`, `/Subtype /Form`, `/BBox`, `/Resources`).
5. For each target page in the input document (filtered by `options.pages`):
   - Register the template form XObject in `/Resources` -> `/XObject` (e.g. `TplOverlay`).
   - If `mode == "underlay"`:
     - Prepend `/TplOverlay Do` to `/Contents` so the template renders **underneath** existing document content.
   - If `mode == "overlay"`:
     - Append `/TplOverlay Do` to `/Contents` so the template renders **on top** of existing document content.
6. Return `doc.save_to(&mut buf)`.
