## Objective
Upgrade `PdfToDocxOperation` in `paperpilot-pdf` to use the pure-Rust `unpdf` crate for recursive XY-Cut layout segmentation, converting multi-column PDFs into structured Markdown and emitting clean OpenXML DOCX (`docx-rs`).

Currently, raw extraction flattens columns into a single unformatted text blob.
`unpdf` uses recursive XY-Cut algorithms to segment multi-column layouts into ordered structural blocks (titles, subtitles, cards, tables).

You are provided with:
1. **Input PDF**: `fixtures/Get_Started_With_Smallpdf.pdf`
2. **Current Deficient DOCX**: `fixtures/Get_Started_With_Smallpdf.docx`
3. **Reference Expected DOCX**: `fixtures/Get_Started_With_Smallpdf_EXPECTED.docx`

## 1. Concrete Implementation Guidance
1. In `paperpilot-pdf/Cargo.toml`, add `unpdf = "0.1"`.
2. In `paperpilot-pdf/src/operations/conversion.rs`:
   - Parse input PDF via `unpdf::Unpdf::new().parse(...)` or `unpdf::to_markdown(...)`.
   - Feed the resulting structured markdown through `pulldown-cmark` into `docx-rs`.
   - Title / Heading 1: Centered, Bold 44 dxa (22pt), color `1F242E`.
   - Subtitle / Heading 3: Centered, 22 dxa (11pt), color `757E8A`.
   - Section heading + description pairs: Generate 2-column borderless `Table` elements (`TableBorders::new().clear_all()`), maintaining side-by-side card flow.
   - Page margins: `720 dxa` (0.5 in) ensuring 1 single page fit in Word/LibreOffice.
