### Goal
Implement a pure-Rust vector stream color inversion and dark mode engine (`pdf_invert_colors`) using `lopdf`.
Preserve 100% of selectable vector text and embedded fonts (do not rasterize to images!).

### Step 1: Core Engine in `paperpilot-pdf`
Create `paperpilot-pdf/src/operations/pdf_invert_colors.rs`:
- Define:
  ```rust
  #[derive(Debug, Clone, Serialize, Deserialize)]
  #[serde(rename_all = "snake_case")]
  pub enum InvertMode {
      DarkMode,
      TrueInvert,
      HighContrast,
      Sepia,
  }

  #[derive(Debug, Clone, Serialize, Deserialize)]
  pub struct InvertColorsOptions {
      pub mode: Option<InvertMode>,
      pub pages: Option<String>,
  }
  ```
- Implement `pub fn invert_pdf_colors(doc: &mut lopdf::Document, options: &InvertColorsOptions) -> Result<(), PaperPilotError>`.
- For each target page:
  1. Retrieve `/MediaBox` rectangle `[x, y, w, h]`.
  2. Inject background fill rectangle (e.g., `#181818` for DarkMode) at the beginning of the page `/Contents` stream.
  3. Scan the `/Contents` stream bytes for color operands (`rg`, `RG`, `g`, `G`, `k`, `K`) or invert text fill from black to white.
  4. Write unit tests:
     - `test_invert_pdf_colors_dark_mode`
     - `test_invert_pdf_colors_true_invert`
     - `test_invert_pdf_colors_page_subset`
- Export from `paperpilot-pdf/src/operations/mod.rs` and `paperpilot-pdf/src/lib.rs`.
