Task: Context-Aware Dynamic Tool Dispatcher & Feature Pack Filtering [Spec 054]

Objective:
Implement an intelligent, context-aware tool recommendation and filtering system across the PaperPilot Desktop interface:
1. Dynamically adapt available/spotlighted tools based on uploaded document types:
   - When Excel (.xlsx/.xls) is dropped: Spotlight `excel_to_json` and `excel_to_csv`.
   - When >= 2 PDFs are dropped: Spotlight both Multi-File tools (`merge`, `compare`) AND high-utility Batch Operations (`compress`, `ocr`, `pdf_to_docx`, `rotate`).
   - When a single PDF is dropped: Spotlight `compress`, `split`, `rotate`, `ocr`, `pdf_to_docx`.
2. Filter tools according to installed Feature Packs (e.g., Office Conversion Pack, OCR Models), displaying smart in-place 1-click install/enable prompts rather than obscure failures.
3. Add a contextual filter chip bar (`[ ⚡ Recommended ]`, `[ All Tools ]`, `[ PDF ]`, `[ Office ]`, `[ AI & OCR ]`) above the tool grid in both `OperationsPanel.svelte` and `+page.svelte` (Studio Hub).

Context & Architecture:
- Read `specs/054-context-aware-dynamic-tool-dispatcher/spec.md` for architectural design and constraints.
- Framework: Svelte 5 with runes (`$state`, `$derived`, `$props`).
- Tool Types & Catalog: 
  * `apps/desktop/src/lib/types/tools.ts`
  * `apps/desktop/src/lib/types/toolList.ts`
- Services: `apps/desktop/src/lib/services/toolRegistry.ts`.
- Components: `apps/desktop/src/lib/components/layout/OperationsPanel.svelte` and `apps/desktop/src/routes/+page.svelte`.
- Concurrency Constraint: Max 6 cores. All cargo commands must use `-j 6`.
- Backward Compatibility: Must maintain existing DOM IDs (`tool-btn-*`, `#operations-panel`) and classes so Playwright tests pass 100%.

PART 1: TOOL REGISTRY CAPABILITY RULES & RANKING ENGINE
================================================================================
Files to modify / create:
- `apps/desktop/src/lib/types/tools.ts`:
  1. Add `ToolConditionRule` and extend `ToolDefinition`:
     ```ts
     export interface ToolConditionRule {
       supportedExtensions: string[]; // ['pdf'], ['xlsx', 'xls', 'csv'], ['docx'], or ['*']
       minDocuments?: number;         // e.g. merge requires >= 2
       maxDocuments?: number;
       requiredPack?: 'core' | 'office' | 'ocr' | 'dev';
       isBatchable?: boolean;         // Supports batch execution across multiple files
     }

     export interface ToolDefinition {
       id: string;
       title: string;
       description: string;
       icon: string;
       category: 'quick' | 'pages' | 'edit' | 'optimize' | 'security' | 'convert' | 'ai';
       context: 'pdf' | 'office' | 'ai';
       tags: string[];
       rule?: ToolConditionRule;
     }
     ```

- `apps/desktop/src/lib/types/toolList.ts`:
  2. Populate `rule` metadata for tools in `allTools`:
     - `compress`, `rotate`, `ocr`, `pdf_to_docx`, `watermark`: `rule: { supportedExtensions: ['pdf'], isBatchable: true }`
     - `split`, `delete_pages`, `reorder_pages`: `rule: { supportedExtensions: ['pdf'], maxDocuments: 1 }`
     - `merge`, `compare`: `rule: { supportedExtensions: ['pdf'], minDocuments: 2 }`
     - `excel_to_json`, `excel_to_csv`: `rule: { supportedExtensions: ['xlsx', 'xls', 'csv'], requiredPack: 'office', isBatchable: true }`
     - `office_to_markdown`, `office_extract_text`: `rule: { supportedExtensions: ['docx', 'xlsx', 'pptx'], requiredPack: 'office', isBatchable: true }`
     - `office_modernize_legacy`: `rule: { supportedExtensions: ['doc', 'xls', 'ppt'], requiredPack: 'office', isBatchable: true }`
     - `json_to_pdf`, `img_to_pdf`, `md_to_pdf`: `rule: { supportedExtensions: ['*'], minDocuments: 0 }`

- `apps/desktop/src/lib/services/toolRegistry.ts`:
  3. Implement ranking and classification function:
     ```ts
     export interface RankedToolsResult {
       recommended: ToolDefinition[];
       available: ToolDefinition[];
       packLocked: { tool: ToolDefinition; missingPack: string }[];
     }

     export function rankToolsByContext(
       tools: ToolDefinition[],
       documents: File[],
       activePacks: string[]
     ): RankedToolsResult
     ```
     - Rules:
       * If documents have `.xlsx` or `.xls`: recommend `excel_to_json` and `excel_to_csv`.
       * If documents count >= 2 and all are `.pdf`:
         - Recommend Multi-File Operations: `merge` and `compare`.
         - Recommend Batch Operations: `compress`, `ocr`, `pdf_to_docx`, and `rotate`.
       * If single `.pdf`: recommend `compress`, `split`, `rotate`, `ocr`, and `pdf_to_docx`.
       * If no documents loaded: recommend creation tools (`img_to_pdf`, `json_to_pdf`, `md_to_pdf`).
       * If a tool requires `requiredPack` that is not in `activePacks`, place in `packLocked`.

PART 2: OPERATIONS PANEL & STUDIO HUB UI INTEGRATION
================================================================================
Files to modify:
- `apps/desktop/src/lib/components/layout/OperationsPanel.svelte`:
  1. Integrate `rankToolsByContext` reactively using Svelte 5 runes:
     ```ts
     let activePackIds = $derived(
       appState.featurePacks.filter((p: any) => p.is_enabled).map((p: any) => p.id)
     );
     let ranked = $derived(
       rankToolsByContext(allTools, appState.documents, activePackIds)
     );
     ```
  2. Add Context Filter Chip Bar:
     - Chips: `⚡ Recommended (${ranked.recommended.length})`, `All (${allTools.length})`, `PDF`, `Office`, `AI`.
     - When multiple files are loaded (>= 2):
       - Tools with `minDocuments: 2` (Merge/Compare) show badge `Multi-File Action`.
       - Tools with `isBatchable: true` show badge `Batch Action (N files)`.
  3. Missing Feature Pack Warning/Enable Button:
     - For tools in `ranked.packLocked`, display a clean inline card:
       `📦 Requires ${missingPack} Pack • [Enable Pack in 1-Click]`
     - Clicking executes `appState.toggleFeaturePack(missingPack, true)`.

- `apps/desktop/src/routes/+page.svelte` (Studio Hub Layout):
  4. In the Studio Hub view, display the `⚡ Recommended` operations section at the very top of the operations grid whenever files are loaded, with appropriate badges (`Multi-File Action` vs `Batch Action`).
