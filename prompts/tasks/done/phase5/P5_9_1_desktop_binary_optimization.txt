### B. Pure-Rust Inference Engine (`rten`) Migration & Model Conversion
1. In `paperpilot-nlp/Cargo.toml`, replace `ort` with `rten` (version matching `Cargo.lock` ~0.21.0) and `rten-tensor`.
2. **Model Conversion Guideline (Crucial)**:
   - Convert from `tools/train-nlp/output/tinybert.onnx` (the unquantized FP32 model) instead of `tinybert_int8.onnx`:
     ```bash
     rten-convert tools/train-nlp/output/tinybert.onnx tools/train-nlp/output/tinybert.rten
     zstd -19 tools/train-nlp/output/tinybert.rten -o tools/train-nlp/output/tinybert.rten.zst
     ```
   - **Why FP32 instead of INT8**: `rten` SIMD engine does not support Microsoft ONNX Runtime's custom INT8 MatMul quantization scale/zero-point operators (`OperatorError: MatMul_quant_output_scale_mul UnsupportedType`). The unquantized FP32 TinyBERT model is small (~14MB, ~4MB with zstd), executes sub-2ms, and avoids all quantization tensor type errors.
   - Committing the converted model artifact to `tools/train-nlp/output/tinybert.rten.zst` is authorized under the `tools/train-nlp/` ownership rule.
3. Update `paperpilot-nlp/src/layer2.rs` so `predict(&self, query: &str) -> Option<Intent>` executes in memory using `rten::Model::load_bytes` (decompressed via `zstd`).
4. Ensure all NLP unit and integration tests pass:
   ```bash
   cargo test -p paperpilot-nlp -j 2
   ```
