### Objective
Migrate the 1-hour sustained soak, stress, and endurance benchmark harness from Python (`scripts/stress_test.py`) to a dedicated, high-performance pure-Rust binary (`tools/soak-bench`), eliminating Python runtime dependencies and enabling sub-microsecond latency measurement and cross-platform RSS memory telemetry.

### Detailed Scope & Context
Read `specs/060-pure-rust-soak-benchmark-harness/spec.md` for background.

1. **New Crate `tools/soak-bench` in Cargo Workspace**:

   - Dependencies: `clap = { version = "4.5", features = ["derive"] }`, `serde`, `serde_json`, `paperpilot-core`, `paperpilot-pdf`.

2. **Benchmark Execution Loop Across All 50 Tools**:

     - `--duration <SECONDS>` (default: 3600)
