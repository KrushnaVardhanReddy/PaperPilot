# Task P5_9_43: Tool Disambiguation & Explicit Input/Output Format Badges Across Desktop Studio
# Associated Spec: specs/066-tool-format-badges-and-disambiguation/spec.md
# Priority: High
# Target Branch: main

### Objective
Disambiguate tool titles across PaperPilot's desktop application (resolving confusing overlapping names like "Extract Plain Text", "Extract Text", "Extract Pages") and introduce high-contrast, explicit `INPUT ➔ OUTPUT` format badges on all 50+ tool cards so users immediately know which file formats are supported and what output file will be generated.

### Detailed Scope & Context
Read `specs/066-tool-format-badges-and-disambiguation/spec.md` for full background and specifications.

---

### Concrete Implementation Steps

#### 1. TypeScript Interface Update (`apps/desktop/src/lib/types/tools.ts`)
Add `inputFormat` and `outputFormat` to the `ToolDefinition` interface:
```typescript
export interface ToolDefinition {
  id: string;
  title: string;
  description: string;
  icon: string;
  category: 'quick' | 'pages' | 'edit' | 'optimize' | 'security' | 'convert' | 'ai';
  context: 'pdf' | 'office' | 'ai';
  tags: string[];
  inputFormat: string;   // e.g. "PDF", "Office (DOCX/XLSX/PPTX)", "Scanned PDF / Images"
  outputFormat: string;  // e.g. ".TXT", ".DOCX", ".PDF", "PNG Images", ".JSON"
  rule?: ToolConditionRule;
}
```
