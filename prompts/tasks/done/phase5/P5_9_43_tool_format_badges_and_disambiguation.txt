# Task P5_9_43: Universal Penta-Interface Tool Disambiguation & Explicit Input/Output Format Badges
# Associated Spec: specs/066-tool-format-badges-and-disambiguation/spec.md
# Priority: High
# Target Branch: main

### Objective
Disambiguate tool titles and declare explicit `[Input: ... | Output: ...]` format boundaries across ALL of PaperPilot's interfaces (Desktop Studio UI, MCP Server, CLI, and REST Gateway) according to the Penta-Interface Mandate.

### Detailed Scope & Context
Read `specs/066-tool-format-badges-and-disambiguation/spec.md` for complete schema and component details.

---

### Implementation Across All 4 Surfaces

#### Surface 1: Desktop Studio UI (`apps/desktop`)
1. **Interface (`apps/desktop/src/lib/types/tools.ts`)**:
   - Add `inputFormat: string;` and `outputFormat: string;` to `ToolDefinition`.

2. **Catalog Disambiguation (`apps/desktop/src/lib/types/toolList.ts`)**:
   - Update `allTools` with unambiguous titles and format tags:
     - `extract_text` $\to$ `"PDF to Plain Text"`, `inputFormat: "PDF"`, `outputFormat: ".TXT"`
     - `office_extract_text` $\to$ `"Office to Plain Text"`, `inputFormat: "DOCX, XLSX, PPTX"`, `outputFormat: ".TXT"`
     - `extract_pages` $\to$ `"Extract PDF Pages"`, `inputFormat: "PDF"`, `outputFormat: ".PDF"`
     - `extract_images` $\to$ `"Extract Embedded Images"`, `inputFormat: "PDF"`, `outputFormat: "PNG Images"`
     - `ocr` $\to$ `"OCR Text Recognition"`, `inputFormat: "Scanned PDF / Image"`, `outputFormat: ".TXT / PDF"`
     - Add matching `inputFormat` & `outputFormat` to all other conversion, page, security, and optimization tools.

3. **UI Rendering (`OperationsPanel.svelte` & `+page.svelte`)**:
   - In both search results and category grids, render the format badge:
     ```svelte
     <div class="tool-card-title-row">
       <span class="tool-card-title">{tool.title}</span>
       {#if tool.inputFormat && tool.outputFormat}
         <span class="format-pill">
           <span class="fmt-in">{tool.inputFormat}</span>
           <span class="fmt-arrow">➔</span>
           <span class="fmt-out">{tool.outputFormat}</span>
         </span>
       {/if}
     </div>
     ```
   - Add CSS for `.tool-card-title-row`, `.format-pill`, `.fmt-in`, `.fmt-arrow`, and `.fmt-out`.
