# Task 5.9.90: Baseline Integrity & Pre-Sign Tamper Detection (`pdf_validate_signatures --baseline`)

## Context & Objectives
You are implementing **Task 5.9.90 (Spec 101)**: Extending PaperPilot's digital signature validation engine (`pdf_validate_signatures`) to perform pre-sign baseline tamper detection when an optional `--baseline <baseline_pdf>` is provided.

### The Problem
Standard digital signature verification (PKCS#7 / CMS) proves that a document was not modified *after* it was signed. However, if an adversarial counterparty modifies clauses, terms, or interest rates in a contract *before* signing, the cryptographic signature remains 100% valid.
Spec 101 solves this by allowing users and systems to provide the authoritative original baseline document. PaperPilot performs a dual-layer audit in one operation:
1. **Cryptographic Validation**: Validates PKCS#7 / CMS signatures, byte ranges, certificates, and post-signing alterations.
2. **Baseline Structural & Semantic Integrity**: Compares document page counts, `/Contents` text streams, and structure against the baseline document.

## Detailed Implementation Requirements

### 1. Data Structures (`paperpilot-pdf/src/operations/pdf_validate_signatures.rs`)

Update the options and report structs:

```rust
#[derive(Debug, Clone, Serialize, Deserialize, Default)]
pub struct PdfValidateSignaturesOptions {
    /// Optional path to baseline reference PDF
    #[serde(default)]
    pub baseline_path: Option<String>,
    /// Optional raw bytes of baseline reference PDF (for WASM / API memory workflows)
    #[serde(default)]
    pub baseline_bytes: Option<Vec<u8>>,
    /// If true, verify byte range only without full certificate chain inspection
    #[serde(default)]
    pub verify_byte_range_only: bool,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct BaselineComparisonReport {
    /// True if baseline was provided and compared
    pub baseline_checked: bool,
    /// True if all content streams and text match the baseline
    pub baseline_match: bool,
    /// High-level verdict: "UNTOUCHED_JUST_SIGNED" | "CONTENT_ALTERED_PRIOR_TO_SIGNATURE"
    pub verdict: String,
    /// Page numbers (1-indexed) containing text, stream, or layout differences
    pub altered_pages: Vec<u32>,
    /// Human-readable list of detected changes
    pub diff_summary: Vec<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SignatureValidationReport {
    pub total_signatures: usize,
    pub valid_signatures: usize,
    pub all_valid: bool,
    pub signatures: Vec<DigitalSignatureInfo>,
    /// Baseline comparison result (populated only when baseline is provided)
    #[serde(skip_serializing_if = "Option::is_none")]
    pub baseline_report: Option<BaselineComparisonReport>,
}
```

### 2. Implementation Logic in `pdf_validate_signatures_bytes`

In `paperpilot-pdf/src/operations/pdf_validate_signatures.rs`:

1. **Resolve Baseline Bytes**:
   - Check `options.baseline_bytes`.
   - If not present but `options.baseline_path` is given:
     - Read file bytes with fallback for relative paths (`path` or `../path`).
   - If neither is provided, `report.baseline_report = None` (preserves backward compatibility).

2. **When Baseline is Provided**:
   - Load `baseline_doc = Document::load_mem(&baseline_bytes)`.
   - Initialize `BaselineComparisonReport`:
     ```rust
     let mut baseline_report = BaselineComparisonReport {
         baseline_checked: true,
         baseline_match: true,
         verdict: "UNTOUCHED_JUST_SIGNED".to_string(),
         altered_pages: Vec::new(),
         diff_summary: Vec::new(),
     };
     ```
   - **Check Page Counts**:
     - `signed_page_count = doc.get_pages().len()`
     - `baseline_page_count = baseline_doc.get_pages().len()`
     - If counts differ:
       - `baseline_report.baseline_match = false;`
       - `baseline_report.verdict = "CONTENT_ALTERED_PRIOR_TO_SIGNATURE".to_string();`
       - `baseline_report.diff_summary.push(format!("Page count mismatch: baseline has {}, signed document has {}", baseline_page_count, signed_page_count));`
   - **Check Page Contents Streams (Tier 1 SHA-256 + Tier 2 Content Diff)**:
     - For each page index `p` in `1..=std::cmp::min(signed_page_count, baseline_page_count)`:
       - Extract raw `/Contents` streams of signed page and baseline page.
         *(Note: In `lopdf`, a page's `/Contents` can be a single stream object reference or an array of stream references; extract and concatenate the stream data bytes).*
       - If the byte contents match identically: page content is untouched.
       - If byte contents differ:
         - Inspect whether differences are solely standard signature widgets / annotations or actual text stream modifications.
         - If text content or non-signature graphics differ:
           - Push page number `p as u32` to `baseline_report.altered_pages`.
           - Push explanatory message to `baseline_report.diff_summary` (e.g. `format!("Page {}: text content stream was altered prior to signing", p)`).
           - Set `baseline_report.baseline_match = false;`
           - Set `baseline_report.verdict = "CONTENT_ALTERED_PRIOR_TO_SIGNATURE".to_string();`
   - Attach `baseline_report` to `report.baseline_report = Some(baseline_report);`.
