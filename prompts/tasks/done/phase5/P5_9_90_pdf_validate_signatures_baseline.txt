# Task 5.9.90: Baseline Integrity & Pre-Sign Tamper Detection (`pdf_validate_signatures --baseline`)

## Context & Objectives
You are implementing **Task 5.9.90 (Spec 101)**: Extending PaperPilot's digital signature validation engine (`pdf_validate_signatures`) to perform pre-sign baseline tamper detection when an optional `--baseline <baseline_pdf>` is provided.

### The Problem & Solution
Standard digital signature verification (PKCS#7 / CMS) proves that a document was not modified *after* it was signed. However, if an adversarial counterparty modifies clauses, terms, or interest rates in a contract *before* signing, the cryptographic signature remains 100% valid.
Spec 101 solves this by allowing users to provide the authoritative original baseline document. PaperPilot performs a dual-layer audit in one operation:
1. **Cryptographic Validation**: Validates PKCS#7 / CMS signatures, byte ranges, certificates, and post-signing alterations.
2. **Baseline Structural & Semantic Integrity**: Compares document page counts, `/Contents` text streams, and structure against the baseline document.

#### Data Structures:
Update the options and report structs:
```rust
#[derive(Debug, Clone, Serialize, Deserialize, Default)]
pub struct PdfValidateSignaturesOptions {
    /// Optional path to baseline reference PDF
    #[serde(default)]
    pub baseline_path: Option<String>,
    /// Optional raw bytes of baseline reference PDF (for WASM / API memory workflows)
    #[serde(default)]
    pub baseline_bytes: Option<Vec<u8>>,
    /// If true, verify byte range only without full certificate chain inspection
    #[serde(default)]
    pub verify_byte_range_only: bool,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct BaselineComparisonReport {
    /// True if baseline was provided and compared
    pub baseline_checked: bool,
    /// True if all content streams and text match the baseline
    pub baseline_match: bool,
    /// High-level verdict: "UNTOUCHED_JUST_SIGNED" | "CONTENT_ALTERED_PRIOR_TO_SIGNATURE"
    pub verdict: String,
    /// Page numbers (1-indexed) containing text, stream, or layout differences
    pub altered_pages: Vec<u32>,
    /// Human-readable list of detected changes
    pub diff_summary: Vec<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SignatureValidationReport {
    pub total_signatures: usize,
    pub valid_signatures: usize,
    pub all_valid: bool,
    pub signatures: Vec<DigitalSignatureInfo>,
    /// Baseline comparison result (populated only when baseline is provided)
    #[serde(skip_serializing_if = "Option::is_none")]
    pub baseline_report: Option<BaselineComparisonReport>,
}
```

#### Core Logic in `pdf_validate_signatures_bytes(input_bytes: &[u8], options: &PdfValidateSignaturesOptions)`:
1. Resolve baseline bytes:
   ```rust
   let baseline_bytes_opt: Option<Vec<u8>> = if let Some(ref bytes) = options.baseline_bytes {
       Some(bytes.clone())
   } else if let Some(ref path) = options.baseline_path {
       std::fs::read(path)
           .or_else(|_| std::fs::read(format!("../{}", path)))
           .ok()
   } else {
       None
   };
   ```
2. If `baseline_bytes_opt` is `Some(ref b_bytes)`:
   - Load `baseline_doc = Document::load_mem(b_bytes).map_err(|e| PdfError::ParseError(e.to_string()))?`.
   - Initialize `BaselineComparisonReport`:
     ```rust
     let mut baseline_report = BaselineComparisonReport {
         baseline_checked: true,
         baseline_match: true,
         verdict: "UNTOUCHED_JUST_SIGNED".to_string(),
         altered_pages: Vec::new(),
         diff_summary: Vec::new(),
     };
     ```
   - Compare page counts:
     ```rust
     let signed_pages = doc.get_pages();
     let baseline_pages = baseline_doc.get_pages();
     let signed_count = signed_pages.len();
     let baseline_count = baseline_pages.len();
     if signed_count != baseline_count {
         baseline_report.baseline_match = false;
         baseline_report.verdict = "CONTENT_ALTERED_PRIOR_TO_SIGNATURE".to_string();
         baseline_report.diff_summary.push(format!(
             "Page count mismatch: baseline has {}, signed document has {}",
             baseline_count, signed_count
         ));
     }
     ```
   - Compare page contents streams:
     Helper to extract page stream bytes in `lopdf`:
     ```rust
     fn extract_page_contents(doc: &Document, page_id: ObjectId) -> Vec<u8> {
         let mut bytes = Vec::new();
         if let Ok(page_dict) = doc.get_dictionary(page_id) {
             if let Ok(contents) = page_dict.get(b"Contents") {
                 match contents {
                     lopdf::Object::Reference(r) => {
                         if let Ok(stream) = doc.get_object(*r).and_then(|o| o.as_stream()) {
                             bytes.extend_from_slice(&stream.content);
                         }
                     }
                     lopdf::Object::Array(arr) => {
                         for item in arr {
                             if let Ok(r) = item.as_reference() {
                                 if let Ok(stream) = doc.get_object(r).and_then(|o| o.as_stream()) {
                                     bytes.extend_from_slice(&stream.content);
                                 }
                             }
                         }
                     }
                     _ => {}
                 }
             }
         }
         bytes
     }
     ```
   - For each 1-indexed page `p` up to `min(signed_count, baseline_count)`:
     - Compare extracted stream bytes. If they differ:
       ```rust
       baseline_report.baseline_match = false;
       baseline_report.verdict = "CONTENT_ALTERED_PRIOR_TO_SIGNATURE".to_string();
       baseline_report.altered_pages.push(p as u32);
       baseline_report.diff_summary.push(format!("Page {}: content stream modified prior to signature", p));
       ```
   - Attach: `report.baseline_report = Some(baseline_report);`.

```rust
pub fn handle_pdf_validate_signatures_command(
    input: &PathBuf,
    output: &PathBuf,
    baseline: Option<&PathBuf>,
) -> Result<(), PdfError> {
    let input_bytes = std::fs::read(input).map_err(PdfError::IoError)?;
    let mut options = paperpilot_pdf::operations::pdf_validate_signatures::PdfValidateSignaturesOptions::default();
    if let Some(b) = baseline {
        options.baseline_path = Some(b.to_string_lossy().to_string());
    }
    let output_bytes = paperpilot_pdf::operations::pdf_validate_signatures::pdf_validate_signatures_bytes(
        &input_bytes,
        &options,
    ).map_err(|e| PdfError::Other(e.to_string()))?;
    std::fs::write(output, output_bytes).map_err(PdfError::IoError)?;
    println!("PdfValidateSignatures complete.");
    Ok(())
}
```

   *(Keep `required` as only `["input", "output"]`).*

2. **In `execute_call_tool` match arm `"pdf_validate_signatures"`**:
   ```rust
   "pdf_validate_signatures" => {
       let input = get_string("input")?;
       let output = get_string("output")?;
       ensure_parent_dir(&output)?;
       
       let baseline = args.get("baseline").and_then(|v| v.as_str()).map(|s| s.to_string());

       let input_bytes = std::fs::read(&input)
           .map_err(|e| rmcp::ErrorData::internal_error(e.to_string(), None))?;
       let mut options = paperpilot_pdf::operations::pdf_validate_signatures::PdfValidateSignaturesOptions::default();
       options.baseline_path = baseline;
       
       let result = paperpilot_pdf::operations::pdf_validate_signatures::pdf_validate_signatures_bytes(&input_bytes, &options)
           .map_err(|e| rmcp::ErrorData::internal_error(e.to_string(), None))?;

       std::fs::write(&output, result)
           .map_err(|e| rmcp::ErrorData::internal_error(e.to_string(), None))?;

       Ok(OperationResult {
           data: Some(serde_json::json!({ "output_path": output })),
           success: true,
           message: "Validate Digital Signatures executed successfully".to_string(),
           output_path: Some(output),
           diff_detected: None,
       })
   }
   ```
