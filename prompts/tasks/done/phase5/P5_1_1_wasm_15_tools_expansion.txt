## 1. Implementation Details: `paperpilot-wasm/src/operations.rs`

### A. `images_to_pdf`
```rust
pub fn images_to_pdf(image_buffers: &[&[u8]]) -> OperationResult<Vec<u8>>
```
- Decodes image bytes using `image::load_from_memory`.
- Encodes frames into PDF image XObjects.
- Appends each image as a full-bleed page in a newly created or loaded `lopdf::Document`.
- Serializes document to a `Vec<u8>` buffer.

### B. `extract_images`
```rust
pub fn extract_images(input_bytes: &[u8]) -> OperationResult<Vec<Vec<u8>>>
```
- Traverses document page dictionaries and `/Resources` -> `/XObject`.
- Filters for `/Subtype /Image`.
- Extracts raw stream bytes, formats as PNG/JPEG buffers, and returns an array of image byte arrays.

### C. `pdf_hash`
```rust
pub fn pdf_hash(input_bytes: &[u8]) -> OperationResult<String>
```
- Uses `sha2::Sha256` to compute the SHA-256 hex digest of the raw byte slice.
- Returns formatted hex string.
