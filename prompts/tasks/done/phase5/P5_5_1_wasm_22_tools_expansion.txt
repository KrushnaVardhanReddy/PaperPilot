Expand `paperpilot-wasm`, `apps/web/`, and `apps/edge/` from the current 15 tools to **22 tools** by re-exporting and integrating pure-Rust capabilities that already landed in `paperpilot-pdf`:
1. `render_page` (PDF page to PNG rasterization via `hayro` + `tiny-skia` landed in PR #142)
2. `extract_text` (Pure-Rust text extraction directly from PDF content streams via `lopdf`)
3. `decrypt` (Decrypt password-protected PDFs with user/owner password)
4. `page_numbers` (Add dynamic "Page X of Y" numbering to pages)
5. `header_footer` (Add header/footer text overlays with customizable positioning)
6. `pdf_info` / `validate` (Extract metadata, page count, PDF version, encryption status)
7. `ocr` (Pure-Rust OCR text extraction via `ocrs` and `rten` SIMD neural runtime landed in PR #141)

This fulfills Phase 5.5.1 and elevates PaperPilot's in-browser and Cloudflare Edge capability from 15 to **22 fully client-side tools**.

## 1. Rust Implementation Details (`paperpilot-wasm`)

### Dependencies to add to `paperpilot-wasm/Cargo.toml`:
```toml
hayro = { version = "0.7.2", default-features = false }
hayro-syntax = { version = "0.7.2", default-features = false }
tiny-skia = { version = "0.11", default-features = false, features = ["simd", "std"] }
bytemuck = "1.25.0"
ocrs = { version = "0.10.0", default-features = false }
rten = { version = "0.14.0", default-features = false }
```

### New Operations in `paperpilot-wasm/src/operations.rs`:

1. **`render_page(input_bytes: &[u8], page_index: u32, scale: f32) -> OperationResult<Vec<u8>>`**
   - Parse `input_bytes` with `hayro_syntax::Pdf`.
   - Render page at `page_index` (0-indexed) with `hayro::render`.
   - Draw into `tiny_skia::Pixmap` and encode as PNG bytes.
   - Return raw PNG `Vec<u8>`.

2. **`extract_text(input_bytes: &[u8]) -> OperationResult<String>`**
   - Parse `input_bytes` with `lopdf::Document::load_mem`.
   - Iterate through pages, extract `/Contents` streams, decode `Tj` / `TJ` text operators into a clean UTF-8 string.

3. **`decrypt(input_bytes: &[u8], password: &str) -> OperationResult<Vec<u8>>`**
   - Load PDF, authenticate with password, decrypt streams/dictionaries, and save unencrypted PDF bytes.

4. **`page_numbers(input_bytes: &[u8], format: &str, position: &str) -> OperationResult<Vec<u8>>`**
   - Inject text streams at bottom-center / bottom-right with dynamic "Page {n} of {total}".

5. **`header_footer(input_bytes: &[u8], header: &str, footer: &str) -> OperationResult<Vec<u8>>`**
   - Inject header and footer text operators onto target pages.

6. **`pdf_info(input_bytes: &[u8]) -> OperationResult<String>`**
   - Inspect page count, version, encryption, author, title, and return a JSON string:
     `{"page_count": 5, "version": "1.7", "encrypted": false, "title": "..."}`.

7. **`ocr(image_or_pdf_bytes: &[u8]) -> OperationResult<String>`**
   - Decode input pixels, run `ocrs::OcrEngine`, extract text boxes and return recognized text.
