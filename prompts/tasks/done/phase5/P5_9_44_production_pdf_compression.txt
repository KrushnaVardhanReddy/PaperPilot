## 1. Requirements & Features

### A. Compression Implementation (`paperpilot-pdf/src/operations/compress.rs`)
1. **Quality Presets**:
   - Parse `quality`:
     - `"low"` / `"screen"` -> max dimension 1024, JPEG quality 40.
     - `"medium"` / `"ebook"` (default) -> max dimension 1600, JPEG quality 60.
     - `"high"` / `"prepress"` -> max dimension 2400, JPEG quality 80.
     - Numeric strings (e.g. `"75"`) -> mapped to JPEG quality number, max dimension 1600.
2. **Image Stream Processing**:
   - Iterate over all stream objects in `lopdf_doc.inner.objects`.
   - If `/Subtype /Image`:
     - Decompress using `stream.decompressed_content()`.
     - Decode image with `image::load_from_memory` (or reconstruct RGB/Gray buffer).
     - Downsample with `image::imageops::FilterType::Triangle` if dimensions exceed `max_dim`.
     - Re-encode as JPEG with `JpegEncoder::new_with_quality`.
     - Replace stream bytes **only if** new JPEG size is strictly less than original size.
3. **Flate Stream Compression**:
   - For all stream objects that are not images:
     - Check if `/Filter` dictionary entry is absent or uncompressed.
     - If uncompressed, compress stream contents using `flate2::write::ZlibEncoder`.
     - Set `/Filter` to `/FlateDecode`.
4. **Pruning & Modern Packing**:
   - Call `lopdf_doc.inner.prune_objects()` to eliminate unreferenced/dead objects.
   - Call `lopdf_doc.inner.compress()`.

### B. Unit & Fixture Tests
