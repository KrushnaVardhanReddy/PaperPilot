## 2. Test Execution Details

### A. Rust Integration Tests (`tests/e2e/test_wave2_penta_interface.rs` or `paperpilot-mcp/tests/`)
1. **MCP Server**: Invoke `PaperPilotMcpServer::execute_call_tool(params)` for all 6 tools with real disk fixtures. Verify JSON response `success: true` and validate output files on disk. (Reference: see `paperpilot-mcp/tests/wave2_mcp_tests.rs`).
2. **CLI**: Execute the compiled binary (`target/debug/paperpilot` or `paperpilot-cli`) using `std::process::Command` passing CLI arguments (e.g. `paperpilot burst`, `paperpilot search`, `paperpilot page-numbers`).
3. **REST Gateway**: Use `axum::test` or `reqwest` against `paperpilot-gateway` endpoints (e.g. `/api/v1/pdf/search`, `/api/v1/pdf/burst`).

### B. Playwright Browser / Web Worker WASM Test (`apps/web/tests/e2e_wave2_wasm.spec.ts`)
Run headless Chromium through Playwright testing client-side execution:
1. Load `single_page.pdf` and image fixtures.
2. Evaluate through `page.evaluate()` calling the Web Worker / WASM client.
3. Assert that resulting buffers have valid `%PDF-` magic bytes and images extract cleanly.
