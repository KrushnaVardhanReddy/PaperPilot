# Task P5_9_41: Clean-Room E2E Verification & Audit for All 50 Tools
# Associated Spec: specs/064-all-50-tools-cleanroom-audit/spec.md
# Priority: High
# Target Branch: main

### Objective
Expand the automated clean-room audit test runner from the Top 12 tools to all 50 PaperPilot tools. Each run must execute in a freshly created, timestamped isolation sandbox directory, verifying real input files, verifying real output files on disk, updating the Makefile with convenience test targets, and producing a detailed Markdown scorecard (`reports/ALL_50_TOOLS_CLEANROOM_AUDIT_REPORT.md`).

### Detailed Scope & Context
Read `specs/064-all-50-tools-cleanroom-audit/spec.md` for full background and the exact 50-tool validation matrix.

1. **Clean-Room Sandbox Isolation**:
   - The test must create a brand-new directory: `tests/e2e_fixtures/out/all50_audit_<timestamp>/`.
   - Stale outputs from prior runs must never be touched or checked.
   - If output directory exists from a prior test, wipe and recreate it.

   23. `pdf_page_numbers`: Input `multi_page.pdf` with format `{n}/{total}` → Output `page_numbers.pdf` → Validate "1/5".
   24. `pdf_extract_text`: Input `single_page.pdf` → Output `extracted.txt` → Validate text > 0 bytes without binary garbage.
   25. `pdf_extract_images`: Input `multimodal.pdf` → Output directory with extracted PNG/JPEG files starting with valid image magic bytes.

### Constraints & Rules
- Concurrency bounded: strictly `-j 2` during compilation and testing to keep CPU load low.
- Zero mocked passes: all 50 tools must execute the real engine on real disk files.
- NEVER run `git reset`, `git checkout -- .`, `git restore`, or `git clean -fd`.
- Preserved fixtures: Use `tests/e2e_fixtures/real/test.xlsx` for Excel tools, `tests/e2e_fixtures/real/encrypted.pdf` for decrypt.
