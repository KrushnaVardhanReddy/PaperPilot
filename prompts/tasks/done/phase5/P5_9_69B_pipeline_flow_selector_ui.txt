## ⚠️ CRITICAL IMPLEMENTATION DETAILS (Do Not Miss)

### 1. Storage & Preset Initialization in Components:
In `pipeline.svelte.ts`, `pipelineState.savedFlows` starts as empty `[]`. Presets are ONLY populated when `pipelineState.initStorage()` is called.
Therefore, in **`FlowSelector.svelte`** (or `PipelineView.svelte`), you MUST call `pipelineState.initStorage()` inside `onMount()`:
```svelte
<script lang="ts">
  import { onMount } from 'svelte';
  import { pipelineState } from '$lib/state/pipeline.svelte';

  onMount(() => {
    pipelineState.initStorage();
  });
</script>
```
If this is omitted, `savedFlows` has length 0, the select dropdown is empty, and `loadFlow('preset-legal-discovery')` returns false!

### 2. Svelte 5 Select Element Binding & Change Handler:
Ensure the dropdown selector triggers `pipelineState.loadFlow` on change:
```svelte
<select
  class="input-field flow-select"
  id="flow-selector-dropdown"
  value={pipelineState.activeFlowId || ''}
  onchange={(e) => {
    const val = (e.currentTarget as HTMLSelectElement).value;
    if (val) pipelineState.loadFlow(val);
  }}
>
  <option value="" disabled selected={!pipelineState.activeFlowId}>
    {pipelineState.steps.length > 0 ? "— Custom / Unsaved Pipeline —" : "Select a workflow preset..."}
  </option>
  <optgroup label="Standard Presets">
    {#each pipelineState.savedFlows.filter(f => f.isPreset) as flow (flow.id)}
      <option value={flow.id}>{flow.name} ({flow.steps.length} steps)</option>
    {/each}
  </optgroup>
  {#if pipelineState.savedFlows.some(f => !f.isPreset)}
    <optgroup label="My Saved Flows">
      {#each pipelineState.savedFlows.filter(f => !f.isPreset) as flow (flow.id)}
        <option value={flow.id}>{flow.name} ({flow.steps.length} steps)</option>
      {/each}
    </optgroup>
  {/if}
</select>
```

## 2. `FlowSelector.svelte` Toolbar Buttons
- **`💾 Save Flow`** (id `#save-flow-btn`): Disabled if `pipelineState.steps.length === 0`. Opens `SaveFlowModal.svelte`.
- **`⬇️ Export JSON`** (id `#export-flow-btn`): Disabled if `pipelineState.steps.length === 0`. Exports JSON using `pipelineState.exportFlowJson()`, triggers download.
- **`⬆️ Import JSON`** (id `#import-flow-btn`): Hidden `<input type="file" accept=".json" bind:this={fileInput} onchange={handleFileImport} style="display: none;" />`. Reads JSON file, calls `pipelineState.importFlowFromJson(text)`.
- **`🗑️ Delete Flow`** (id `#delete-flow-btn`): Visible only when active selected flow is non-preset (`!currentFlow?.isPreset`).
- **`✨ New`** (id `#new-flow-btn`): Clears canvas (`pipelineState.clearPipeline()`).
