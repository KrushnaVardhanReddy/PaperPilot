Task: Universal pdf_oxide Core Engine Migration & High-Performance Extraction Suite [Spec 040]

Objective:
Migrate and upgrade PaperPilot's text extraction, document conversion (`pdf_convert_markdown`, `pdf_convert_html`), spatial search (`pdf_search`), and RAG chunking to `pdf_oxide` (v0.3.78) for sub-1ms speed, perfect word spacing, and structured multi-column/table reconstruction.

Context & Reference:
- Read `specs/040-pdf-oxide-universal-migration/spec.md` for complete architecture and guidelines.
- Concurrency Constraint: Max 6 cores. All builds and tests must pass `-j 6` (e.g., `cargo test -p paperpilot-pdf -j 6`).
- WASM & Edge Constraint: 100% in-memory, zero C dependencies, fully compatible with `wasm32-unknown-unknown` and Cloudflare Workers (<35MB RSS).
- IMPORTANT DEPENDENCY CONFIG: Update `pdf_oxide = "0.3.78"` in `paperpilot-pdf/Cargo.toml` and `paperpilot-wasm/Cargo.toml` with `default-features = false`. (Note: omit the `"wasm"` feature if compiling against `DocumentIR` defined_names conflicts).
- IMPORTANT DESKTOP MODULARITY: `OperationsPanel.svelte` was refactored in Spec 048. Tool names must be registered in `apps/desktop/src/lib/services/toolRegistry.ts` (`resolveToolName`) and `apps/desktop/src/lib/services/operationArgsBuilder.ts`.

Implementation Steps:
1. Engine Core Integration (`paperpilot-pdf`):
   - Upgrade `PdfToMarkdownOperation` using `pdf_oxide::api::Pdf`:
     - Generate structured Markdown with headings (`#`), bold/italic (`**`), tables (`| Header |`), and de-weaved XY-Cut column flow.
   - Implement first-class `pdf_to_html` (`PdfToHtmlOperation`):
     - Generate responsive semantic HTML5 (`<article>`, `<p>`, `<table>`, embedded `<img>` tags, mobile viewport metadata, clean CSS preset).
     - Add dedicated `pdf_to_html` tool card in Desktop UI (`OperationsPanel.svelte`) and register in `apps/desktop/src/lib/services/toolRegistry.ts`.
   - Upgrade `ExtractTextOperation` (`pdf_extract_text`):
     - Leverage `pdf_oxide`'s word-spacing heuristic and layout reading order.
   - Upgrade `SearchOperation` (`pdf_search`):
     - Return bounding-box coordinates (`x`, `y`, `width`, `height`) for term occurrences.
   - Add `PdfRagChunksOperation` (`pdf_rag_chunks`):
     - Output structured semantic chunks with page numbers and heading context for LLM/RAG pipelines.

2. Penta-Interface Wiring (All 5 surfaces):
   - CLI (`paperpilot-cli`): Update `convert --format html`, `convert --format markdown`, `text`, `search`, and add `rag-chunks`.
   - MCP (`paperpilot-mcp`): Register tool declarations and handlers in `paperpilot-mcp/src/server.rs` (`pdf_to_html`, `pdf_convert_markdown`, `pdf_search`, `pdf_rag_chunks`). Update `test_execute_list_tools` tool count assertion.
   - Gateway REST (`paperpilot-gateway`): Add OpenAPI routes and handlers in `handlers.rs` and `server.rs`.
   - WASM & Cloudflare Edge (`paperpilot-wasm`, `apps/edge`): In-memory buffer support via `Pdf::from_bytes` with zero filesystem calls.

3. Verification & Quality Gates:
   - Add unit tests verifying:
     - Markdown output contains table pipes `|` when given table PDFs.
     - Multi-column reading flow does not interleave sentences.
     - Search results return valid `bbox` objects (`x`, `y`, `width`, `height`).
   - Run tests bounded with `-j 6`: `cargo test -p paperpilot-pdf -p paperpilot-mcp -p paperpilot-gateway -j 6`.
   - Ensure clean clippy: `cargo clippy --workspace --all-targets -- -D warnings`.

4. Report & Documentation:
   - Author `wiki/PDF-Oxide-Migration.md` and `reports/PDF_OXIDE_UNIVERSAL_MIGRATION_REPORT.md`.
   - Update `PHASES.md` marking Task 5.9.15 as completed.

Deliverables:
