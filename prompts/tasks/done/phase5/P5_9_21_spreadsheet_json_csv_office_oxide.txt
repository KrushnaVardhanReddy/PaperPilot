=== TASK DEFINITION: Phase 5 - Spec 046: Structured Spreadsheet Ingestion & Tabular JSON/CSV Agent Tooling via office_oxide ===

CONTEXT & OBJECTIVE:
AI agents (e.g. Claude, Cursor, OpenCode) require structured spreadsheet ingestion (.xlsx, .xls) to directly analyze financial models, inventory tables, and data matrices without external Python scripts (pandas/openpyxl) or LibreOffice.
PaperPilot already includes `office_oxide = "0.1.13"`, `calamine = "0.36.1"`, and `csv = "1.4.0"` in `paperpilot-pdf`.
We need to implement `ExcelToJsonOperation` and `ExcelToCsvOperation` across the core engine (`paperpilot-pdf`), CLI (`paperpilot-cli`), and MCP server (`paperpilot-mcp`).

DETAILED STEP-BY-STEP IMPLEMENTATION:

Step 1: Core Engine Implementation (`paperpilot-pdf/src/operations/office.rs`)
- In `paperpilot-pdf/src/operations/office.rs`, implement:
  1. `pub struct ExcelToJsonOperation;`
     - Method: `pub fn execute(input_path: &Path, sheet_name: Option<&str>, has_headers: bool) -> OperationResult<String>`
     - Implementation:
       Use `calamine::open_workbook_auto(input_path)` (or `office_oxide`).
       Iterate through sheets (or filter by `sheet_name` if specified).
       For each sheet:
       - Read rows. If empty, return empty sheet data.
       - If `has_headers` is true, take the first row cells as column header strings. Subsequent rows are serialized as JSON objects `{ "Header": value }`.
       - If `has_headers` is false, serialize rows as arrays of values.
       - Preserve cell data types: integers, floats, booleans, strings.
       - Return serialized JSON string with top-level structure:
         `{"sheets": [{"name": "Sheet1", "rows_count": N, "columns": [...], "data": [...]}]}`
  2. `pub struct ExcelToCsvOperation;`
     - Method: `pub fn execute(input_path: &Path, output_path: &Path, sheet_name: Option<&str>) -> OperationResult<()>`
     - Implementation:
       Open workbook, select target sheet (or first sheet if `sheet_name.is_none()`).
       Use `csv::Writer::from_path(output_path)` to write rows and cells.

Step 3: CLI Commands (`paperpilot-cli/src/commands/office.rs`)
- Add subcommands to `OfficeCommands`:
  ```rust
  /// Ingest Excel spreadsheet and output structured JSON
  ExcelToJson {
      #[arg(long, required = true)]
      input: PathBuf,
      #[arg(long)]
      output: Option<PathBuf>,
      #[arg(long)]
      sheet: Option<String>,
      #[arg(long)]
      no_headers: bool,
  },
  /// Export Excel spreadsheet sheet to CSV
  ExcelToCsv {
      #[arg(long, required = true)]
      input: PathBuf,
      #[arg(long, required = true)]
      output: PathBuf,
      #[arg(long)]
      sheet: Option<String>,
  },
  ```
- Wire into `handle_office_command`.
- If `output` is `None` in `ExcelToJson`, print the JSON to `stdout`.

Step 4: MCP Server Registration (`paperpilot-mcp/src/server.rs`)
