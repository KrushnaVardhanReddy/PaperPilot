### 2. Implementation Details

#### Tool Specifications for Batch 3 (Tools 21–30)
Map each tool with exact commands, inputs, and outputs in `scripts/test_tri_interface_e2e.py`:

21. **Render (`pdf_render`)**:
   - Input: `single_page.pdf`
   - Output: `out/tri_e2e/rendered.png`
   - CLI: `render --input {in} --page 1 --output {out}`
   - MCP: `{"name":"pdf_render", "arguments":{"input":in, "page":1, "output":out}}`
   - API: `POST /api/v1/pdf/render-page` with `{"input":in, "page":1}`
22. **OCR (`pdf_ocr`)**:
   - Input: `image_doc.pdf`
   - Output: `out/tri_e2e/ocr_result.pdf` (or text output)
   - CLI: `ocr --input {in} --output {out}`
   - MCP: `{"name":"pdf_ocr", "arguments":{"input":in, "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_ocr` with `{"input":in, "output":out}`
23. **Search (`pdf_search`)**:
   - Input: `search_test.pdf`
   - Output: JSON match list
   - CLI: `search --input {in} --query "test"`
   - MCP: `{"name":"pdf_search", "arguments":{"input":in, "query":"test"}}`
   - API: `POST /api/v1/pdf/tools/pdf_search` with `{"input":in, "query":"test"}`
24. **Bates Stamping (`pdf_bates`)**:
   - Input: `multi_page.pdf`
   - Output: `out/tri_e2e/bates_stamped.pdf`
   - CLI: `bates --input {in} --prefix "CONF-" --start-number 1 --padding 6 --output {out}`
   - MCP: `{"name":"pdf_bates", "arguments":{"input":in, "prefix":"CONF-", "start_number":1, "padding":6, "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_bates` with `{"input":in, "prefix":"CONF-", "start_number":1, "padding":6, "output":out}`
25. **Watermark (`pdf_watermark`)**:
   - Input: `single_page.pdf`
   - Output: `out/tri_e2e/watermarked.pdf`
   - CLI: `watermark --input {in} --text "SAMPLE" --output {out}`
   - MCP: `{"name":"pdf_watermark", "arguments":{"input":in, "text":"SAMPLE", "output":out}}`
   - API: `POST /api/v1/pdf/watermark` with `{"input":in, "text":"SAMPLE", "output":out}`
26. **Header & Footer (`pdf_header_footer`)**:
   - Input: `multi_page.pdf`
   - Output: `out/tri_e2e/header_footer.pdf`
   - CLI: `header-footer --input {in} --header-left "Confidential" --footer-center "Page" --output {out}`
   - MCP: `{"name":"pdf_header_footer", "arguments":{"input":in, "header_left":"Confidential", "footer_center":"Page", "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_header_footer` with `{"input":in, "header_left":"Confidential", "footer_center":"Page", "output":out}`
27. **Read Form (`pdf_read_form`)**:
   - Input: `form.pdf`
   - Output: JSON form fields map
   - CLI: `read-form --input {in}`
   - MCP: `{"name":"pdf_read_form", "arguments":{"input":in}}`
   - API: `POST /api/v1/pdf/tools/pdf_read_form` with `{"input":in}`
28. **Fill Form (`pdf_fill_form`)**:
   - Input: `form.pdf`
   - Output: `out/tri_e2e/filled_form.pdf`
   - CLI: `fill-form --input {in} --data '{"first_name":"Alice"}' --output {out}`
   - MCP: `{"name":"pdf_fill_form", "arguments":{"input":in, "fields":{"first_name":"Alice"}, "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_fill_form` with `{"input":in, "fields":{"first_name":"Alice"}, "output":out}`
29. **Create Form Field (`pdf_create_form_field`)**:
   - Input: `single_page.pdf`
   - Output: `out/tri_e2e/field_added.pdf`
   - CLI: `create-form-field --input {in} --field-type text --field-name "signature" --x 50 --y 50 --width 150 --height 30 --output {out}`
   - MCP: `{"name":"pdf_create_form_field", "arguments":{"input":in, "field_type":"text", "field_name":"signature", "x":50, "y":50, "width":150, "height":30, "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_create_form_field` with `{"input":in, "field_type":"text", "field_name":"signature", "x":50, "y":50, "width":150, "height":30, "output":out}`
30. **Metadata (`pdf_metadata`)**:
   - Input: `single_page.pdf`
   - Output: JSON document metadata
   - CLI: `metadata --input {in}`
   - MCP: `{"name":"pdf_metadata", "arguments":{"input":in}}`
   - API: `POST /api/v1/pdf/info` with `{"input":in}`
