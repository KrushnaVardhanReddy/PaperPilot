## Requirements

### 1. Realistic Legal Mock Corpus Generator
Create a fixture generator (in `demo/legal_discovery/` or invoked within the runner):
- `01_asset_purchase_agreement.pdf`: 4-page agreement with text including `SSN: 987-65-4321` and `Routing: 021000021`.
- `02_disclosure_schedules_tilted.pdf`: 3-page schedule with page 2 rotated 90 degrees (`/Rotate 90`).
- `03_unredacted_financial_exhibit.pdf`: 2-page exhibit with confidential financial tables.

### 2. Demo Execution Runner (`scripts/run_ai_legal_demo.sh`)
Create an executable shell script `scripts/run_ai_legal_demo.sh` (with `chmod +x`):
1. Locate or build `paperpilot` binary (`cargo build -p paperpilot-cli`).
2. Generate input fixtures if missing.
3. Print colorized, professional CLI output simulating an Autonomous AI Agent solving a legal discovery mandate:
   - 🔄 Step 1: Detect orientation and rotate page 2 of `02_disclosure_schedules_tilted.pdf` (`paperpilot rotate`).
   - ✂️ Step 2: Redact sensitive SSN & routing numbers from `01_asset_purchase_agreement.pdf` (`paperpilot redact`).
   - 🏷️ Step 3: Sequentially Bates-stamp all three documents (`DISCOVERY-2026-000001` through `000009`) (`paperpilot bates`).
   - 📑 Step 4: Merge sanitized exhibits into a single master courtroom bundle (`paperpilot merge`).
   - 🛡️ Step 5: Apply protective order watermark `CONFIDENTIAL - ATTORNEYS EYES ONLY` (`paperpilot watermark`).
   - ⚡ Step 6: Web-linearize for fast browser preview (`paperpilot linearize`).
   - 🔒 Step 7: Generate tamper-evident SHA-256 audit digest (`paperpilot hash`).
4. Output the final PDF to `demo/legal_discovery/output/final_court_bundle.pdf`.
5. Display an ASCII benchmark scorecard with per-step latency and total execution time (<500ms).

### 3. Makefile Integration
Add to `Makefile`:
```makefile
.PHONY: demo-legal-discovery

demo-legal-discovery:
	./scripts/run_ai_legal_demo.sh
```
