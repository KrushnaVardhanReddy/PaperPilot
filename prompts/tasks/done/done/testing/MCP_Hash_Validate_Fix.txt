# Task: Implement Missing MCP Handlers & Fix Schema Descriptions

## Context
We are trying to get the `paperpilot-mcp` E2E tests to 100% pass rate. Antigravity has already fixed the 17 Python test script bugs, but we still have two missing tools and a bunch of schema issues in the Rust server.

## Objective
1. **Implement `pdf_hash` and `pdf_validate` Handlers**: In `paperpilot-mcp/src/server.rs`, these two tools are missing from the `execute_list_tools` schema registration and the `call_tool` execution match block.
   - You need to add `pdf_hash` and `pdf_validate` schemas to `execute_list_tools()`. They should take a single `input` parameter (string).
   - Note: The underlying CLI operations for hashing and validating already exist. You just need to wire them up to the MCP `OperationResult`.

     For `pdf_hash`, the handler should look like:
     ```rust
     "pdf_hash" => {
         let input = get_string("input")?;
         let op = paperpilot_pdf::operations::hash::IntegrityHashOperation::new(std::path::PathBuf::from(&input));
         // It implements PdfOperation but its hash execution doesn't mutate the doc
         let mut doc = paperpilot_pdf::document::LopdfDocument::new();
         op.execute(&mut doc).map_err(crate::error::to_mcp_error)?;
         let result = op.hash_result.lock().unwrap();
         let (hash, _size) = result.as_ref().unwrap();
         Ok(OperationResult {
             success: true,
             message: "Hash calculated".to_string(),
             output_path: Some(hash.clone()), // The test just checks that there is output text
         })
     }
     ```

     For `pdf_validate`, the handler should look like:
     ```rust
     "pdf_validate" => {
         let input = get_string("input")?;
         let mut doc = paperpilot_pdf::document::LopdfDocument::load(&std::path::PathBuf::from(&input))
             .map_err(crate::error::to_mcp_error)?;
         let op = paperpilot_pdf::operations::validate::ValidateOperation::new();
         op.execute(&mut doc).map_err(crate::error::to_mcp_error)?;
         Ok(OperationResult {
             success: true,
             message: "Document is valid".to_string(),
             output_path: Some("true".to_string()),
         })
     }
     ```

2. **Fix Schema Missing Descriptions**: The `MCP_TEST_REPORT.md` lists ~40 "missing description for required [parameter]" issues. 
   - Open `paperpilot-mcp/src/server.rs` and go through the `execute_list_tools()` function.
   - For every required property in every tool, ensure `prop_name.insert("description".to_string(), serde_json::Value::String("...".to_string()));` is present.

## Validation
- After making the changes, run `scripts/test_mcp_e2e.py` locally and ensure the output for the schema issues and `pdf_hash` / `pdf_validate` is completely green.
- Commit the changes and open a PR against `main`.
