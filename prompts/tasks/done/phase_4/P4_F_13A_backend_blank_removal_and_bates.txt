### Step 1: Implement `RemoveBlankPagesOperation`
In `paperpilot-pdf/src/operations/cleanup.rs`:
- Create `RemoveBlankPagesOperation` implementing the `PdfOperation` trait.
- Input parameters:
  - `input`: Path to input PDF file.
  - `threshold`: Sensitivity threshold (e.g. byte length threshold for stream or empty text/graphic objects, default: 50 bytes).
  - `output`: Path to write the cleaned PDF file.
- Logic using `lopdf::Document`:
  - Load the document.
  - Iterate through all pages.
  - If a page has an empty content stream or stream length < threshold with no visible text/image operators, omit it from the page tree.
  - If no pages are blank, copy input to output or save document.
