# Task: Phase 4.F.13 — Stirling Parity: Category Filter Pills, Stirling Tools (To-PDF, Page Numbers, Blank Removal) & Clean Ergonomics

## Priority: HIGH — Parity with Stirling PDF v1/v2 Directory & Clean Modern Ergonomics

---

## 1. OBJECTIVES

This task modernizes the **Operations Dock** (`OperationsPanel.svelte`) and backend execution pipeline with top-tier UI ergonomics inspired by VS Code and Figma, while adding Stirling PDF's highest-value missing tools:

1. **Modern Category Filter Pills Bar (No Hidden Tools, Zero Friction)**:
   - Below the search bar, provide a horizontal scrolling pill selector:
     - `[ All ] [ ⚡ Quick ] [ 📑 Pages ] [ ✍️ Edit ] [ 🗜️ Optimize ] [ 🔒 Security ] [ 🔄 Convert ] [ 🧠 AI ]`
   - **Single-Click Filtering**: Clicking a category pill filters the view to that category instantly.
   - **All Open by Default**: The "All" view shows all tools without hiding anything.
   - **Chevron Minimizing Option**: Optional subtle chevron on section headers allowing users to minimize sections if desired, but defaults to fully visible.
   - **Instant Search Integration**: Typing into the search bar auto-activates search mode across all categories. Clearing search restores the active pill selection.

2. **Integration of "To-PDF" Conversions (Phase 4.F.12 Engine)**:
   - Wire existing backend conversion engines directly into the Tools Dock:
     - **Markdown → PDF** (`md_to_pdf`) with custom CSS preset options.
     - **HTML → PDF** (`html_to_pdf`) with styling presets.
     - **Images → PDF** (`img_to_pdf` / PNG, JPG, WebP combining).
     - **DOCX → PDF** (`docx_to_pdf`).
   - Add dedicated inspector parameter views allowing users to select an input file or paste text, select a CSS preset (Academic / Corporate / Minimalist), and produce an output PDF tab.

3. **New Stirling-Style Core Utilities**:
   - **Add Page Numbers / Bates Stamping**:
     - Parameters: Format template (e.g., `Page {n} of {total}` or `{n}`), Position (`bottom-right`, `bottom-center`, `bottom-left`, `top-right`, `top-center`), Margin, and Starting number.
   - **Remove Blank Pages**:
     - Parameters: Sensitivity threshold (e.g. 98% white / empty text & vector streams). Auto-strips blank scan pages.
   - **Auto-Redact / Blackout**:
     - Tool to redact sensitive patterns (Emails, Phone Numbers, SSN / Credit Card patterns) or user-specified keywords, permanently sanitizing the PDF stream.

## 2. STEP-BY-STEP IMPLEMENTATION PLAN

### Step 2.1: Update `apps/desktop/src/lib/components/layout/OperationsPanel.svelte`

1. **Category Pills State & Template**:
   ```ts
   let selectedCategory = $state<string>('all');
   ```

2. **Category Pill Bar HTML**:
   ```svelte
   <div class="category-pills-bar">
     <button 
       class="pill-btn" 
       class:active={selectedCategory === 'all'}
       onclick={() => selectedCategory = 'all'}
     >
       All
     </button>
     {#each categories as cat}
       <button 
         class="pill-btn" 
         class:active={selectedCategory === cat.id}
         onclick={() => selectedCategory = cat.id}
       >
         <span class="pill-icon">{cat.icon}</span>
         {cat.title}
       </button>
     {/each}
   </div>
   ```

3. **Filtered View Logic**:
   - When `searchQuery` has text, show matching tools.
   - When `searchQuery` is empty:
     - If `selectedCategory === 'all'`, display all sections.
     - If `selectedCategory !== 'all'`, display only the chosen category's grid.

4. **Register New Tools in `allTools`**:
   - `md_to_pdf`: Category `convert`, title `'Markdown to PDF'`, tags `['markdown', 'convert', 'pdf', 'generate']`
   - `html_to_pdf`: Category `convert`, title `'HTML to PDF'`, tags `['html', 'web', 'convert', 'pdf']`
   - `img_to_pdf`: Category `convert`, title `'Images to PDF'`, tags `['image', 'jpg', 'png', 'combine', 'photo']`
   - `page_numbers`: Category `pages`, title `'Add Page Numbers'`, tags `['numbering', 'bates', 'header', 'footer', 'page']`
   - `remove_blank`: Category `pages`, title `'Remove Blank Pages'`, tags `['blank', 'empty', 'clean', 'delete']`
   - `redact_text`: Category `security`, title `'Redact Sensitive Text'`, tags `['redact', 'blackout', 'privacy', 'sanitize']`

5. **Inspector Views for New Tools**:
   - For `page_numbers`: Provide dropdown for position (`Bottom Right`, `Bottom Center`, `Top Right`) and format input (`Page {n} of {total}`).
   - For `remove_blank`: Provide a one-click "Detect & Remove Blank Pages" with a sensitivity slider (Default: 99%).
   - For `img_to_pdf` / `md_to_pdf`: File picker input + CSS theme preset selector (`Academic Paper`, `Corporate Report`, `Modern Minimalist`).
