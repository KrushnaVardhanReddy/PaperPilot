### Step 1: Category Filter Pills Bar in `OperationsPanel.svelte`
In `apps/desktop/src/lib/components/layout/OperationsPanel.svelte`:
- Below `#tool-search-input`, add a horizontal scrolling pill selector:
  ```svelte
  <div class="category-pills-bar">
    <button 
      class="pill-btn" 
      class:active={selectedCategory === 'all'}
      onclick={() => selectedCategory = 'all'}
    >
      All
    </button>
    {#each categories as cat}
      <button 
        class="pill-btn" 
        class:active={selectedCategory === cat.id}
        onclick={() => selectedCategory = cat.id}
      >
        <span class="pill-icon">{cat.icon}</span>
        {cat.title}
      </button>
    {/each}
  </div>
  ```
- State: `let selectedCategory = $state<string>('all');`
- Clicking a category pill filters visible tool sections to only that category.
- When `searchQuery` has text, automatically show matching tools across all categories.
- When `searchQuery` is empty, filter by `selectedCategory` (or display all if `'all'`).
