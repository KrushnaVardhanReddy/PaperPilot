#### Annotation Toolbar (`PdfAnnotationToolbar.svelte`)
A floating or pinned toolbar to select the active tool.
```svelte
<script lang="ts">
  let { activeTool = $bindable('none') } = $props();
</script>

<div class="toolbar">
  <button class:active={activeTool === 'highlight'} onclick={() => activeTool = 'highlight'}>Highlight</button>
  <button class:active={activeTool === 'pen'} onclick={() => activeTool = 'pen'}>Pen</button>
  <button class:active={activeTool === 'note'} onclick={() => activeTool = 'note'}>Note</button>
</div>
```
