## Required Test Coverage in `apps/desktop/tests/e2e_canvas_viewer_features.spec.ts`

### 1. Sticky Notes & Annotations
- Create a text note / sticky note on canvas.
- Edit sticky note content.
- Reposition / drag note on canvas.
- Delete sticky note and verify removal from DOM.

### 2. Pointer, Highlighting & Markup Tools
- Select highlight / pen tool from `PdfToolbar.svelte`.
- Trigger draw stroke on canvas.
- Verify stroke or markup is recorded in active annotations array.

### 3. Visual Pixel Diff Slider (`PdfVisualDiff.svelte`)
- Open comparison view between two documents.
- Verify side-by-side view and overlay split slider exist.
- Interact with slider position (drag between 0% and 100%) and assert visual split style updates.

### 4. Zoom Toolbar & Thumbnail Navigation
- Test Zoom In (+), Zoom Out (-), Fit to Width, and Reset buttons.
- Click a page in `PdfThumbnails.svelte` and verify main canvas scrolls/switches to that page.
