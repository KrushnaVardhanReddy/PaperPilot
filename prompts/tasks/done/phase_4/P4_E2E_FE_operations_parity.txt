## Required Test Coverage in `apps/desktop/tests/e2e_operations_parity.spec.ts`

### 1. Operations Panel Navigation & Search
- Verify all operation categories (Organize, Convert, Security, Forms, Optimize, Edit) display cleanly.
- Verify searching in the operations search bar filters tools accurately.
- Verify clicking a tool opens its parameter configuration card/dialog.

### 2. Operation Form Inputs & Execution Mock
- Test form field validations for common operations:
  - **Merge**: Multi-file input list.
  - **Split & Reorder**: Page input fields and ranges (`1-5`, `2,1,3,4,5`).
  - **Encrypt & Decrypt**: Password input fields.
  - **Convert**: Format dropdown selection (`docx`, `xlsx`, `pptx`, `html`, `markdown`).
  - **Watermark & Header/Footer**: Text input fields and position toggles.
- Verify mock Tauri IPC invoke `invoke_mcp_tool` receives the properly formatted arguments when clicking "Run Operation" or "Execute".

### 3. Viewer Interaction & Canvas
- Verify loading a document into the viewer renders canvas pages.
- Verify zoom toolbar controls (zoom in, zoom out, fit to width, reset).
- Verify page navigation buttons and thumbnail sidebar.
