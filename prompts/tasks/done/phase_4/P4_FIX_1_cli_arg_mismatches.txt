## All Required Fixes

### Fix A: `pdf_merge` — multiple inputs as space-separated values
**Error:** `"error: unexpected argument '/app/.../page_2.pdf' found"`  
**Root cause:** `input: Vec<PathBuf>` requires `--input a --input b` by default. Tests call `--input a b`.

In `cli.rs`, update the `Merge` variant:
```rust
Merge {
    #[arg(long, required = true, num_args = 1..)]
    input: Vec<PathBuf>,
    #[arg(long)]
    output: PathBuf,
},
```

No change needed in `commands/mod.rs` — dispatch already passes `input`.

---

### Fix B: `pdf_rotate` — `--angle` alias + optional `--pages`
**Error:** `"error: unexpected argument '--angle' found"` and MCP/API: `"Missing or invalid 'pages' parameter"`  
**Root cause:** CLI requires `--pages` but tests only pass `--angle`.

In `cli.rs`, update the `Rotate` variant:
```rust
Rotate {
    #[arg(long)]
    input: PathBuf,
    #[arg(long)]
    pages: Option<String>,   // make optional
    #[arg(long, alias = "angle")]
    degrees: i32,
    #[arg(long)]
    output: PathBuf,
},
```

In `commands/mod.rs`, update the Rotate arm to unwrap pages:
```rust
Commands::Rotate { input, pages, degrees, output } =>
    group_a::handle_rotate(input, &pages.clone().unwrap_or_else(|| "all".to_string()), *degrees, output),
```

---

### Fix C: `pdf_burst` — `--output-dir` alias
**Error:** `"error: unexpected argument '--output-dir' found"`  
**Root cause:** CLI only has `--output` but tests pass `--output-dir`.

In `cli.rs`, update the `Burst` variant:
```rust
Burst {
    #[arg(long)]
    input: PathBuf,
    #[arg(long, aliases = &["output-dir"])]
    output: PathBuf,
},
```

No dispatch change needed.

### Fix D: `pdf_crop` — accept `--x --y --width --height` flags
**Error:** `"error: unexpected argument '--x' found"`. CLI expects `--rect x,y,w,h` but tests pass individual flags.

In `cli.rs`, update the `Crop` variant to accept individual flags AND optionally keep `--rect`:
```rust
Crop {
    #[arg(long)]
    input: PathBuf,
    #[arg(long)]
    pages: Option<String>,      // make optional
    #[arg(long)]
    rect: Option<String>,       // make optional (combined form "x,y,w,h")
    #[arg(long)]
    x: Option<f32>,
    #[arg(long)]
    y: Option<f32>,
    #[arg(long)]
    width: Option<f32>,
    #[arg(long)]
    height: Option<f32>,
    #[arg(long)]
    output: PathBuf,
},
```

In `commands/mod.rs`, update the Crop arm to build `rect` from individual fields if `rect` is None:
```rust
Commands::Crop { input, pages, rect, x, y, width, height, output } => {
    let resolved_rect = rect.clone().unwrap_or_else(|| {
        format!("{},{},{},{}", x.unwrap_or(0.0), y.unwrap_or(0.0), width.unwrap_or(0.0), height.unwrap_or(0.0))
    });
    let resolved_pages = pages.clone().unwrap_or_else(|| "all".to_string());
    group_a::handle_crop(input, &resolved_pages, &resolved_rect, output)
},
```

### Fix E: `pdf_remove_blank` — add missing CLI subcommand

In `cli.rs`, add the variant to `Commands`:

```rust
    #[arg(long)]

    #[arg(long)]
    output: PathBuf,
},
```

In `commands/mod.rs`, add the dispatch arm (before the `Commands::Compress` arm or at the end of Group A section):
```rust
Commands::RemoveBlank { input, output } => group_a::handle_remove_blank(input, output),
```

In `commands/group_a.rs`, add the handler if not present:
```rust
pub fn handle_remove_blank(input: &std::path::Path, output: &std::path::Path) -> OperationResult<()> {
    let op = paperpilot_pdf::operations::cleanup::RemoveBlankPagesOperation {
        input_path: input.to_path_buf(),
        output_path: output.to_path_buf(),
    };
    op.execute()
}
```
(Check the exact struct/method name by looking at `paperpilot-pdf/src/operations/cleanup.rs`.)

### Fix H: `pdf_render` — add `--page` option

```rust
    output: PathBuf,
},
```

In `commands/mod.rs`, update the `Render` arm:
```rust
Commands::Render { input, page, output } => group_c::handle_render(input, *page, output),
```

In `commands/group_c.rs`, update `handle_render` signature to accept a `page: u32` argument and pass it to the underlying operation.

### Fix J: Batch 4 CLI — all `paperpilot to-docx/to-xlsx/etc.` subcommands exit with code 11 (wrong binary name)
**Error:** The Batch 4 tests call `paperpilot to-docx ...` (using binary name `paperpilot`) while the built binary is `paperpilot-cli`. Exit code 11 = binary not found.  
**Root cause:** The binary name alias is missing. In `paperpilot-cli/Cargo.toml`, the binary is named `paperpilot-cli`. The tests expect `paperpilot`.

Add an additional binary alias in `paperpilot-cli/Cargo.toml`:
```toml
[[bin]]
name = "paperpilot"
path = "src/main.rs"
```
Keep the existing `paperpilot-cli` binary too. OR, rename the binary to `paperpilot` (preferred for user experience).
