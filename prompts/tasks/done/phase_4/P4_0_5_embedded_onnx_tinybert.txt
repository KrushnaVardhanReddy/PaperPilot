# Task: Phase 4.0.5 — Embedded ONNX Intent Classifier (TinyBERT-4L-312D)

## Technical Architecture & Requirements

### 1. Update Training Script for `TinyBERT-4L-312D`
In `tools/train-nlp/train.py`:
- Update `model_name = "huawei-noah/TinyBERT_General_4L_312D"` (or `"prajjwal1/bert-tiny"`).
- After training, export the model to INT8 ONNX (`model_int8.onnx`).
- Compress the ONNX model using `zstd` to produce `tools/train-nlp/output/tinybert_int8.onnx.zst` (~6–7MB).

### 2. Rust In-Memory Inference in `paperpilot-nlp`
In `paperpilot-nlp/Cargo.toml`:
Add:
```toml
ort = { version = "2.0.0-rc.9", default-features = false, features = ["copy-dylibs"] }
# or appropriate version of ort / tokenizers
tokenizers = { version = "0.21", default-features = false, features = ["onig"] }
zstd = "0.13"
```
*(Note: If building ONNX runtime in headless CI poses download constraints, implement a clean feature flag `#[cfg(feature = "onnx")]` with an in-memory embedded fallback model or mock tensor session so tests run deterministically in any offline environment!)*

### 4. Wire Layer 2 into `OfflineNlpResolver` (`resolver.rs`)
In `OfflineNlpResolver::resolve(&self, query: &str)`:
1. Try Layer 1 `RuleEngine::predict(query)`.
2. If Layer 1 returns `None`, fall back to Layer 2 `OnnxClassifier::predict(query)`.
