### Task: Implement Spec 159 - Agent Semantic Chunking & Dynamic Overlap (`pdf_chunk`)

#### Context
Spec 159 (`specs/159-agent-semantic-chunking/spec.md`) defines `pdf_chunk` as an intelligent, structure-aware semantic chunker tailored for LLMs and AI agent context windows.
Note: PaperPilot has an existing basic `rag-chunks` (`PdfRagChunksOperation` in `paperpilot-pdf/src/operations/rag_chunks.rs`), but `pdf_chunk` provides full structural boundary splitting (`#`, `##`, `\n\n`, tables `|...|`), configurable `target_tokens` (default 500), `overlap_tokens` (default 50), `strip_boilerplate` (recurring headers/footers across consecutive pages), and `break_on_headings` (default true). Furthermore, it should integrate seamlessly with `DocumentSource` (implemented in Spec 163).

#### Requirements

1. **Core Data Structures & Algorithm (`paperpilot-pdf/src/operations/pdf_chunk.rs`)**:
   Implement `ChunkOptions`, `DocumentChunk`, `ChunkResult`, and `PdfChunkOperation`:
   ```rust
   #[derive(Debug, Clone, Serialize, Deserialize)]
   pub struct ChunkOptions {
       pub target_tokens: usize,       // default 500, min 50, max 4000
       pub overlap_tokens: usize,      // default 50, min 0, max 500
       pub strip_boilerplate: bool,   // default true
       pub break_on_headings: bool,   // default true
   }

   #[derive(Debug, Clone, Serialize, Deserialize)]
   pub struct DocumentChunk {
       pub chunk_index: usize,
       pub page_start: u32,
       pub page_end: u32,
       pub estimated_tokens: usize,
       pub text: String,
       pub headings_context: Vec<String>,
   }

   #[derive(Debug, Clone, Serialize, Deserialize)]
   pub struct ChunkResult {
       pub total_chunks: usize,
       pub total_tokens: usize,
       pub chunks: Vec<DocumentChunk>,
       pub execution_time_ms: f64,
   }
   ```
   - Support `DocumentSource` directly (`PdfChunkOperation::chunk_source(&DocumentSource, ChunkOptions)` and `PdfChunkOperation::chunk_bytes(&[u8], ChunkOptions)`).
   - Implement token estimation (~4 characters per token or accurate whitespace-based estimation with bpe heuristic).
   - Boundary prioritization:
     - Level 1: Hard break on `#` / `##` headings if `break_on_headings == true`.
     - Level 2: Paragraph breaks (`\n\n`).
     - Level 3: Sentence terminators (`. `, `! `, `? `).
     - Keep Markdown tables (`| ... |`) intact within a single chunk whenever possible unless the table exceeds `target_tokens`.
   - Boilerplate suppression: If `strip_boilerplate == true`, identify repetitive single-line headers or footers across $\ge 3$ consecutive pages and remove them before chunking.
   - Dynamic overlap: When starting the next chunk, rewind by up to `overlap_tokens` sentences/words from the previous chunk unless broken by a major heading.
   - Export `pdf_chunk` in `paperpilot-pdf/src/operations/mod.rs` and `paperpilot-pdf/src/lib.rs`.
