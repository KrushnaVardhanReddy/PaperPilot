# Task 103C: Desktop UI Async Job Drawer & Cross-Document Semantic Search Integration

## Context & Objectives
You are implementing **Task 103C (Spec 103)**: Integrating the newly completed embedded Turso/libSQL persistent engine (`paperpilot-storage`) into the Desktop Tauri application (`apps/desktop`).

### The Goal
1. Allow the desktop app to persist and inspect asynchronous background jobs (`jobs` table).
2. Allow users to inspect immutable audit events (`audit_logs` table).
3. Connect the vector store and semantic search engine (`document_chunks` table) to the desktop workspace search interface.
4. Provide a sleek, modern slide-out `<JobQueueDrawer.svelte>` component and integrate it with the command bar / status bar.

## Detailed Implementation Requirements

### 1. Backend: `apps/desktop/src-tauri/`

#### 1.1 Add dependency in `apps/desktop/src-tauri/Cargo.toml`:
```toml
[dependencies]
paperpilot-storage = { path = "../../../paperpilot-storage" }
```

#### 1.2 Storage Manager in `apps/desktop/src-tauri/src/storage.rs`:
Add a thread-safe helper to initialize and access `StorageEngine`:
```rust
use std::sync::Arc;
use tokio::sync::Mutex;
use paperpilot_storage::StorageEngine;

lazy_static::lazy_static! {
    static ref GLOBAL_STORAGE: Arc<Mutex<Option<StorageEngine>>> = Arc::new(Mutex::new(None));
}

pub async fn get_storage_engine() -> Result<StorageEngine, String> {
    let mut lock = GLOBAL_STORAGE.lock().await;
    if let Some(ref engine) = *lock {
        return Ok(engine.clone());
    }

    let root = get_app_data_root();
    std::fs::create_dir_all(&root).map_err(|e| e.to_string())?;
    let db_path = root.join("paperpilot.db");

    let engine = StorageEngine::open_local(&db_path)
        .await
        .map_err(|e| format!("Failed to open libSQL storage: {}", e))?;

    engine.run_migrations()
        .await
        .map_err(|e| format!("Failed to run migrations: {}", e))?;

    *lock = Some(engine.clone());
    Ok(engine)
}
```

#### 1.3 Expose Tauri IPC Commands in `apps/desktop/src-tauri/src/lib.rs`:
Expose the following commands:
```rust
#[tauri::command]
async fn get_jobs_history(limit: Option<usize>) -> Result<Vec<paperpilot_storage::models::JobRecord>, String> {
    let engine = storage::get_storage_engine().await?;
    engine.list_jobs(limit.unwrap_or(50))
        .await
        .map_err(|e| e.to_string())
}

#[tauri::command]
async fn get_audit_events(limit: Option<usize>) -> Result<Vec<paperpilot_storage::models::AuditRecord>, String> {
    let engine = storage::get_storage_engine().await?;
    engine.list_audit_events(limit.unwrap_or(50))
        .await
        .map_err(|e| e.to_string())
}

#[tauri::command]
async fn search_document_vectors(
    query_embedding: Vec<f32>,
    limit: Option<usize>,
) -> Result<Vec<paperpilot_storage::models::SemanticSearchResult>, String> {
    let engine = storage::get_storage_engine().await?;
    engine.search_chunks(&query_embedding, limit.unwrap_or(10))
        .await
        .map_err(|e| e.to_string())
}

#[tauri::command]
async fn store_document_chunks(
    chunks: Vec<paperpilot_storage::models::NewDocumentChunk>,
) -> Result<(), String> {
    let engine = storage::get_storage_engine().await?;
    engine.store_chunks(&chunks)
        .await
        .map_err(|e| e.to_string())
}
```
Register them in `tauri::Builder::default().invoke_handler(tauri::generate_handler![...])`.

### 2. Frontend UI: `apps/desktop/src/`

#### 2.1 Create Slide-Out Drawer: `apps/desktop/src/lib/components/pipeline/JobQueueDrawer.svelte`
- Svelte 5 component with reactive drawer visibility (`isOpen = $bindable(false)`).
- Tabs or filter pills: `All`, `Running`, `Completed`, `Failed`.
- For each job:
  - Operation name with clean badge (e.g. `OCR`, `COMPRESS`, `VECTOR_INDEX`).
  - Status pill:
    - `running` (with animated pulse indicator and progress bar).
    - `completed` (green checkmark).
    - `failed` (red badge with expandable error message).
  - Relative timestamp (e.g., "2 mins ago").
- Action bar: `Refresh` button and `Clear History` button.

#### 2.2 Global Trigger Integration: `apps/desktop/src/lib/components/GlobalCommandBar.svelte`
- Add a job queue icon button next to settings / command palette showing active background job count badge if any.
- Clicking the button toggles `JobQueueDrawer`.

#### 2.3 Semantic Vector Search in `apps/desktop/src/lib/components/workspace/WorkspaceSearchModal.svelte`:
- Add a toggle switch in the search header:
  `[Exact Text | 🧠 Semantic Vector]`
- When `Semantic Vector` is active:
  - If local vector embeddings are available or if text query is converted, call `search_document_vectors`.
  - Display similarity score badge (e.g. `92% match`) next to the search result chunk snippet.
