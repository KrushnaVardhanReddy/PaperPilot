# Task 104A: Web Worker Bridge Expansion & Category Navigation Bar (`apps/web`)

## Context & Objectives
You are implementing **Task 104A (Spec 104)**: Expanding the PaperPilot client-side Web portal (`apps/web`) to support all operations compiled in `paperpilot-wasm`, and upgrading the toolbar from a flat 12-item list into a clean, categorized navigation dock (`pages`, `edit`, `optimize`, `security`, `convert`).

All operations execute 100% in the user's browser via WebAssembly with zero network uploads.

---

### 3. Tool Panels & Input Handling for New Tools
In `OperationsView.svelte`, add interactive parameter panes for the new operations:

1. **`pdf_nup`**:
   - Primary PDF dropzone.
   - Grid selector buttons: `2` (2x1), `4` (2x2), `9` (3x3), `16` (4x4).
   - Ordering: `horizontal` vs `vertical`.
   - Action: `wasmPdfClient.pdf_nup(bytes, { grid, ordering })` $\to$ download `nup_${file.name}`.
2. **`pdf_booklet`**:
   - Primary PDF dropzone.
   - Page format: `a4` vs `letter`.
   - Action: `wasmPdfClient.pdf_booklet(bytes, { page_format })` $\to$ download `booklet_${file.name}`.
3. **`pdf_scale_pages`**:
   - Primary PDF dropzone.
   - Target format: `a4`, `letter`, `legal`, `a3`, or percentage slider (50% to 200%).
   - Action: `wasmPdfClient.pdf_scale_pages(bytes, options)` $\to$ download `scaled_${file.name}`.
4. **`pdf_auto_rotate`**:
   - Primary PDF dropzone.
   - Target orientation toggle: `portrait` vs `landscape`.
   - Action: `wasmPdfClient.pdf_auto_rotate(bytes, { target_orientation })` $\to$ download `autorotated_${file.name}`.
5. **`pdf_stamp`**:
   - Primary PDF dropzone + Secondary Stamp Image picker (PNG/JPEG).
   - Position picker (top-left, center, bottom-right).
   - Action: read image as base64 or bytes $\to$ `wasmPdfClient.pdf_stamp(bytes, { image_data: b64, position })` $\to$ download.
6. **`pdf_validate_signatures`**:
   - Signed PDF dropzone + optional Baseline PDF dropzone.
   - Action: `wasmPdfClient.pdf_validate_signatures(bytes, options)` $\to$ renders formatted JSON inspection report with signer, certificate validity, and baseline tamper verdict.
7. **`pdf_remove_signatures`**:
   - Signed PDF dropzone.
   - Action: `wasmPdfClient.pdf_remove_signatures(bytes, {})` $\to$ download `unlocked_${file.name}`.
