# Task 105A: Embed Widget Tool Parity & Categorized Embeds (`apps/embed` & `/embed-test`)

## Context & Objectives
You are implementing **Task 105A (Spec 105)**: Upgrading the PaperPilot drop-in embed widget (`apps/embed`) and its live demonstration sandbox (`apps/web/public/embed-test.html`) to support all newly completed Wave 2 operations.

Developers embedding PaperPilot widgets on external websites can now embed full imposition suites (`pdf_nup`, `pdf_booklet`, `pdf_scale_pages`, `pdf_auto_rotate`), stationery stamping (`pdf_stamp`, `pdf_overlay_underlay`), and contract forensics (`pdf_validate_signatures`).

---

## Detailed Implementation Tasks

### 1. Tool Expansion & Categorization (`apps/embed/src/Widget.svelte`)
1. Expand the `allTools` array in `Widget.svelte` with:
   - `pdf_nup`: "N-Up Imposition" (category: `'pages'`, description: "Combine multiple pages per sheet (2, 4, 9, 16)")
   - `pdf_booklet`: "Booklet Imposition" (category: `'pages'`, description: "Impose pages for fold-and-staple booklet printing")
   - `pdf_scale_pages`: "Scale Dimensions" (category: `'pages'`, description: "Resize pages between standard formats (A4, Letter, Legal) or scale")
   - `pdf_auto_rotate`: "Auto Upright" (category: `'pages'`, description: "Automatically detect and upright landscape or skewed pages")
   - `pdf_stamp`: "Image Stamp" (category: `'edit'`, description: "Stamp coordinate-exact PNG/JPEG logos and badges")
   - `pdf_overlay_underlay`: "Stationery Overlay" (category: `'edit'`, description: "Apply letterheads and stationery background/foreground")
   - `pdf_validate_signatures`: "Validate Signatures" (category: `'security'`, description: "Verify digital signatures and baseline tamper detection")
   - `pdf_remove_signatures`: "Strip Signatures" (category: `'security'`, description: "Remove signature fields and cryptographic locks")

2. Support `category` filtering prop:
   - Accept `category?: string` (e.g. `data-category="pages"` or `data-category="security"`).
   - If `category` is supplied, filter `filteredTools` to only include tools matching that category unless explicit `tools` list is given.

3. Parameter Inputs inside Widget:
   - When `pdf_nup` is selected, show 2/4/9/16 grid selection buttons.
   - When `pdf_scale_pages` is selected, show format dropdown (A4, Letter, Legal, A3).
   - When `pdf_auto_rotate` is selected, show orientation toggle (Portrait, Landscape).

---

### 2. Pipeline Execution Expansion (`apps/embed/src/api.ts`)
In `runPipeline`:
1. Add handling for `pdf_nup`, `pdf_booklet`, `pdf_scale_pages`, `pdf_auto_rotate`, `pdf_stamp`:
   - Support step parameters (e.g. `grid: 2`, `format: 'a4'`, `target_orientation: 'portrait'`).
2. Keep client execution 100% in-browser.
