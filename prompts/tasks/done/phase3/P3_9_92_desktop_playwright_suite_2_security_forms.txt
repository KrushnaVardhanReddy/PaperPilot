TEST PATTERN PER TOOL
================================================================================
Follow the tested lifecycle from `e2e_all_tools_real_execution.spec.ts`:
1. Workspace Reset: `await page.evaluate(() => (window as any).appState?.clearAllDocuments())` and `await page.click('#tab-btn-home')`.
2. Stage input files: `await fileInput.setInputFiles([path.resolve('../../tests/e2e_fixtures/real/<fixture>')])`.
3. Set context tab: `#context-btn-pdf`.
4. Select tool: Focus `#tool-search-input`, type exact name (e.g. `'Sign Document'`, `'Encrypt Document'`), click `.tool-card`.
5. Enter parameters: Fill inputs (e.g. password, certificate file path, form JSON).
6. Execute: Click `.run-btn`, wait for `.toast`.
7. Assert: Verify signature dictionary, encryption status, form schemas, or output hash.
8. Reset UI: Click `.back-btn` or `#tab-btn-home`.
