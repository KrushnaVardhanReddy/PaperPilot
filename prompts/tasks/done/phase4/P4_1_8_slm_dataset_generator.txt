# Task 4.1.8 Prompt: On-Device Document SLM Dataset Generator Engine (`tools/slm-training`)

You are implementing Task 4.1.8 (Spec 084 / Task 84A): On-Device Document SLM Dataset Generator Engine in PaperPilot.
Follow this systematic workflow:

---

### Goal
Implement a modular, high-speed Python synthetic dataset generation engine under `tools/slm-training/`.
This engine will programmatically create thousands of training examples in ChatML format mapping natural language user instructions (single tools, compound workflows, legal/finance jargon, typos, informal speech) to strict JSON tool calls.

---

### Step 3: Implement `tool_registry.py` (Wave 1: Top 15 Core Tools)
In `tools/slm-training/tool_registry.py`:
- Establish the tool registration data structure (e.g., dataclass or Pydantic model with tool ID, category, description, parameters with types and defaults).
- Implement the **Top 15 Core Tools** for this first wave:
  1. `pdf_merge`: Combine multiple PDFs.
  2. `pdf_split`: Split PDF by page numbers or ranges.
  3. `pdf_compress`: Optimize and compress PDF.
  4. `pdf_rotate`: Rotate specific or all pages.
  5. `pdf_watermark`: Add diagonal or horizontal watermark text.
  6. `pdf_encrypt`: Password protect and encrypt PDF.
  7. `pdf_decrypt`: Decrypt PDF with password.
  8. `pdf_ocr`: Extract or burn in OCR text.
  9. `pdf_bates_numbering`: Legal Bates stamp numbering.
  10. `pdf_extract_text`: Extract raw text from document.
  11. `pdf_extract_tables`: Extract tabular data to JSON/CSV.
  12. `pdf_redact`: Redact sensitive text or bounding boxes.
  13. `sanitize`: Strip metadata, JavaScript, hidden layers.
  14. `pdf_auto_rotate`: Automatically upright rotated pages.
  15. `document_pii_scan`: Audit document for SSN, credit cards, emails.

*(Note: Future tasks 84B and 84C will add the remaining organization and conversion tools).*

---

### Step 4: Implement `templates.py` (Wave 1 Templates)
In `tools/slm-training/templates.py`:
- Create templates across 5 linguistic tiers covering the 15 core tools:
  1. **Direct Imperatives**: "Split input.pdf every 2 pages", "Compress document with high ratio", "Rotate page 3 by 90 degrees".
  2. **Conversational / Casual**: "hey can u make this pdf smaller it's too big to email", "turn this sideways scan upright", "strip all private metadata from this pdf".
  3. **Domain Legal & Finance**: "Apply Bates prefix SEC-DISCOVERY- starting at 1001 to all production documents", "Redact all SSN and PAN numbers and deep sanitize metadata".
  4. **Typo & Noise Robustness**: "watermrak 'CONFIDENTIAL' on pgs 1-5", "extarct tables to exel", "encrpyt with password pass123".
  5. **Compound Workflows**: Multi-step chained actions:
     - "Clean this scan, upright sideways pages, and run OCR" -> `[pdf_auto_rotate, sanitize, pdf_ocr]`
     - "Prepare for legal production: Bates stamp, add confidential watermark, and scan for PII" -> `[pdf_bates_numbering, pdf_watermark, document_pii_scan]`

---

### Step 5: Implement `generate_dataset.py`
In `tools/slm-training/generate_dataset.py`:
- CLI flags:
  - `--count <int>` (default `25000`)
  - `--output-dir <path>` (default `dataset/`)
  - `--val-ratio <float>` (default `0.1`)
  - `--sample <int>` (print N sample items to stdout)
- Outputs each record in standard **ChatML JSON format**:
  ```json
  {
    "messages": [
      {
        "role": "system",
        "content": "You are PaperPilot's on-device neural assistant. Convert user instructions into strict JSON tool calls."
      },
      {
        "role": "user",
        "content": "Stamp 'DRAFT' diagonally in red across all pages with 30% opacity"
      },
      {
        "role": "assistant",
        "content": "{\"tool\": \"pdf_watermark\", \"parameters\": {\"text\": \"DRAFT\", \"color\": \"#FF0000\", \"opacity\": 0.3, \"rotation\": 45, \"pages\": \"all\"}}"
      }
    ]
  }
  ```
- Randomly shuffles and partitions output into:
  - `<output-dir>/train.jsonl` (90%)
  - `<output-dir>/val.jsonl` (10%)
