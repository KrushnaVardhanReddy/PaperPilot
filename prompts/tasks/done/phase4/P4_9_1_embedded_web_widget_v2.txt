## Objective
Implement the core Embedded Web Distribution layer (`apps/embed/`) so that any website can embed PaperPilot's client-side WASM engine using 2 lines of HTML:
1. `embed.js` CDN loader (< 5KB gzip) with Shadow DOM container mounting and stylesheet encapsulation.
2. Configurable Svelte 5 Embed Widget (`apps/embed/src/Widget.svelte`) reading `data-*` attributes.
3. JavaScript programmatic API on `window.PaperPilot` (`mount`, `on`, `unmount`).
4. End-to-end Playwright test suite (`apps/embed/tests/e2e_embed.spec.ts`) — written once, fixed by fixing source.

## 2. Implementation Details

### A. `embed.ts` Loader
1. Scans DOM for `[data-paperpilot-portal]` or `#paperpilot-portal` on load.
2. Reads config attributes: `data-tools` (comma-separated or `"all"`), `data-theme` (`dark|light|system`), `data-brand-color` (hex), `data-logo-url`, `data-hide-badge`.
3. Creates Shadow DOM root (`attachShadow({ mode: 'open' })`).
4. Mounts `Widget.svelte` inside shadow root with CSS custom properties:
   ```css
   :host {
     --pp-brand-color: #2563eb;
     --pp-radius: 8px;
     --pp-font-family: system-ui, sans-serif;
   }
   ```
5. Initialises `window.PaperPilot` API.

### B. Widget.svelte (Svelte 5 Runes)
- Tool grid / toolbar based on `data-tools`.
- Drag-and-drop file zone.
- Viral badge (shown unless `data-hide-badge="true"`):
  ```html
  {#if !hideBadge}
    <a href="https://usepaperpilot.com" target="_blank" rel="noopener" class="pp-badge">
      ⚡ Powered by PaperPilot
    </a>
  {/if}
  ```
- Emits custom DOM events: `paperpilot:ready`, `paperpilot:process-start`, `paperpilot:process-complete`, `paperpilot:error`.

### C. window.PaperPilot API (`api.ts`)
```typescript
interface PaperPilotAPI {
  mount(selector: string | HTMLElement, options?: EmbedOptions): EmbedInstance;
  unmount(selector: string | HTMLElement): void;
  on(event: string, callback: (data: any) => void): void;
}
```

## 3. Playwright Tests (`e2e_embed.spec.ts`) — Write ONCE

The following test cases must all be in one file, written once:
1. **Shadow DOM Encapsulation**: Host page injects `div { color: red !important; }` globally. Assert widget internals retain their own styles.
2. **Tool Filtering**: `data-tools="merge,compress"` → only merge and compress operations visible.
3. **Badge Visibility (on by default)**: Assert `⚡ Powered by PaperPilot` is visible when no `data-hide-badge` attribute is set.
4. **Badge Hidden**: Assert badge is absent when `data-hide-badge="true"`.
5. **Programmatic Mount/Unmount**: Call `PaperPilot.mount()` and `PaperPilot.unmount()` via `page.evaluate()`, assert widget appears and disappears cleanly.

> NOTE: Do NOT test actual PDF processing via WASM in E2E (WASM binary may not be available in CI). Test widget mounting, DOM structure, attribute binding, and events only.
