## 2. Certificate Templates (`apps/web/src/components/certificate/templates/`)
Create 4 polished, professional HTML5/CSS3/SVG vector certificate templates:
1. **ClassicGold.svelte**: Traditional diploma style with ornate gold foil borders, serif typography, decorative ribbon/seal, and dual signature lines.
2. **ModernMinimalist.svelte**: Clean architectural layout, subtle geometric accents, modern sans-serif typography, and sleek lines.
3. **TechHackathon.svelte**: Dark/cyber aesthetic, glowing neon borders, tech grid accents, and badge placeholder.
4. **AcademicDiploma.svelte**: Formal university style with gothic/calligraphic headings, embossed seal effect, and honor recognition banner.

Each template must accept reactive props:
- `recipientName`: string (e.g. "Alex Morgan")
- `title`: string (e.g. "Certificate of Achievement" or "Full Stack Rust & WASM Mastery")
- `description`: string (e.g. "For successfully completing the intensive curriculum...")
- `date`: string (e.g. "October 2026")
- `issuerName`: string (e.g. "PaperPilot Academy")
- `issuerTitle`: string (e.g. "Lead Instructor")
- `certId`: string (unique verification identifier)
- `verificationUrl`: string (e.g. `https://usepaperpilot.com/verify?id=...`)
- `sha256Hash`: string (optional authenticity hash)
