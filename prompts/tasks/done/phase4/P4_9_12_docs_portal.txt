## 2. Documentation Content Structure (`apps/docs/src/content/docs/`)

### A. Pillar 1: Getting Started (`getting-started/`)
- `quickstart.md`: 2-minute overview across Desktop, CLI, and In-Browser WASM.
- `desktop-installation.md`: Windows (`.msi`), macOS (`.dmg`), Linux (`.deb`, `.AppImage`).
- `zero-cloud-privacy.md`: Zero telemetry, client-side memory safety, HIPAA/GDPR compliance rationale.
- `cli-guide.md`: Headless CLI usage, stdin/stdout piping, and automated scripting.

### B. Pillar 2: Embed.js Widget Integration (`embed/`)
- `quickstart.md`: The 2-line HTML drop-in snippet (`<script src=".../embed.js"></script><div id="paperpilot-portal"></div>`).
- `configuration.md`: Table of `data-*` attributes (`data-tools`, `data-theme`, `data-brand-color`, `data-hide-badge`, `data-logo-url`).
- `programmatic-api.md`: JavaScript lifecycle methods (`mount()`, `unmount()`, event callbacks for completed operations).
- `cms-integration.md`: Copy-paste instructions for WordPress Gutenberg, Webflow Custom Code, Shopify theme liquid, and Squarespace.

### C. Pillar 3: Master 44-Tool Reference (`reference/`)
- `44-tools-handbook.md`: Index table of all 44 tools categorized by operation domain (Merge/Split, Raster & OCR, Encryption, Metadata, Pages, Forms).
- For each tool category, provide exact copy-pasteable snippets:
  1. CLI command.
  2. cURL REST API request to `/api/v1/pdf/*`.
  3. Model Context Protocol (MCP) JSON-RPC tool call.
  (Reference data from `reports/TRI_INTERFACE_E2E_100_VERIFIED.md`).

### D. Pillar 4: Developer Gateway & AI Agents (`developer/`)
- `swagger-and-openapi.md`: How to access the local Swagger UI at `/swagger-ui` and download `/api-docs/openapi.json`.
- `mcp-agent-integration.md`: Setup instructions for Claude Desktop (`claude_desktop_config.json`) and Cursor IDE to invoke PaperPilot operations directly from LLM chat.
