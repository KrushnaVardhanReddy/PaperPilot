# Task: Phase 4.3.14 — Editable Action Blueprint Cards & 44-Tool Execution Dispatch (`PdfChatPanel.svelte`)

## Objective

## Technical Requirements

### 1. Editable Action Blueprint UI inside `PdfChatPanel.svelte`
When a message contains a `plan`, render an interactive form instead of static read-only text:

1. **Target Pages Selector & Array Display**:
   - Show an explicit **Pages Target** section.
   - Segmented buttons / pills:
     - `[ All Pages ]` (default when no specific pages extracted)
     - `[ Current Page: {currentPage} ]` (one-click bind to the currently visible viewer page)
     - `[ Custom Pages ]` (editable text input / tag array: e.g. `1, 4` or `1-3`)
   - Pre-populate this based on `plan.page_ranges`:
     - If `page_ranges` is empty -> select `All Pages`.
     - If `page_ranges` contains ranges (e.g. `[(1, 1)]`) -> pre-fill `1`.

2. **Operation-Specific Editable Fields with Contextual Hints & Examples**:
   - Every input field MUST display a clear placeholder hint and helper label so the user knows exactly what format and values to enter:
   - **Pages Field**:
     - *Helper hint*: `"e.g. '1, 4' or range '1-5' (or 'all' for entire document)"`
     - *Badge/Tag*: Shows total page count of active document (e.g. `Max: 4 pages`).
   - **Rotate**:
     - Segmented angle selector: `[ 90° ]` `[ 180° ]` `[ 270° ]` (pre-selecting extracted angle, defaulting to 90°).
     - *Helper hint*: `"Clockwise rotation angle in degrees"`
   - **Split / Extract / Burst**:
     - *Helper hint*: `"e.g. '1-2, 3-4' to split into chunks, or '2, 5' to extract"`
   - **Watermark / Stamp / Header-Footer**:
     - *Helper hint*: `"e.g. 'CONFIDENTIAL', 'DRAFT', or company name"`
   - **Security (Encrypt / Decrypt / Redact / Sign)**:
     - *Helper hint*: `"e.g. Minimum 6 characters (AES-256 protected)"`
   - **Crop**:
     - *Helper hint*: `"Format: x,y,width,height e.g. '50,50,400,600'"`
   - **Bates Numbering**:
     - *Helper hint*: `"Prefix e.g. 'CASE-2024-' | Start number e.g. '001' | Padding: 6"`
   - **Conversions (DOCX, XLSX, PPTX, Markdown, Text, HTML, Images)**:
     - Target format indicator / dropdown with file extension badge.
   - **Output Path**:
     - *Helper hint*: `"Destination file path (e.g. /path/to/doc_rotated.pdf)"`
     - Auto-suggests `{base}_{operation}.pdf` with an option or toggle to overwrite original.

3. **Execution Button & Validation**:
   - `[ ⚡ Execute Action ]` button that reads the *currently edited* values rather than raw static plan data.
   - If a required field is empty or format is invalid, shows an inline validation hint beneath the input (e.g. `"Please enter valid page numbers like 1, 3"`).
   - Disable button while operation is running with an active loading spinner (`Executing...`).

### 2. Comprehensive 44-Tool Execution Mapping
Update `executePlan(plan)` in `PdfChatPanel.svelte` to support **all 44 tools** with accurate MCP parameters, mirroring `OperationsPanel.svelte`:

1. **Rotate (`pdf_rotate`)**:
   - `input`: active document path.
   - `pages`: `'all'` (if All Pages selected) or comma-separated string (e.g. `'1,4'`). **MUST NEVER BE MISSING**.
   - `angle`: selected angle (number).
   - `output`: valid destination file path.

2. **Merge (`pdf_merge`)**:
   - `inputs`: list of document paths.
   - `output`: valid destination file path.

3. **Split (`pdf_split`)**:
   - `input`: active document path.
   - `output_pattern`: `{dir}/{base}_p%d.pdf`.
   - `ranges`: page ranges string (e.g. `'1-2, 3-4'`).

4. **Compress (`pdf_compress`)**:
   - `input`: docPath, `output`: outputPath.

5. **Page Operations**:
   - `delete_pages` (`pdf_delete_pages`): `input`, `pages`, `output`.
   - `reorder_pages` (`pdf_reorder_pages`): `input`, `order`, `output`.
   - `burst` (`pdf_burst`): `input`, `output_dir`.
   - `crop` (`pdf_crop`): `input`, `box`, `output`.
   - `extract_pages` (`pdf_extract_pages`): `input`, `pages`, `output`.
   - `remove_blank` (`pdf_remove_blank`): `input`, `output`.
   - `page_numbers` (`pdf_page_numbers`): `input`, `output`.

6. **Edit & Markup**:
   - `watermark` (`pdf_watermark`): `input`, `text`, `output`.
   - `bates` (`pdf_bates`): `input`, `prefix`, `start_number`, `padding`, `output`.
   - `header_footer` (`pdf_header_footer`): `input`, `header_left`, `footer_center`, `output`.
   - `flatten` (`pdf_flatten`): `input`, `output`.
   - `annotate` (`pdf_annotate`): `input`, `output`.

7. **Security & Privacy**:
   - `encrypt` (`pdf_encrypt`): `input`, `user_password`, `output`.
   - `decrypt` (`pdf_decrypt`): `input`, `password`, `output`.
   - `redact` (`pdf_redact`): `input`, `regions`, `output`.
   - `sign` (`pdf_sign`): `input`, `cert`, `output`.
   - `metadata` (`pdf_metadata`): `input`, `output`.
   - `validate` (`pdf_validate`): `input`.
   - `hash` (`pdf_hash`): `input`.

8. **Conversions & Extraction**:
   - `pdf_to_docx`, `pdf_to_xlsx`, `pdf_to_pptx`, `pdf_to_pdf_a`: `input`, `output`.
   - `extract_text` (`pdf_extract_text`): `input`, `output`.
   - `extract_images` (`pdf_extract_images`): `input`, `output_dir`.
   - `pdf_convert_markdown` / `pdf_convert_html` / `pdf_images_to_pdf`.
   - `render` (`pdf_render`): `input`, `page`, `output`.

9. **Forms & Intel**:
   - `read_form`, `fill_form`, `create_form_field`, `bookmarks`, `search`, `ocr`, `compare`, `linearize`, `classify_type`.
