## Requirements:

1. **Setup Vitest:**

   - Add a `vitest.config.ts` (or extend `vite.config.js`) configured for Svelte 5 component testing.
   - Add a `"test": "vitest run"` script to `package.json`.

2. **Write Component Unit Tests (`apps/desktop/src/lib/components/__tests__/`):**
   - **`Toast.test.ts`**: Mount a Toast notification, verify the message text renders, verify the correct CSS class is applied for `success` vs `error` type.

   - **`OperationsPanel.test.ts`**: Mount the OperationsPanel, verify the operation selector renders, select a different operation from the dropdown, verify the correct parameter inputs appear.

3. **Rules:**
   - Use Svelte 5 rune-compatible testing patterns. `@testing-library/svelte` v5+ supports Svelte 5 runes.
   - Do NOT use Playwright in these tests — pure Vitest only.
   - STRICTLY DO NOT USE TailwindCSS.
