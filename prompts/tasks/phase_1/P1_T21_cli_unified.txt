CRITICAL IMPLEMENTATION RULES & TIPS FOR JULES:
1. DO NOT WRITE ANY `#[cfg(test)]` MODULES. We are handling testing externally in Phase 1.4. You will get missing import errors if you try to mock files in unit tests. Just write the handler logic.
2. Standardize error handling: All handlers should map exactly to `OperationResult<()>` (which is `Result<(), paperpilot_core::error::PdfError>`) so `main.rs` doesn't suffer type inference failures.
3. In `main.rs`, after execution, format a JSON payload `{"success": true, "operation": "...", "error": null}`.
4. If `--json` is active, print ONLY that JSON payload to stdout.
5. If `--webhook <url>` is present, `POST` that JSON payload to the URL via `reqwest::blocking::Client`.
