Jules, you are our Senior Autonomous QA Engineer.

## STEP 2: LAUNCH & TEST VIA AGENT BROWSER

1. Start dev server:
   ```bash
   npm --prefix apps/desktop run dev &
   sleep 3
   ```

2. Open app and load `tests/e2e_fixtures/search_test.pdf`:
   ```bash
   npx --prefix apps/desktop agent-browser open "http://localhost:5173"
   npx --prefix apps/desktop agent-browser snapshot -i
   ```

3. **Open Search Bar**:
   - Press shortcut `ControlOrMeta+f`:
     ```bash
     npx --prefix apps/desktop agent-browser keyboard press "ControlOrMeta+f"
     ```
   - Verify `#pdf-search-bar` is visible.

4. **Search for Numbered Target**:
   - Fill `#pdf-search-input` with `SERIAL-777` and press Enter.
   - Verify match indicator `#pdf-search-count` shows `1 of 3` (or `3 matches`).

5. **Navigate Matches**:
   - Click `#pdf-search-next` (Next button) -> verify counter advances to `2 of 3`.
   - Click `#pdf-search-prev` (Prev button) -> verify counter returns to `1 of 3`.

6. **Close Search**:
   - Click `#pdf-search-close` (or press Escape).
   - Verify `#pdf-search-bar` is hidden.

7. **Triple-Channel Verification Contract (UI vs. REST vs. MCP)**:

| Channel | Input Payload / Action | Expected Output | Assertion Command |
|---|---|---|---|
| **Channel 1 (UI)** | Search `SERIAL-777` via `#pdf-search-input` | Matches count reads `1 of 3`, highlights yellow | `#pdf-search-count` contains `1 of 3` |
| **Channel 2 (REST)** | `POST /api/v1/pdf/extract-text` (`query=SERIAL-777`) | `HTTP 200` + JSON with 3 occurrences on pages [1, 3, 5] | `curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/extract-text -F "file=@tests/e2e_fixtures/search_test.pdf" -F "query=SERIAL-777" \| grep '"total_matches":3'` |
| **Channel 2 (REST)** | `POST /api/v1/pdf/tools/extract_text` | `HTTP 200` + Dump of raw text containing query | `curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/tools/extract_text -H "Content-Type: application/json" -d '{"input":"tests/e2e_fixtures/search_test.pdf","output":"/tmp/search_out.txt"}' && grep 'SERIAL-777' /tmp/search_out.txt` |
| **Channel 3 (MCP stdio)** | `tools/call` (`pdf_search`, `query: "SERIAL-777"`) | JSON-RPC result listing matching pages [1, 3, 5] | `echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"pdf_search","arguments":{"input":"tests/e2e_fixtures/search_test.pdf","query":"SERIAL-777"}}}' \| cargo run -p paperpilot-mcp \| grep 'SERIAL-777'` |

- **Strict Parity Rule**: The number of search matches and target pages highlighted in UI must match the occurrences reported by REST and MCP search tools.
