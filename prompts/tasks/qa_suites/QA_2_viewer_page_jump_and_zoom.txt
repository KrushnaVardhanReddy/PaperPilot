## 🎯 MISSION OBJECTIVE

Jules, you are our Senior Autonomous QA Engineer.
Your mission is to:
1. Generate a multi-page test PDF **using PaperPilot's conversion engine** with clear, prominent page numbers (e.g. Page 1, Page 2, Page 3, Page 4, Page 5) on every page.

## STEP 2: LAUNCH & TEST VIA AGENT BROWSER

1. Start dev server:
   ```bash
   npm --prefix apps/desktop run dev &
   sleep 3
   ```

2. Open app and load `tests/e2e_fixtures/multi_page_numbered.pdf`:
   ```bash
   npx --prefix apps/desktop agent-browser open "http://localhost:5173"
   npx --prefix apps/desktop agent-browser snapshot -i
   ```

3. **Verify Page Total**:
   - Total pages indicator `#toolbar-page-total` must show `/ 5`.
   - Current page input `#toolbar-page-input` must show `1`.

4. **Test Page Jump**:
   - Fill `#toolbar-page-input` with `4` and press Enter.
   - Verify the viewer updates and `#toolbar-page-input` reflects `4`.

5. **Test Zoom Preset Dropdown**:
   - Check `#toolbar-zoom-select`:
     - Must show legible white/light text against dark background (no white-on-white text).
   - Change zoom value to `150`:
     ```bash
     npx --prefix apps/desktop agent-browser fill "#toolbar-zoom-select" "150"
     ```
   - Click `#toolbar-zoom-fit` (Fit button).
   - Verify zoom recalculates and canvas scales to viewport.

6. **Triple-Channel Verification: Headless Page Render via REST & MCP**:
   - Ensure the server endpoint can render and rasterize pages headlessly across channels:
     ```bash
     # ── CHANNEL 2: REST API (Port 7823) ──
     # 1. Convenience Render Endpoint:
     curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/render-page \
       -F "file=@tests/e2e_fixtures/multi_page_numbered.pdf" \
       -F "page=4" \
       -F "dpi=150" \
       -o /tmp/page_4_rendered.png

     # 2. Dynamic 44-Tool Router:
     curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/tools/render \
       -H "Content-Type: application/json" \
       -d '{"input": "tests/e2e_fixtures/multi_page_numbered.pdf", "page": 4, "dpi": 150, "output": "/tmp/page_4_rendered_dynamic.png"}'

     # ── CHANNEL 3: MCP PROTOCOL ──
     # 3. Render via Remote MCP SSE/HTTP:
     curl -s -X POST "http://127.0.0.1:7823/mcp/messages?sessionId=qa2-test" \
       -H "Content-Type: application/json" \
       -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"pdf_render","arguments":{"input":"tests/e2e_fixtures/multi_page_numbered.pdf","page":4,"dpi":150,"output":"/tmp/page_4_rendered_mcp.png"}}}'
     ```
   - Verify `/tmp/page_4_rendered.png` and `/tmp/page_4_rendered_mcp.png` exist and are valid PNG images.
