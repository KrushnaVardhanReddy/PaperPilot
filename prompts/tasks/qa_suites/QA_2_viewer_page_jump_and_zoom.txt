## STEP 2: LAUNCH & TEST VIA AGENT BROWSER

1. Start dev server:
   ```bash
   npm --prefix apps/desktop run dev &
   sleep 3
   ```

2. Open app and load `tests/e2e_fixtures/multi_page_numbered.pdf`:
   ```bash
   npx --prefix apps/desktop agent-browser open "http://localhost:1420"
   npx --prefix apps/desktop agent-browser snapshot -i
   ```

3. **Verify Page Total**:
   - Total pages indicator `#toolbar-page-total` must show `/ 5`.
   - Current page input `#toolbar-page-input` must show `1`.

4. **Test Page Jump**:
   - Fill `#toolbar-page-input` with `4` and press Enter.
   - Verify the viewer updates and `#toolbar-page-input` reflects `4`.

5. **Test Zoom Preset Dropdown**:
   - Check `#toolbar-zoom-select`:
     - Must show legible white/light text against dark background (no white-on-white text).
   - Change zoom value to `150`:
     ```bash
     npx --prefix apps/desktop agent-browser fill "#toolbar-zoom-select" "150"
     ```
   - Click `#toolbar-zoom-fit` (Fit button).
   - Verify zoom recalculates and canvas scales to viewport.

6. **Triple-Channel Semantic Verification Contract (UI vs. REST vs. MCP)**:

| Channel | Input Payload / Action | Expected Semantic Result | Strict Verification Command |
|---|---|---|---|
| **Channel 1 (UI)** | Type page `4` in `#page-jump-input` + Press Enter | Canvas scrolls to Page 4, renders "Header 4" | `#page-jump-input` value is `4`, canvas renders |
| **Channel 2 (REST)** | `POST /api/v1/pdf/render-page` (`page=4, dpi=150`) | Output file is genuine raster PNG image (not HTML error or 0-byte file) | `curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/render-page -F "file=@tests/e2e_fixtures/multi_page_numbered.pdf" -F "page=4" -F "dpi=150" -o /tmp/page_4_rendered.png && file /tmp/page_4_rendered.png \| grep 'PNG image data'` |
| **Channel 2 (REST)** | `POST /api/v1/pdf/tools/pdf_render` (`page: 4`) | Dynamic tool renders verified PNG | `curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/tools/pdf_render -H "Content-Type: application/json" -d '{"input":"tests/e2e_fixtures/multi_page_numbered.pdf","page":4,"dpi":150,"output":"/tmp/page_4_dynamic.png"}' && file /tmp/page_4_dynamic.png \| grep 'PNG image data'` |
| **Channel 2 (REST)** | `POST /api/v1/pdf/tools/pdf_classify_type` | Document classified as digital native / scanned | `curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/tools/pdf_classify_type -H "Content-Type: application/json" -d '{"input":"tests/e2e_fixtures/multi_page_numbered.pdf"}' \| grep -q 'pdf_type\|text_based\|searchable'` |
| **Channel 3 (MCP SSE)** | `POST /mcp/messages` (`pdf_render`) | MCP tool rasterizes real PNG image | `curl -s -X POST "http://127.0.0.1:7823/mcp/messages?sessionId=qa2-test" -H "Content-Type: application/json" -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"pdf_render","arguments":{"input":"tests/e2e_fixtures/multi_page_numbered.pdf","page":4,"dpi":150,"output":"/tmp/page_4_mcp.png"}}}' && file /tmp/page_4_mcp.png \| grep 'PNG image data'` |
| **Channel 3 (MCP stdio)** | `tools/call` (`pdf_bookmarks`) | Returns document outline tree / bookmarks | `echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"pdf_bookmarks","arguments":{"input":"tests/e2e_fixtures/multi_page_numbered.pdf"}}}' \| cargo run -p paperpilot-mcp \| grep -q 'bookmarks\|outline'` |

- **Strict Rasterization & Inspection Rule**: Inspecting HTTP 200 is NOT sufficient. You MUST execute `file <output.png>` to assert that the file header begins with PNG magic bytes `\x89PNG` and contains valid image data.
