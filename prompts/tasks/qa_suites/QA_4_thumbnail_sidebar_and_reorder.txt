1. Start dev server:
   ```bash
   npm --prefix apps/desktop run dev &
   sleep 3
   ```

2. Open app and load `tests/e2e_fixtures/thumbnail_test.pdf`:
   ```bash
   npx --prefix apps/desktop agent-browser open "http://localhost:5173"
   npx --prefix apps/desktop agent-browser snapshot -i
   ```

3. **Verify Thumbnail Sidebar**:
   - Ensure the left thumbnail sidebar is open and shows 3 thumbnail cards (`.thumbnail-card` or `#thumb-page-1`, `#thumb-page-2`, `#thumb-page-3`).

4. **Test Quick Actions on Hover**:
   - Locate hover action buttons for page 2:
     - Rotate 90° button (`#thumb-rotate-2` or `.thumb-btn-rotate`).
     - Click rotate and verify page rotation angle updates in state.

5. **Test Page Reorder**:
   - Simulate dragging page 3 before page 1 (or clicking move-up action).
   - Verify page sequence reflects the new order.

6. **Triple-Channel Semantic Verification Contract (UI vs. REST vs. MCP)**:

| Channel | Input Payload / Action | Expected Semantic Result | Strict Verification Command |
|---|---|---|---|
| **Channel 1 (UI)** | Click `#thumb-rotate-1` (rotate page 2 by 90°) | Thumbnail 2 renders landscape orientation | `#thumb-1` has rotated canvas class |
| **Channel 2 (REST)** | `POST /api/v1/pdf/rotate` (`pages=2, angle=90`) | Output PDF exists and Page 2 rotation strictly equals 90 degrees | `curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/rotate -F "file=@tests/e2e_fixtures/thumbnail_test.pdf" -F "pages=2" -F "angle=90" -o /tmp/rotated_api.pdf && cargo run -p paperpilot-cli -- info --input /tmp/rotated_api.pdf \| grep -E 'Page 2.*90|Rotate.*90'` |
| **Channel 2 (REST)** | `POST /api/v1/pdf/tools/rotate` | Rotated output file is structurally valid | `curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/tools/rotate -H "Content-Type: application/json" -d '{"input":"tests/e2e_fixtures/thumbnail_test.pdf","pages":"2","angle":90,"output":"/tmp/rotated_tools.pdf"}' && cargo run -p paperpilot-cli -- validate --input /tmp/rotated_tools.pdf` |
| **Channel 3 (MCP stdio)** | `tools/call` (`pdf_rotate`, `pages: "2", angle: 90`) | Operation reports success and output file validates | `echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"pdf_rotate","arguments":{"input":"tests/e2e_fixtures/thumbnail_test.pdf","pages":"2","angle":90,"output":"/tmp/rotated_mcp.pdf"}}}' \| cargo run -p paperpilot-mcp \| grep -q '"success":true' && cargo run -p paperpilot-cli -- validate --input /tmp/rotated_mcp.pdf` |

- **Strict Orientation Rule**: You MUST run `cargo run -p paperpilot-cli -- info --input <rotated.pdf>` and `validate` to verify that the internal PDF page dictionary `/Rotate` key is actually modified to 90 degrees.
