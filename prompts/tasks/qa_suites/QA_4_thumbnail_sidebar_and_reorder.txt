## STEP 1: CREATE TEST PDF WITH GIANT NUMBERED PAGES

```bash
cat << 'EOF' > /tmp/thumbnail_test.md
# PAGE 111 - ALPHA

<div style="page-break-after: always;"></div>

# PAGE 222 - BETA
Unique fingerprint: 222-BBB

<div style="page-break-after: always;"></div>

cargo run -p paperpilot-cli -- convert --format pdf --input /tmp/thumbnail_test.md --output tests/e2e_fixtures/thumbnail_test.pdf --css-preset modern
```

1. Start dev server:
   ```bash
   npm --prefix apps/desktop run dev &
   sleep 3
   ```

2. Open app and load `tests/e2e_fixtures/thumbnail_test.pdf`:
   ```bash
   npx --prefix apps/desktop agent-browser open "http://localhost:5173"
   npx --prefix apps/desktop agent-browser snapshot -i
   ```

3. **Verify Thumbnail Sidebar**:
   - Ensure the left thumbnail sidebar is open and shows 3 thumbnail cards (`.thumbnail-card` or `#thumb-page-1`, `#thumb-page-2`, `#thumb-page-3`).

4. **Test Quick Actions on Hover**:
   - Locate hover action buttons for page 2:
     - Rotate 90° button (`#thumb-rotate-2` or `.thumb-btn-rotate`).
     - Click rotate and verify page rotation angle updates in state.

5. **Test Page Reorder**:
   - Simulate dragging page 3 before page 1 (or clicking move-up action).
   - Verify page sequence reflects the new order.

6. **Dual-Channel Verification: REST API Page Reorder & Rotate**:
   - Verify identical page manipulation via REST API:
     ```bash
     curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/rotate \
       -F "file=@tests/e2e_fixtures/thumbnail_test.pdf" \
       -F "pages=2" \
       -F "angle=90" \
       -o /tmp/rotated_via_api.pdf
     ```
   - Assert `/tmp/rotated_via_api.pdf` exists and is a valid 3-page PDF.
