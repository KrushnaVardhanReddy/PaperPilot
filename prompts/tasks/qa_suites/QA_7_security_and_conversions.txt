   ```bash

   ```

   ```bash

   ```

3. **Test Encrypt Tool**:
   - Filter search by typing `encrypt`.
   - Click `#tool-encrypt`.
   - Fill password field `#password` with `vault999`.
   - Click `#btn-run-operation`.
   - Verify success toast appears.
   - Click `#btn-back-tools`.

4. **Test Metadata Sanitization**:
   - Filter search by typing `metadata`.
   - Click `#tool-metadata`.
   - Fill title input with `Sanitized Document 999`.
   - Click `#btn-run-operation`.
   - Verify success toast appears.

5. **Triple-Channel Verification: REST API & MCP Security Tools**:
   - Ensure metadata, inspection, and security tools work identically across all channels:
     ```bash
     # ── CHANNEL 2: REST API (Port 7823) ──
     # 1. Metadata Inspection:
     curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/info \
       -F "file=@tests/e2e_fixtures/secret_999.pdf"

     # 2. Dynamic 44-Tool Router Encryption:
     curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/tools/encrypt \
       -H "Content-Type: application/json" \
       -d '{"input": "tests/e2e_fixtures/secret_999.pdf", "password": "vault999", "output": "/tmp/secret_999_enc.pdf"}'

     # ── CHANNEL 3: MCP PROTOCOL ──
     # 3. Encrypt via MCP stdio:
     echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"pdf_encrypt","arguments":{"input":"tests/e2e_fixtures/secret_999.pdf","password":"vault999","output":"/tmp/secret_999_mcp_enc.pdf"}}}' | cargo run -p paperpilot-mcp
     ```
   - Verify encrypted output exists across both REST and MCP channels.
