## STEP 1: CREATE TEST DOCUMENTS VIA CLI

```bash
cat << 'EOF' > /tmp/part_10.md
# Document 10 - Section A
First chunk of data with identifier #10.
EOF

cat << 'EOF' > /tmp/part_20.md
# Document 20 - Section B
Second chunk of data with identifier #20.
EOF

cargo run -p paperpilot-cli -- convert --format pdf --input /tmp/part_10.md --output tests/e2e_fixtures/part_10.pdf
cargo run -p paperpilot-cli -- convert --format pdf --input /tmp/part_20.md --output tests/e2e_fixtures/part_20.pdf
```

## STEP 2: LAUNCH & TEST VIA AGENT BROWSER

1. Start dev server:
   ```bash
   npm --prefix apps/desktop run dev &
   sleep 3
   ```

2. Open app and load `tests/e2e_fixtures/part_10.pdf` and `tests/e2e_fixtures/part_20.pdf`:
   ```bash
   npx --prefix apps/desktop agent-browser open "http://localhost:5173"
   npx --prefix apps/desktop agent-browser snapshot -i
   ```

3. **Test Category Filter Pills**:
   - Locate category pills (`.pill-btn`).
   - Click `Pages` pill -> verify only page management tools are visible.
   - Click `All` pill -> verify all tool sections return.

4. **Test Search Filter**:
   - Type `merge` into `#tool-search-input`.
   - Click `#tool-merge`.
   - Verify inspector mode opens with `#btn-back-tools` and reorder list.
   - Click `#btn-run-operation`.
   - Verify success toast `.toast-success` appears.
   - Click `#btn-back-tools` to return to directory.

5. **Test Split Tool**:
   - Click `#tool-split`.
   - Fill `#splitPoints` with `1`.
   - Click `#btn-run-operation`.
   - Verify execution completes.

6. **Dual-Channel Verification: REST API Execution**:
   - Ensure the server endpoint processes the exact same fixtures via HTTP:
     ```bash
     curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/merge \
       -F "files=@tests/e2e_fixtures/part_10.pdf" \
       -F "files=@tests/e2e_fixtures/part_20.pdf" \
       -o /tmp/api_merged_6.pdf
     ```
   - Verify `/tmp/api_merged_6.pdf` exists and page count is 2.
