## 🎯 MISSION OBJECTIVE

Jules, you are our Senior Autonomous QA Engineer.
Your mission is to:
1. Generate two numbered revisions of a contract **using PaperPilot's conversion engine**:
   - `contract_v1.pdf` (contains `$10,000` price tag)
   - `contract_v2.pdf` (contains modified `$15,000` price tag)
2. Launch the desktop app and open both documents in tabs.
3. Open the **Visual Split-Screen Pixel Diff Slider** (`Ctrl+D` or compare tool).
4. Verify:
   - Split slider handle dragging works.
   - Discrepancy highlights the changed price area.
   - Mode toggling between Split, Overlay, and Side-by-Side functions smoothly.
5. Verify PDF comparison parity via the REST API endpoint (`/api/v1/pdf/compare`).
6. If ANY canvas rendering error or slider drag defect occurs, fix the code and submit a green PR.

## STEP 1: CREATE TWO NUMBERED REVISIONS VIA CLI

```bash
cat << 'EOF' > /tmp/contract_v1.md
# Master Services Agreement Revision 1
- Client: Acme Corp
- Total Contract Fee: $10,000.00
- Payment Schedule: Net 30
EOF

cat << 'EOF' > /tmp/contract_v2.md
# Master Services Agreement Revision 2
- Client: Acme Corp
- Total Contract Fee: $15,000.00
- Payment Schedule: Net 15
EOF

cargo run -p paperpilot-cli -- convert --format pdf --input /tmp/contract_v1.md --output tests/e2e_fixtures/contract_v1.pdf --css-preset corporate
cargo run -p paperpilot-cli -- convert --format pdf --input /tmp/contract_v2.md --output tests/e2e_fixtures/contract_v2.pdf --css-preset corporate
```


2. Open app and load `tests/e2e_fixtures/contract_v1.pdf` and `tests/e2e_fixtures/contract_v2.pdf`:
   ```bash
   npx --prefix apps/desktop agent-browser open "http://localhost:1420"
   npx --prefix apps/desktop agent-browser snapshot -i
   ```

3. **Open Visual Pixel Diff**:
   - Press shortcut `ControlOrMeta+d`:
     ```bash
     npx --prefix apps/desktop agent-browser keyboard press "ControlOrMeta+d"
     ```
   - Verify `#visual-diff-container` is visible.

4. **Verify Slider & Modes**:
   - Check `#diff-split-handle` is visible.
   - Click `#diff-mode-overlay` -> verify `#diff-overlay-canvas` appears.
   - Click `#diff-mode-side-by-side` -> verify dual side-by-side view.
   - Click `#diff-close-btn` -> verify diff modal closes.

5. **Triple-Channel Verification Contract (UI vs. REST vs. MCP)**:

| Channel | Input Payload / Action | Expected Output | Assertion Command |
|---|---|---|---|
| **Channel 1 (UI)** | Open Diff (`Ctrl+D`) comparing `contract_v1` & `contract_v2` | `#visual-diff-container` visible, highlight map displays diff on line fee | `#visual-diff-container` visible |
| **Channel 2 (REST)** | `POST /api/v1/pdf/compare` (`files=[v1, v2]`) | `HTTP 200` + JSON report marking page 1 diffs | `curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/compare -F "file1=@tests/e2e_fixtures/contract_v1.pdf" -F "file2=@tests/e2e_fixtures/contract_v2.pdf" \| grep '"diff_detected":true'` |
| **Channel 2 (REST)** | `POST /api/v1/pdf/tools/compare` | `HTTP 200` + Diff JSON result | `curl -s -X POST http://127.0.0.1:7823/api/v1/pdf/tools/compare -H "Content-Type: application/json" -d '{"file_a":"tests/e2e_fixtures/contract_v1.pdf","file_b":"tests/e2e_fixtures/contract_v2.pdf"}' \| grep -i 'diff'` |
| **Channel 3 (MCP stdio)** | `tools/call` (`pdf_compare`) | JSON-RPC result confirming changes detected | `echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"pdf_compare","arguments":{"file_a":"tests/e2e_fixtures/contract_v1.pdf","file_b":"tests/e2e_fixtures/contract_v2.pdf"}}}' \| cargo run -p paperpilot-mcp \| grep -i 'diff'` |

- **Strict Parity Rule**: Visual pixel discrepancies highlighted on canvas must match the exact diff regions and page numbers detected by REST and MCP comparison tools.
