## Technical Requirements & Test Flow

### 1. Zero Mocking (Real IPC Bridge)
- Unlike unit/component tests, this test interacts with the live backend IPC.
- Uses `tests/fixtures/sample.pdf` or creates a real sample PDF fixture.

### 2. Required Test Scenarios
1. **Implicit Active Document Binding**:
   - Open a document in the viewer.
   - Switch to the `💬 AI Chat` tab.
   - Type `"Split pages 1 to 2"` (or click the suggestion chip).
   - Verify the assistant responds with an Action Card targeting the open document.
   - Click `[Execute Action]`.
   - Verify success toast and check that output files exist.

2. **Semantic / TinyBERT Classification**:
   - Type `"rotate 90 degrees"` or `"squish this document"`.
   - Verify the intent is resolved and action card is rendered.
   - Execute the action and verify the rotated/compressed PDF.

3. **Multi-Turn Conversation**:
   - Verify follow-up questions or commands maintain conversation state.

### 3. Generate Report
Generate `reports/AI_CHAT_REAL_PIPELINE_E2E_REPORT.md` documenting:
- Test scenarios executed.
- Latency from user prompt to action card display.
- Verification of actual output files generated on disk.
