## 1. Tauri Backend Commands (`apps/desktop/src-tauri/src/ai_commands.rs`)
Expose Tauri IPC commands:
1. `get_available_models()` -> Returns list of curated models (name, size_mb, download_url, local_path, is_downloaded).
2. `download_model(model_id: String)` -> Emits Tauri events `model-download-progress { percent, bytes_downloaded, total_bytes }`.
3. `cancel_model_download(model_id: String)`.
4. `save_ai_config(config: AiSettingsConfig)`.
5. `get_ai_config() -> AiSettingsConfig`.
6. `test_ai_endpoint(config: AiSettingsConfig) -> Result<String, String>` -> Pings endpoint `/v1/models` and returns latency in ms.
