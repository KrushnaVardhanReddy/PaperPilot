# Task: Phase 4.8.4 — Expand WASM Engine and Web Suite to 12 Pure-Rust Tools

## Objective
Expand `paperpilot-wasm` and `apps/web/` from 6 tools to 12 pure-Rust in-browser tools.
All operations execute 100% in browser memory with zero filesystem access and zero network requests.

## Requirements
- Use pure Rust (`lopdf`) in `paperpilot-wasm` to process in-memory buffers (`&[u8]` and `Vec<u8>`).
- Expose all 6 new operations through `wasm-bindgen` on `WasmPdfEngine`.
- Update the Web Worker bridge in both `apps/desktop` and `apps/web` to pass messages asynchronously off the main thread.
- Build dedicated interactive UI cards with parameter controls in `apps/web/src/views/OperationsView.svelte` with instant browser downloads.
- Generate verification report at `reports/WASM_12_TOOLS_EXPANSION_REPORT.md` and documentation in `wiki/06-Wasm-12-Tools-Suite.md`.

### 1. Component Structure
You will need to create or update the following files:
1. **`paperpilot-wasm/src/operations.rs`** -> Implement the 6 pure-memory Rust operations.
2. **`paperpilot-wasm/src/lib.rs`** -> Export the 6 operations via `WasmPdfEngine` methods.
3. **`paperpilot-wasm/tests/wasm_tests.rs`** -> Add comprehensive unit tests for each new operation.
4. **`apps/web/src/lib/wasm/pdfWorker.ts`** & **`apps/web/src/lib/wasm/index.ts`** -> Web Worker message dispatch and client interface.
5. **`apps/desktop/src/lib/wasm/pdfWorker.ts`** & **`apps/desktop/src/lib/wasm/index.ts`** -> Keep desktop WASM client parity aligned.
6. **`apps/web/src/views/OperationsView.svelte`** -> Expand the `tools` array to 12 tools and add parameter inputs/actions.

### 2. Implementation Details

#### A. The 6 New In-Memory Operations (`paperpilot-wasm/src/operations.rs`)
Implement the following pure `lopdf` memory operations returning `OperationResult<Vec<u8>>`:

1. **Delete Pages (`delete_pages`)**:
   ```rust
   pub fn delete_pages(input_bytes: &[u8], pages_str: &str) -> OperationResult<Vec<u8>>
   ```
   Parse comma and range format (e.g. `"2, 4"` or `"1-3"`), validate 1-based page indices against `doc.get_pages()`, call `doc.delete_pages(&to_delete)`, and save to memory buffer.

2. **Extract Pages (`extract_pages`)**:
   ```rust
   pub fn extract_pages(input_bytes: &[u8], pages_str: &str) -> OperationResult<Vec<u8>>
   ```
   Parse 1-based target pages, calculate complement `pages_to_delete = (1..=total).filter(|p| !targets.contains(p))`, delete them from cloned document, and save to memory buffer.

3. **Reorder Pages (`reorder_pages`)**:
   ```rust
   pub fn reorder_pages(input_bytes: &[u8], new_order: &[u32]) -> OperationResult<Vec<u8>>
   ```
   Validate that `new_order.len() == total_pages` with no duplicates. Re-index pages according to the array order and emit result bytes.

4. **Crop Pages (`crop`)**:
   ```rust
   pub fn crop(input_bytes: &[u8], left: f32, bottom: f32, right: f32, top: f32) -> OperationResult<Vec<u8>>
   ```
   Iterate over `doc.get_pages()`, set `/CropBox` array `[Real(left), Real(bottom), Real(right), Real(top)]` on each page dictionary.

5. **Flatten Form Fields (`flatten`)**:
   ```rust
   pub fn flatten(input_bytes: &[u8]) -> OperationResult<Vec<u8>>
   ```
   Find root `/Catalog` object in `doc.trailer`, remove `/AcroForm` entry from dictionary, and serialize bytes.

6. **Edit Metadata (`set_metadata`)**:
   ```rust
   pub fn set_metadata(
       input_bytes: &[u8],
       title: Option<String>,
       author: Option<String>,
       subject: Option<String>,
       keywords: Option<String>,
   ) -> OperationResult<Vec<u8>>
   ```
   Find or create `/Info` dictionary reference in trailer, update provided `/Title`, `/Author`, `/Subject`, `/Keywords` as `Object::String` (PDF DocEncoding), and emit bytes.

#### B. Wasm Exports (`paperpilot-wasm/src/lib.rs`)
Export each method on `WasmPdfEngine` with appropriate `js_sys` / `wasm_bindgen` types:
- `pub fn delete_pages(input_bytes: &[u8], pages: &str) -> Result<js_sys::Uint8Array, JsValue>`
- `pub fn extract_pages(input_bytes: &[u8], pages: &str) -> Result<js_sys::Uint8Array, JsValue>`
- `pub fn reorder_pages(input_bytes: &[u8], new_order: Vec<u32>) -> Result<js_sys::Uint8Array, JsValue>`
- `pub fn crop(input_bytes: &[u8], left: f32, bottom: f32, right: f32, top: f32) -> Result<js_sys::Uint8Array, JsValue>`
- `pub fn flatten(input_bytes: &[u8]) -> Result<js_sys::Uint8Array, JsValue>`
- `pub fn set_metadata(input_bytes: &[u8], title: Option<String>, author: Option<String>, subject: Option<String>, keywords: Option<String>) -> Result<js_sys::Uint8Array, JsValue>`
