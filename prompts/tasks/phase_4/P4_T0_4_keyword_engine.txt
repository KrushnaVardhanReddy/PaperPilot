## Context
Our offline NLP pipeline uses a 2-layer approach:
1. **Layer 1 (Rule Engine):** A blazing fast (<1ms) keyword and regex matcher. If a user's query perfectly matches a known alias (e.g., "combine pdfs"), Layer 1 immediately returns `Intent::Merge`, completely bypassing the heavy ML models. This handles ~80% of real-world queries.
2. **Layer 2 (ONNX):** A fallback embedding model (built later in 4.0.5) used only if Layer 1 fails to find a confident match.
