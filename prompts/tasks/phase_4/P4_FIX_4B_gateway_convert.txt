## Required Fixes

### 1. `handlers.rs` — Forward JSON requests on `/api/v1/pdf/convert` to target tools
**Issue:**
When clients POST to `/api/v1/pdf/convert` with JSON:
```json
{
  "input": "document.pdf",
  "output": "document.docx",
  "format": "docx"
}
```
`handle_tool` receives `tool_name = "convert"`. It tries to resolve it as `pdf_convert`, which does not exist in `paperpilot-mcp` (the MCP tools are named `pdf_to_docx`, `pdf_to_xlsx`, `pdf_to_pptx`, etc.), returning HTTP 500.

**Fix:**
In `paperpilot-gateway/src/handlers.rs`:
In `handle_tool` (around line 242) or in `pub async fn convert`:
- If `tool_name == "convert"` or `resolved_name == "pdf_convert"`:
  - Check the `format` argument in `args`:
    - `"docx"` => map `resolved_name = "pdf_to_docx".to_string();`
    - `"xlsx"` => map `resolved_name = "pdf_to_xlsx".to_string();`
    - `"pptx"` => map `resolved_name = "pdf_to_pptx".to_string();`
    - `"html"` => map `resolved_name = "pdf_convert_html".to_string();`
    - `"markdown"` => map `resolved_name = "pdf_convert_markdown".to_string();`
    - `"excel"` | `"csv"` => map `resolved_name = "pdf_convert_excel".to_string();`
- Ensure that the execution completes and returns HTTP 200 with the operation result.
