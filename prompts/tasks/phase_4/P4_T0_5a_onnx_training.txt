---

## What to Build

We need a Python training pipeline that fine-tunes a tiny NLP model (like `prajjwal1/bert-tiny` or `distilbert-base-uncased`) on PDF commands, and exports the final model to ONNX format so we can later run it via the `ort` crate in Rust.

### 1. Setup the Directory
Create a new directory at the root of the repo: `tools/train-nlp/`
Create a `requirements.txt` containing the necessary libraries (e.g., `transformers`, `torch`, `optimum`, `onnxruntime`, `scikit-learn`, `datasets`).

### 2. Dataset Generation
Create a script `tools/train-nlp/generate_data.py`.
It should programmatically generate a synthetic JSON/CSV dataset of natural language queries mapped to our PDF intents.
For example:
- "combine these documents" -> `Merge`
- "put a password on this" -> `Encrypt`
- "pull out page 5" -> `Extract`
- "make this a docx" -> `ToDocx`
Include at least 20-30 variations for each of the core ~35 intents. You can use standard data augmentation/templating (e.g., swapping "file", "document", "pdf").

### 3. Training & ONNX Export Script
Create `tools/train-nlp/train.py`.
This script should:
1. Load the dataset generated in step 2.
2. Load a tiny pretrained model (e.g. `prajjwal1/bert-tiny` which is only ~17MB).
3. Fine-tune the model for sequence classification using the HuggingFace `Trainer`.
4. Export the fine-tuned model and its tokenizer to ONNX format using HuggingFace `optimum` (e.g. `ORTModelForSequenceClassification.from_pretrained(..., export=True)`).
5. Save the resulting `model.onnx` and tokenizer files to an `output/` directory.

### 4. Verification
Create a quick `tools/train-nlp/infer.py` script that loads the exported ONNX model using `onnxruntime` and tests a few sample queries to ensure the export worked correctly.
