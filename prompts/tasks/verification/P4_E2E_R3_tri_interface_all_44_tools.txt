## CONTEXT & OBJECTIVE

PaperPilot now has 44 PDF operations available across:
1. **CLI**: `paperpilot <subcommand> ... --json`
2. **MCP**: stdio JSON-RPC `{"jsonrpc":"2.0","method":"tools/call","params":{"name":"pdf_...","arguments":{...}}}`
3. **REST API**: HTTP POST `http://127.0.0.1:7823/api/v1/pdf/...` or `/api/v1/pdf/tools/{tool_name}`

We need an automated master verification harness and living documentation generator:
`scripts/test_tri_interface_e2e.py`

This script will run every tool, inspect the input PDF and output PDF (file size, page counts, format check), and generate a comprehensive reference manual and validation report at `reports/TRI_INTERFACE_E2E_AND_DOCS.md`.

## STEP 1: Implement `scripts/test_tri_interface_e2e.py`

The script must:
1. **Manage Environment**:
   - Locate/build binaries: `target/debug/paperpilot-cli`, `target/debug/paperpilot-mcp`, and `target/debug/paperpilot-gateway`.
   - Check if `paperpilot-gateway` is running on port 7823 (e.g., ping `http://127.0.0.1:7823/health`). If not, spawn it in background and terminate on exit.
   - Ensure fixtures in `tests/e2e_fixtures` are available.
   - Create clean output test directory: `tests/e2e_fixtures/out/tri_e2e/`.

2. **Snapshot Pre-Execution State**:
   - For every test, record:
     - `input_path`
     - `input_size_bytes`
     - `input_pages` (inspect using binary parser or quick regex / lopdf)

3. **Execute across all 3 Interfaces**:
   - **CLI**:
     - Command: `./target/debug/paperpilot-cli <subcommand> [flags] --json`
     - Measure latency in ms, capture exit code, stdout, and stderr.
   - **MCP**:
     - Command: pipe JSON-RPC `{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"pdf_<name>","arguments":{...}}}` to `./target/debug/paperpilot-mcp`.
     - Measure latency in ms, parse JSON-RPC response.
   - **REST API**:
     - Request: POST JSON to `http://127.0.0.1:7823/api/v1/pdf/tools/pdf_<name>` (or dedicated route).
     - Measure latency in ms, capture HTTP status code and response payload.

4. **Snapshot Post-Execution State & Assertions**:
   - Record:
     - `output_path`
     - `output_size_bytes`
     - `size_delta_bytes`
     - `output_pages`
     - Format integrity verification (magic bytes: `%PDF` for PDF, `PK\x03\x04` for docx/xlsx/pptx, `\x89PNG` for PNG, valid text for txt/md/json).
   - Assert:
     - Did output get created?
     - Did command return success?
     - If failed: DO NOT FIX CODE, capture exact error details.

5. **Generate Living Documentation & Report**:
   - Write to `reports/TRI_INTERFACE_E2E_AND_DOCS.md`.
