### 2. Implementation Details

#### Tool Specifications for Batch 2 (Tools 11–20)
Map each tool with exact commands, inputs, and outputs in `scripts/test_tri_interface_e2e.py`:

11. **Encrypt (`pdf_encrypt`)**:
   - Input: `single_page.pdf`
   - Output: `out/tri_e2e/encrypted_test.pdf`
   - CLI: `encrypt --input {in} --password "secret123" --output {out}`
   - MCP: `{"name":"pdf_encrypt", "arguments":{"input":in, "user_password":"secret123", "owner_password":"secret123", "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_encrypt` with `{"input":in, "user_password":"secret123", "output":out}`
12. **Decrypt (`pdf_decrypt`)**:
   - Input: `encrypted.pdf` (password: "password123" or "secret123")
   - Output: `out/tri_e2e/decrypted_test.pdf`
   - CLI: `decrypt --input {in} --password "password123" --output {out}`
   - MCP: `{"name":"pdf_decrypt", "arguments":{"input":in, "password":"password123", "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_decrypt` with `{"input":in, "password":"password123", "output":out}`
13. **Redact (`pdf_redact`)**:
   - Input: `search_test.pdf`
   - Output: `out/tri_e2e/redacted_test.pdf`
   - CLI: `redact --input {in} --text "Confidential" --output {out}`
   - MCP: `{"name":"pdf_redact", "arguments":{"input":in, "page":1, "x":50, "y":50, "width":200, "height":50, "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_redact` with `{"input":in, "page":1, "x":50, "y":50, "width":200, "height":50, "output":out}`
14. **Sign (`pdf_sign`)**:
   - Input: `single_page.pdf`
   - Output: `out/tri_e2e/signed_test.pdf`
   - CLI: `sign --input {in} --reason "Verified" --output {out}`
   - MCP: `{"name":"pdf_sign", "arguments":{"input":in, "output":out, "reason":"Verified"}}`
   - API: `POST /api/v1/pdf/tools/pdf_sign` with `{"input":in, "output":out, "reason":"Verified"}`
15. **Validate (`pdf_validate`)**:
   - Input: `single_page.pdf`
   - Output: JSON boolean status
   - CLI: `validate --input {in}`
   - MCP: `{"name":"pdf_validate", "arguments":{"input":in}}`
   - API: `POST /api/v1/pdf/tools/pdf_validate` with `{"input":in}`
16. **Hash (`pdf_hash`)**:
   - Input: `single_page.pdf`
   - Output: SHA-256 hash string
   - CLI: `hash --input {in}`
   - MCP: `{"name":"pdf_hash", "arguments":{"input":in}}`
   - API: `POST /api/v1/pdf/tools/pdf_hash` with `{"input":in}`
17. **Repair (`pdf_repair`)**:
   - Input: `repaired.pdf` (or `single_page.pdf`)
   - Output: `out/tri_e2e/repaired_test.pdf`
   - CLI: `repair --input {in} --output {out}`
   - MCP: `{"name":"pdf_repair", "arguments":{"input":in, "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_repair` with `{"input":in, "output":out}`
18. **Extract Text (`pdf_extract_text`)**:
   - Input: `search_test.pdf`
   - Output: `out/tri_e2e/extracted_text.txt` (or stdout text)
   - CLI: `extract-text --input {in} --output {out}`
   - MCP: `{"name":"pdf_extract_text", "arguments":{"input":in}}`
   - API: `POST /api/v1/pdf/extract-text` with `{"input":in}`
19. **Extract Images (`pdf_extract_images`)**:
   - Input: `image_doc.pdf`
   - Output: `out/tri_e2e/extracted_images/`
   - CLI: `extract-images --input {in} --output-dir {out}`
   - MCP: `{"name":"pdf_extract_images", "arguments":{"input":in, "output_dir":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_extract_images` with `{"input":in, "output_dir":out}`
20. **Images to PDF (`pdf_images_to_pdf`)**:
   - Input: `img1.png`, `img2.png`
   - Output: `out/tri_e2e/images_converted.pdf`
   - CLI: `images-to-pdf --input {img1} {img2} --output {out}`
   - MCP: `{"name":"pdf_images_to_pdf", "arguments":{"inputs":[img1, img2], "output":out}}`
   - API: `POST /api/v1/pdf/tools/pdf_images_to_pdf` with `{"inputs":[img1, img2], "output":out}`
