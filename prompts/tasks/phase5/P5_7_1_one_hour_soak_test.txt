## 1. Test Configuration (`scripts/stress_test.py`)
- Configure test harness to accept `--duration 3600` (or default 3600 seconds = 1 hour).
- **CRITICAL REQUIREMENT**: Must import and iterate through **ALL 44 TOOLS** directly from `scripts/test_tri_interface_e2e.py`'s verified tool definitions.
- Every cycle runs the complete battery of 44 operations:
  - Document manipulation (`merge`, `split`, `extract_pages`, `delete_pages`, `reorder_pages`, `rotate`, `crop`, `burst`, `remove_blank`)
  - Optimization & security (`compress`, `repair`, `linearize`, `encrypt`, `decrypt`, `watermark`, `redact`, `sign`, `flatten`, `to_pdf_a`)
  - Analysis & OCR (`extract_text`, `extract_images`, `search`, `render`, `compare`, `ocr`, `classify_type`, `validate`, `hash`)
  - Formatting & forms (`header_footer`, `bates`, `page_numbers`, `bookmarks`, `images_to_pdf`, `annotate`, `read_form`, `fill_form`, `create_form_field`)
  - Pure-Rust conversions (`to_docx`, `to_xlsx`, `to_pptx`, `convert_html`, `convert_markdown`, `convert_excel`)
- Log telemetry every 60 seconds (elapsed time, cycles completed, total operations, ops/sec, RSS in MB, failures).

## 2. Execution & Quality Gate
1. Build the production release binary:
   ```bash
   cargo build --release -p paperpilot-cli
   ```
2. Run the 1-hour endurance suite:
   ```bash
   python3 scripts/stress_test.py 3600
   ```
3. **Mandatory Acceptance Criteria**:
   - **100% Success Rate**: 0 crashes, 0 unexpected panics, 0 failed exits across 3,600 seconds.
   - **Zero Leaks**: Peak memory usage at minute 60 must not diverge or steadily grow compared to minute 5.
   - **Documented Tail Latencies**: Capture Min, Mean, Median (P50), P90, P95, P99, P99.9, and Max latency for every tested operation.
