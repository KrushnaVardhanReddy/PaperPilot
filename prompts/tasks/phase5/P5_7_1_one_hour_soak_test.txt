## 1. Test Configuration (`scripts/stress_test.py`)
- Configure test harness to accept `--duration 3600` (or default 3600 seconds = 1 hour).
- Include all 100% pure-Rust conversion operations alongside standard core operations:
  - `pdf_merge`, `pdf_split`, `pdf_rotate`, `pdf_compress`, `pdf_watermark`, `pdf_encrypt`
  - `pdf_extract_text`, `pdf_search`, `pdf_hash`, `pdf_ocr`, `pdf_bates`, `pdf_flatten`
  - `pdf_convert_excel`, `pdf_convert_markdown`, `pdf_convert_html`
- Log telemetry every 60 seconds (elapsed time, total operations, ops/sec, current RSS in MB, failures).

## 2. Execution & Quality Gate
1. Build the production release binary:
   ```bash
   cargo build --release -p paperpilot-cli
   ```
2. Run the 1-hour endurance suite:
   ```bash
   python3 scripts/stress_test.py 3600
   ```
3. **Mandatory Acceptance Criteria**:
   - **100% Success Rate**: 0 crashes, 0 unexpected panics, 0 failed exits across 3,600 seconds.
   - **Zero Leaks**: Peak memory usage at minute 60 must not diverge or steadily grow compared to minute 5.
   - **Documented Tail Latencies**: Capture Min, Mean, Median (P50), P90, P95, P99, P99.9, and Max latency for every tested operation.
