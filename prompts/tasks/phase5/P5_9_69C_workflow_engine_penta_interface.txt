## 1. Core Workflow Schema & Presets (`paperpilot-core/src/workflow.rs`)
Define serializable structs matching the `SavedPipeline` schema from Spec 081:

```rust
use serde::{Deserialize, Serialize};
use std::collections::HashMap;

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct WorkflowStep {
    pub id: String,
    pub operation_id: String,
    #[serde(default)]
    pub label: Option<String>,
    #[serde(default)]
    pub icon: Option<String>,
    #[serde(default)]
    pub params: HashMap<String, serde_json::Value>,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct SavedWorkflow {
    pub id: String,
    pub name: String,
    #[serde(default)]
    pub description: Option<String>,
    pub steps: Vec<WorkflowStep>,
    pub updated_at: String,
    #[serde(default)]
    pub is_preset: bool,
    #[serde(default)]
    pub team_id: Option<String>,
}
```

Implement standard presets:
- `legal-discovery`: `pdf_bates` -> `pdf_watermark` -> `pdf_linearize`
- `clean-scan`: `pdf_remove_blank` -> `pdf_page_numbers` -> `pdf_compress`
- `redact-protect`: `pdf_redact` -> `pdf_flatten` -> `pdf_encrypt`

## 3. Native CLI Subcommand (`paperpilot-cli`)
Add `paperpilot workflow` subcommand to `cli.rs`:
```rust
Commands::Workflow {
    #[arg(long)]
    input: PathBuf,
    #[arg(long)]
    output: PathBuf,
    #[arg(long)]
    preset: Option<String>,
    #[arg(long)]
    recipe: Option<PathBuf>,
}
```
Support running both:
- `paperpilot workflow --input doc.pdf --output out.pdf --preset legal-discovery`
- `paperpilot workflow --input doc.pdf --output out.pdf --recipe ./custom_flow.json`

## 4. MCP Tool `document_workflow` (`paperpilot-mcp/src/server.rs`)
Register MCP tool `document_workflow`:
- Input arguments:
  - `input`: Path to input PDF file
  - `output`: Path to output PDF file
  - `preset`: Optional preset identifier (`legal-discovery`, `clean-scan`, `redact-protect`)
  - `recipe`: Optional raw JSON object with steps and parameters
- Executes compound workflows within a single agent tool invocation.
