### Step 2: Implementation Details (`paperpilot-pdf/src/operations/pdf_booklet.rs`)

```rust
use lopdf::{Document, Object, Dictionary, ObjectId};
use paperpilot_core::error::PdfError;
use paperpilot_core::traits::{PdfDocument, PdfOperation};
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PdfBookletOptions {
    /// If true (default), imposes pairs of pages onto 2-up landscape sheets.
    /// If false, reorders single pages into booklet sequence.
    #[serde(default = "default_true")]
    pub create_sheets: bool,

    /// Add a subtle fold line down the center of each sheet.
    #[serde(default)]
    pub center_fold_line: bool,

    /// Margin between side-by-side pages on a sheet in points (default: 0.0).
    #[serde(default)]
    pub gutter_pt: f32,
}

fn default_true() -> bool {
    true
}

impl Default for PdfBookletOptions {
    fn default() -> Self {
        Self {
            create_sheets: true,
            center_fold_line: false,
            gutter_pt: 0.0,
        }
    }
}
```

#### Saddle-Stitch Signature Mathematics
1. Load PDF bytes:
   ```rust
   let mut doc = Document::load_mem(input_bytes)
       .map_err(|e| PdfError::ParseError(e.to_string()))?;
   ```
2. Get existing pages:
   ```rust
   let pages = doc.get_pages(); // BTreeMap<u32, ObjectId>
   let page_count = pages.len();
   if page_count == 0 {
       return Err(PdfError::InvalidInput("Document contains no pages".into()));
   }
   ```
3. Calculate padding:
   - Booklets require a multiple of 4 pages ($N_{padded}$).
   - `let remainder = page_count % 4;`
   - `let pad_count = if remainder == 0 { 0 } else { 4 - remainder };`
   - `let total_pages = page_count + pad_count;`
   - `let sheets = total_pages / 4;`
4. Calculate sequence:
   Build an array of 1-based page indices (where indices $> page_count$ represent blank pages):
   ```rust
   let mut sequence = Vec::with_capacity(total_pages);
   for i in 0..sheets {
       // Sheet Front: [total_pages - 2*i, 2*i + 1]
       sequence.push(total_pages - 2 * i);
       sequence.push(2 * i + 1);
       // Sheet Back: [2*i + 2, total_pages - 2*i - 1]
       sequence.push(2 * i + 2);
       sequence.push(total_pages - 2 * i - 1);
   }
   ```
   Example for 4 pages: `[4, 1, 2, 3]`
   Example for 8 pages: `[8, 1, 2, 7, 6, 3, 4, 5]`
5. Rearrange pages or create blank page objects:
   - For blank pages ($idx > page_count$), create a minimal blank Page dictionary referencing the parent Pages object.
   - Assemble new page list matching `sequence`.
   - Update the `/Kids` and `/Count` of the document's Pages dictionary.
6. Serialize output:
   ```rust
   let mut out_bytes = Vec::new();
   doc.save_to(&mut out_bytes).map_err(|e| PdfError::Other(e.to_string()))?;
   Ok(out_bytes)
   ```
