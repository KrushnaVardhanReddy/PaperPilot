## Objective
Replace raw Rust/backend technical error messages in the Svelte 5 desktop app (`apps/desktop`) with clean, friendly user headlines and actionable resolution hints (e.g. replacing `lopdf: cross-reference table missing offset 0x4f2` with headline `Unable to Read PDF` and action hint `The document structure appears damaged. Power users must still be able to inspect and copy raw technical logs via an expandable "Details" toggle on toasts.

## Implementation Details

### 1. Centralized Formatter (`apps/desktop/src/lib/utils/errorFormatter.ts`)
Create a utility function:
```typescript
export interface FormattedError {
  headline: string;
  actionHint: string;
  technicalDetails?: string;
}

export function formatUserFriendlyError(rawError: unknown, operationTitle?: string): FormattedError;
```

Map error strings (case-insensitive) against taxonomy categories:
1. **Password / Encryption**: (`password`, `encrypted`, `decrypt`, `unauthorized`, `owner password`)
   - Headline: `Protected Document`
   - Action Hint: `Please provide the correct password to unlock and process this PDF.`
2. **Corrupted PDF**: (`xref`, `trailer`, `syntax`, `corrupt`, `damaged`, `invalid stream`, `unexpected token`)
   - Headline: `Unable to Read PDF`
   - Action Hint: `The document structure appears damaged. Try using the 'Repair' tool first.`
3. **Invalid Page Range**: (`out of bounds`, `page count`, `range`, `empty range`, `cannot produce 0-page`)
   - Headline: `Invalid Page Range`
   - Action Hint: `Please verify that the selected page numbers exist in this document.`
4. **Missing Input / Not Found**: (`missing`, `not found`, `no such file`, `enoent`)
   - Headline: `File Not Found`
   - Action Hint: `The specified file could not be found. Please re-select the document.`
5. **File In Use / Permissions**: (`permission denied`, `in use`, `busy`, `locked`, `access is denied`)
   - Headline: `File Is Busy or Inaccessible`
   - Action Hint: `Please close the document in other applications and try again.`
6. **Limit / Timeout**: (`too large`, `memory limit`, `timeout`, `size exceeded`)
   - Headline: `File Limit Reached`
   - Action Hint: `The document is too large or complex for this operation.`
7. **Empty Operation**: (`cannot merge 0 files`, `empty array`, `no inputs`, `need at least 2`)
   - Headline: `No Documents Selected`
   - Action Hint: `Please add at least one document to proceed.`
8. **Fallback**:
   - Headline: `${operationTitle || 'Operation'} could not be completed`
   - Action Hint: `An unexpected issue occurred. Please check the document and retry.`
   - `technicalDetails`: raw string representation of `rawError`.
