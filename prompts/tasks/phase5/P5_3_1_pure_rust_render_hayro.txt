# Base Branch: main
# Spec: docs/PURE_RUST_ARCHITECTURE_ROADMAP.md

## Objective
Migrate `pdf_render` and `pdf_to_images` in `paperpilot-pdf/src/operations/render.rs` to use **`hayro`** and **`tiny-skia`**.
This replaces Google PDFium (`libpdfium.so`, `pdfium-render`) with a pure-Rust vector-to-pixel rasterizer that compiles natively to WebAssembly and runs with zero OS dynamic library dependencies.

## 2. Implementation Details: `paperpilot-pdf/src/operations/render.rs`

### Rendering Architecture
1. Implement `RenderOperation` executing against `PdfDocument`:
   - Inspect page dictionary media box (`/MediaBox`).
   - Create a `tiny-skia::Pixmap` buffer with target scale/DPI (e.g. 150 DPI).
   - Interpret page content streams (paths, text glyph outlines, embedded images) and draw onto the `Pixmap`.
   - Encode the rasterized frame into a PNG buffer using `pixmap.encode_png()`.
   - Save rendered image to output path or return pixel buffer.
2. Parity Assertion:
   - Ensure rendered images produce valid PNG magic bytes (`0x89, 0x50, 0x4E, 0x47`).
