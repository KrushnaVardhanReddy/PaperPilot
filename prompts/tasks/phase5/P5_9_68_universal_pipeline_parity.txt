### Part 2: Desktop Intermediate Data Hand-off in `PipelineRunner.svelte`

In `apps/desktop/src/lib/components/pipeline/PipelineRunner.svelte`:
- When chaining steps where step `N` outputs multiple files (e.g., `pdf_split`), the tool creates an output directory containing `split_1.pdf`, `split_2.pdf`, etc.
- In `runPipeline()`:
  ```typescript
  let resolved = result.output_path ?? outputPath;
  if (step.operationId === 'pdf_split' || resolved.endsWith('_dir')) {
    // Pass the first generated part so downstream tools (OCR, Watermark, Encrypt) do not crash with directory error
    workingPath = `${resolved}/split_1.pdf`;
  } else {
    workingPath = resolved;
  }
  ```
- If a step fails, display the specific failed step name and the friendly error message in `toastState.error`.

### Part 3: Embed & Headless Pipeline Parity in `apps/embed/src/api.ts`

In `apps/embed/src/api.ts`, ensure `runPipeline` supports the full suite of client-side operations:
- **`rotate`**: handles `angle` or `degrees`, and `pages` ('all' or specific pages).
- **`watermark`**: handles `text`, `opacity`, `angle`, `color`.
- **`split` / `extract` / `extract_pages`**: extracts specified pages (`pages` or `split_at`).
- **`delete_pages` / `delete`**: removes specified page indices.
- **`reorder_pages` / `reorder`**: custom order array or 'reverse'.
- **`compress` / `optimize`**: stream compression.
- **`crop`**: margin or cropBox adjustment.
- **`flatten`**: form field and annotation flattening via `doc.getForm().flatten()`.
- **`metadata`**: updates document title, author, subject, keywords.
