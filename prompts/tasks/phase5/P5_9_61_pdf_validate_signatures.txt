### 2. Implementation Logic for `pdf_validate_signatures_bytes`

Implement `pdf_validate_signatures_bytes`:
```rust
pub fn pdf_validate_signatures_bytes(
    input_bytes: &[u8],
    options: &PdfValidateSignaturesOptions,
) -> Result<Vec<u8>, PdfError>
```

1. **Load Document**:
   ```rust
   let doc = Document::load_mem(input_bytes)
       .map_err(|e| PdfError::ParseError(e.to_string()))?;
   ```
2. **Scan for Signatures**:
   - Inspect `doc.trailer.get(b"Root")` -> Catalog `/AcroForm` -> `/Fields`.
   - Also scan `doc.objects` for dictionaries where `/Type == "Sig"` or `/FT == "Sig"`.
   - For each signature dictionary (or field pointing to a signature dictionary `/V`):
     - Extract field name (`/T` string or string name).
     - Extract `/Name` or `/M` (Date) from the dictionary.
     - Extract `/SubFilter` (Name object converted to String, e.g. `"adbe.pkcs7.detached"`).
     - Extract `/ByteRange` (Array of 4 integers: `[offset1, len1, offset2, len2]`).
3. **ByteRange Integrity & Tamper Check**:
   - A valid PDF ByteRange starts at 0: `offset1 == 0`.
   - `len1 < offset2`.
   - `end = offset2 + len2`.
   - If `end > input_bytes.len() as i64`: mark `is_valid = false, is_tampered = true, error_message = Some("ByteRange extends beyond file length")`.
   - If there are non-whitespace trailing bytes after `end` exceeding standard EOF markers: flag `is_tampered = true`.
   - If `/ByteRange` is valid and no tampering detected, set `is_valid = true, is_tampered = false`.
4. **Unsigned Documents**:
   - If no signatures exist in the PDF, return an empty report:
     `SignatureValidationReport { total_signatures: 0, valid_signatures: 0, all_valid: true, signatures: vec![] }`.
5. **Serialize to JSON Bytes**:
   - Return `serde_json::to_vec_pretty(&report).map_err(|e| PdfError::Other(e.to_string()))`.
6. **Implement `PdfValidateSignaturesOperation::execute`**:
   - In `execute(&self, document: &mut dyn PdfDocument) -> paperpilot_core::error::OperationResult<()>`:
     Allow executing against `LopdfDocument` or return `Ok(())` if in-memory document validation is performed.
