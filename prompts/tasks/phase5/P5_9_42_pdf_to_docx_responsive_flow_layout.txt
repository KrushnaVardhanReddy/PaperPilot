# Task P5_9_42: High-Fidelity Responsive Flow Layout & Inline Image Reconstruction for PDF-to-DOCX
# Associated Spec: specs/065-pdf-to-docx-flow-layout-images/spec.md
# Priority: High
# Target Branch: main

### Objective
Upgrade `paperpilot_pdf::operations::conversion::PdfToDocxOperation` in `paperpilot-pdf` to convert PDFs into responsive, clean Microsoft Word (.docx) documents. The engine must preserve 1-page document limits (no spillover into 2+ pages), sanitize font names to eliminate square tofu boxes (`□□□□`), embed extracted PNG images inline, and pair side-by-side elements into borderless 2-column tables.

### Detailed Scope & Context
Read `specs/065-pdf-to-docx-flow-layout-images/spec.md` for complete architectural details and code snippets.
Input validation fixture: `fixtures/Get_Started_With_Smallpdf.pdf`.

#### 1. Font Name Sanitization & Typography (`conversion.rs`)
- In `PdfToDocxOperation`, clean extracted font names before writing to `RunFonts`:
  - Strip 6-letter uppercase subset prefix followed by `+` (`^[A-Z]{6}\+`).
  - Strip `-Bold`, `-Regular`, `-Italic` suffixes to get the clean family name (e.g. `JFGNNE+SourceSansPro-Bold` -> `Source Sans Pro`).
  - Fallback to universal fonts (`Arial`, `Calibri`, `Times New Roman`) if font is missing or synthetic (`F1`, `G1`).
  - Apply `.bold()`, `.italic()`, `.size()`, and `.color()` based on extracted font attributes.

#### 2. Layout Analysis: Block Clustering & 2-Column Pairing
- Extract text spans and bounding boxes via `pdf_oxide` / `lopdf`.
- Extract page images via `doc.extract_images(page_idx)` and convert to PNG bytes via the `image` crate.
- Detect side-by-side layout (such as Smallpdf's 4 feature rows):
  - If an image bounding box horizontally precedes or follows a text block with vertical overlap, pair them into a 2-column borderless OpenXML table (`docx_rs::Table`).
  - Left column: Image (`docx_rs::Pic::new(&png_bytes)`).
  - Right column: Feature Title (bold) + Description paragraph.
  - Set table borders to none so it looks seamless in LibreOffice and Word.
- For full-width/centered blocks (like page headers/titles), render standard centered paragraphs (`AlignmentType::Center`).

#### 3. Single-Page Geometry & Overflow Prevention
- Set section margins to 720 dxa (0.5 in).
- Keep paragraph spacing compact (`before: 0, after: 60 dxa`) so content naturally fits within the exact page height without creating spurious extra pages.
