## 1. Requirements

### A. TypeScript / Node.js SDK (`packages/paperpilot-js/`)
- Pure TypeScript with generated `.d.ts` declarations.
- Dual execution mode:
  - Local mode: invokes local `paperpilot` CLI binary or WASM engine directly.
  - Remote mode: connects to PaperPilot Gateway HTTP REST API (`/api/v1/pdf/*`).
- Fluent strongly typed API:
  ```typescript
  import { PaperPilot } from "@paperpilot/sdk";
  const client = new PaperPilot(); // auto-discovers local binary or accepts { endpointUrl, apiKey }
  await client.merge(["doc1.pdf", "doc2.pdf"], { output: "merged.pdf" });
  await client.compress("huge.pdf", { quality: "medium", output: "compressed.pdf" });
  ```
- Comprehensive unit tests with Vitest asserting mock and live binary runs.

### B. Python SDK (`packages/paperpilot-py/`)
- Type-annotated (`py.typed`, Pydantic models for request/response payloads).
- Support both `async` and synchronous calls:
  ```python
  from paperpilot import PaperPilot
  client = PaperPilot() # auto-discovers local binary or gateway
  client.bates_stamp("input.pdf", prefix="DISCOVERY-", start=1, output="bates.pdf")
  ```
- Fast execution with zero heavy external C-dependencies.
- Unit tests with `pytest` asserting operation invocations.
