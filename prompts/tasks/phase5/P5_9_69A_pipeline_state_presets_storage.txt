## 1. Data Model & Interface Definitions (`pipeline.svelte.ts`)

Define and export the `SavedPipeline` interface:
```typescript
export interface SavedPipeline {
  id: string;               // e.g. "preset-legal-bates" or crypto.randomUUID()
  name: string;             // User-visible flow title
  description?: string;     // Purpose / notes
  steps: PipelineStep[];    // Array of configured steps with tool operationId & params
  updatedAt: string;        // ISO 8601 timestamp
  isPreset?: boolean;       // System default vs user-created
  teamId?: string;          // Optional workspace/team ID
}
```

## 3. `PipelineState` Enhancements

In `PipelineState` class in `apps/desktop/src/lib/state/pipeline.svelte.ts`:
1. **State Fields**:
   - `savedFlows = $state<SavedPipeline[]>([]);`
   - `activeFlowId = $state<string | null>(null);`
2. **Initialization (`initStorage()`)**:
   - Load `localStorage.getItem('paperpilot_saved_flows')`.
   - If empty, initialize `savedFlows` with `[...DEFAULT_PRESETS]`.
   - If present, parse JSON and merge user flows with `DEFAULT_PRESETS` (ensuring presets are always present).
   - Guard against SSR / non-browser environments (`typeof window !== 'undefined' && typeof localStorage !== 'undefined'`).
3. **Flow Management Methods**:
   - `loadFlow(flowId: string): boolean`: Finds flow by ID in `savedFlows`. If found, replaces `this.steps` with deep clone of `flow.steps`, sets `this.activeFlowId = flowId`, and clears `this.selectedStepId`.
   - `saveCurrentFlow(name: string, description?: string): SavedPipeline`:
     - Creates new `SavedPipeline` with `crypto.randomUUID()`, current `steps`, current ISO timestamp.
     - Prepends/appends to `this.savedFlows`.
     - Syncs to `localStorage.setItem('paperpilot_saved_flows', JSON.stringify(userFlows))`.
     - Sets `this.activeFlowId = newFlow.id`.
     - Returns the created flow.
   - `deleteFlow(flowId: string): boolean`:
     - Cannot delete presets (`isPreset: true`).
     - Removes from `this.savedFlows` and syncs to `localStorage`.
     - If `this.activeFlowId === flowId`, resets `activeFlowId = null`.
   - `exportFlowJson(flowId?: string): string`:
     - Serializes the active flow (or specified flow) to formatted JSON (`JSON.stringify(flow, null, 2)`).
   - `importFlowFromJson(jsonString: string): SavedPipeline`:
     - Validates JSON format and ensures required fields (`name`, `steps`).
     - Generates a new unique `id` (to avoid collision with existing flows), sets `updatedAt = new Date().toISOString()`, and sets `isPreset = false`.
     - Adds to `savedFlows`, saves to `localStorage`, and calls `loadFlow(newFlow.id)`.
     - Returns the imported flow.
