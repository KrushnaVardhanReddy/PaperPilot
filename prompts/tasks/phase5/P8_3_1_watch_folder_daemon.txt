## 1. Requirements & CLI Interface
1. **Command Syntax**:
   ```bash
   paperpilot watch ./incoming --recipe compress --output ./processed
   paperpilot watch ./scans --operation ocr --output ./searchable --webhook http://localhost:8080/hook
   ```
2. **Options**:
   - `<DIRECTORY>`: Directory path to monitor for incoming files.
   - `--output <DIR>`: Output directory for processed files.
   - `--operation <OP>`: Single operation to execute (e.g. `compress`, `ocr`, `bates`, `redact`).
   - `--recipe <FILE_OR_PRESET>`: Pipeline recipe to execute.
   - `--webhook <URL>`: Optional webhook to POST upon completion.
   - `--settle-delay-ms <MS>`: Delay (default 500ms) after file write event before processing to ensure file copy is complete.
   - `--move-original <DIR>`: Optional directory to archive original input files.
3. **Robustness & Concurrency**:
   - Pure-Rust `notify = "6.1"` filesystem event watcher.
   - Debouncing: Ignore partial / write-in-progress files using `--settle-delay-ms`.
   - Error tolerance: If a single file fails (e.g. corrupt PDF), log the error cleanly, do not crash the daemon, and continue watching.
   - Graceful shutdown: Cleanly handle `SIGINT` (Ctrl+C) and `SIGTERM`.
