## 1. Core Engine Implementation (`paperpilot-pdf/src/operations/compress.rs`)
1. Define `pub struct CompressOperation`:
   ```rust
   pub struct CompressOperation {
       pub quality: Option<String>,
   }
   ```
   Provide `CompressOperation::new(quality: Option<String>)`.
2. Parse `quality`:
   - `"low"` -> JPEG quality 45, max image dimension 1024px.
   - `"medium"` (default) -> JPEG quality 70, max image dimension 1600px.
   - `"high"` -> JPEG quality 85, max image dimension 2400px.
   - Integer `"50"` -> JPEG quality 50.
3. Traverse `doc.objects`:
   - Inspect streams where `/Type /XObject` and `/Subtype /Image` (or streams in `/XObject` dictionaries with `/Subtype /Image`).
   - Extract raw or decompressed image bytes via `stream.decompressed_content()`.
   - Read image dimensions (`/Width`, `/Height`), color space (`/DeviceRGB`, `/DeviceGray`, etc.).
   - Decode into an `image::DynamicImage` or `RgbImage`/`GrayImage`.
   - If image dimensions exceed `max_dimension`, downsample with `image::imageops::resize`.
   - Encode to JPEG using `JpegEncoder::new_with_quality(&mut jpeg_bytes, jpeg_quality)`.
   - Only replace stream contents if `jpeg_bytes.len() < original_bytes.len()`.
   - Update dictionary keys:
     - `/Filter` = `Object::Name(b"DCTDecode".to_vec())`
     - Remove `/DecodeParms`
     - Update `/Width`, `/Height`
     - Update `/Length` = `jpeg_bytes.len()`
4. Finalize with `doc.inner.compress()` to compress all non-image streams.

## 2. Multi-Interface Plumbing
1. **CLI (`paperpilot-cli/src/commands/group_b.rs`)**:
   - Forward `quality` into `CompressOperation::new(Some(quality.to_string()))`.
2. **MCP (`paperpilot-mcp/src/server.rs`)**:
   - Update `pdf_compress` schema to include optional `quality` property (string, default `"medium"`, enum: `["low", "medium", "high"]` or description).
   - In `pdf_compress` handler, read `let quality = get_optional_string("quality");` and pass to `CompressOperation::new(quality)`.
3. **Gateway (`paperpilot-gateway/src/handlers.rs`)**:
   - Ensure `CompressJsonRequest` / multipart extract `quality` and pass to `CompressOperation`.
4. **Desktop UI (`apps/desktop/src/lib/components/layout/OperationsPanel.svelte`)**:
   - In `case 'compress'`, include `quality: compressQuality.toString()` (e.g. `'80'` or preset `'medium'`) in `args = { input: docPath, quality: compressQuality.toString(), output: ... }` so the slider value is actually forwarded to `pdf_compress`.
5. **WASM (`paperpilot-wasm/src/operations.rs` & `paperpilot-wasm/src/lib.rs`)**:
   - Update `compress(input_bytes: &[u8], quality: Option<&str>)` (or expose `compress_with_quality`) so in-browser compression also supports quality control.
