Task: Pure-Rust Chromium-Free URL-to-PDF Archival Engine via browser_oxide [Spec 041]

Objective:
Integrate `browser_oxide` into PaperPilot (`paperpilot-pdf`) to deliver a 100% pure-Rust, zero-Chromium
web page archiving and dynamic HTML+JS-to-PDF conversion engine.

CRITICAL INSTRUCTIONS & BUG WORKAROUND (READ FIRST):
1. Upstream crate `browser_oxide = "0.1.3"` has a known refutable pattern bug with newer `fontdb`:
   `let fontdb::Source::Binary(data) = &face.source;` fails on recent fontdb updates.
2. TO RESOLVE COMPILATION:
   In the root `Cargo.toml`, add a `[patch.crates-io]` section or pin the dependency using:
   ```toml
   [patch.crates-io]
   # If fontdb can be pinned:
   fontdb = { version = "=0.21.0" }
   ```
   OR alternatively, patch `browser_oxide` via git in root `Cargo.toml`:
   ```toml
   [patch.crates-io]
   browser_oxide = { git = "https://github.com/yfedoseev/browser_oxide.git" }
   ```
   Do NOT ask clarifying questions or reset git. Apply this patch in root `Cargo.toml` and proceed autonomously.

Context & Requirements:
- Read `specs/041-pure-rust-url-to-pdf-browser-oxide/spec.md`.
- Concurrency limit: Maximum 6 cores (-j 6).
- Zero external browser binaries: Must NOT spawn `chrome`, `chromium`, or CDP. Must run 100% in pure Rust.
- Memory ceiling: <35MB RSS.

Implementation Steps:
1. In `paperpilot-pdf/Cargo.toml`:
   - Add `browser_oxide = "0.1.3"` and `tokio = { version = "1", features = ["rt", "macros", "time"] }`.
2. Core Operation (`paperpilot-pdf/src/operations/conversion.rs`):
   - Implement `UrlToPdfOperation`:
     ```rust
     pub struct UrlToPdfOptions {
         pub url: String,
         pub delay_ms: Option<u64>,
         pub page_size: Option<String>,
         pub print_background: bool,
     }
     pub struct UrlToPdfOperation {
         pub options: UrlToPdfOptions,
         pub output_path: PathBuf,
     }
     impl UrlToPdfOperation {
         pub async fn render(&self) -> OperationResult<()> { ... }
     }
     ```
   - Use `browser_oxide` to fetch the URL, wait for `delay_ms`, extract DOM HTML, and render to PDF using PaperPilot's native `HtmlToPdfOperation`.
3. Penta-Interface Exposure:
   - CLI (`paperpilot-cli`): `paperpilot convert-url --url <URL> --output <OUT>`
   - MCP Server (`paperpilot-mcp`): `pdf_convert_url` tool taking `{ "url": string, "output": string, "delay_ms"?: number }`
   - Gateway (`paperpilot-gateway`): `POST /api/v1/pdf/convert/url` Axum endpoint.
4. Unit Tests:
   - Add a unit test verifying that `UrlToPdfOperation` produces valid `%PDF-` bytes.
