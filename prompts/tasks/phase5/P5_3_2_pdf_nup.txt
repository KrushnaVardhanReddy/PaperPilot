### Step 2: Implementation Details (`paperpilot-pdf/src/operations/pdf_nup.rs`)

```rust
use lopdf::{Document, Object, Dictionary, Stream};
use paperpilot_core::error::PdfError;
use paperpilot_core::traits::{PdfDocument, PdfOperation};
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PdfNupOptions {
    #[serde(default = "default_nup")]
    pub nup: u32, // 2, 4, 9, or 16
    #[serde(default = "default_ordering")]
    pub ordering: String, // "horizontal" or "vertical"
    #[serde(default = "default_margin")]
    pub margin_pt: f32,
    #[serde(default = "default_spacing")]
    pub spacing_pt: f32,
    #[serde(default)]
    pub draw_borders: bool,
}

fn default_nup() -> u32 { 2 }
fn default_ordering() -> String { "horizontal".to_string() }
fn default_margin() -> f32 { 18.0 }
fn default_spacing() -> f32 { 10.0 }

impl Default for PdfNupOptions {
    fn default() -> Self {
        Self {
            nup: 2,
            ordering: default_ordering(),
            margin_pt: 18.0,
            spacing_pt: 10.0,
            draw_borders: false,
        }
    }
}
```

#### Imposition Algorithm
1. Parse document:
   ```rust
   let doc = Document::load_mem(input_bytes)
       .map_err(|e| PdfError::ParseError(e.to_string()))?;
   let page_ids = doc.get_pages();
   if page_ids.is_empty() {
       return Err(PdfError::InvalidInput("No pages in document".into()));
   }
   ```
2. Determine rows and cols:
   - `nup == 2` $\rightarrow$ rows = 1, cols = 2 (landscape sheet) or rows = 2, cols = 1.
   - `nup == 4` $\rightarrow$ rows = 2, cols = 2.
   - `nup == 9` $\rightarrow$ rows = 3, cols = 3.
   - `nup == 16` $\rightarrow$ rows = 4, cols = 4.
3. Group input pages into chunks of size `nup`.
4. For each chunk of pages:
   - Create a new composite sheet page.
   - Compute cell box `(cell_w, cell_h)` based on sheet width/height minus margins and inter-cell spacing.
   - Calculate scale factor $s$ and translation $(tx, ty)$ for each page in its cell.
   - Embed original page content as Form XObjects or combine streams wrapped with transformation matrix `cm`.
5. Return output PDF bytes via `doc.save_to(&mut buf)`.
