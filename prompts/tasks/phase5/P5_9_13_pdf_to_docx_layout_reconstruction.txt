Task: High-Fidelity Pure-Rust PDF-to-Word (DOCX) Layout & Style Reconstruction [Spec 038]

Objective:
Upgrade `paperpilot_pdf::operations::conversion::PdfToDocxOperation` in `paperpilot-pdf` to perform layout reconstruction, preserving font sizes, hierarchy (headings), weights (bold/italic), colors, alignment (center/left/right), true page breaks, and embedded images when exporting PDFs to Word (.docx) files using `docx-rs`.

Context & References:
- Read `specs/038-pdf-to-docx-layout-reconstruction/spec.md` for full technical details.
- Read `wiki/25-Penta-Interface-Mandate-And-E2E-Protocol.md` for test requirements.
- Current implementation to upgrade: `paperpilot-pdf/src/operations/conversion.rs` (`PdfToDocxOperation`).
- `docx-rs` is already a dependency in `paperpilot-pdf/Cargo.toml`.

Implementation Steps:
1. `paperpilot-pdf/src/operations/conversion.rs`:
   - Upgrade `PdfToDocxOperation::execute`:
     - Eliminate the literal string `"--- PAGE BREAK ---"` and replace with true OpenXML page breaks (`page_break_before` or `add_page_break`).
     - Detect line font sizes and map large text (>= 18pt) to Heading 1 (`docx-rs::Paragraph::new().style("Heading1")`) or bold runs with larger sizes (`size(36)`).
     - Detect bold/italic font descriptors or names (`/Bold`, `/Italic`) and set `.bold()`, `.italic()`.
     - Detect RGB text color operators (`rg`, `g`) in the PDF stream and convert to hex color (`.color("RRGGBB")`).
     - Calculate horizontal alignment: if line center is near page width center (MediaBox width / 2), set `.align(AlignmentType::Center)`.
     - Extract embedded `/XObject` `/Image` payloads and add images into the docx via `docx-rs::Pic::new`.
