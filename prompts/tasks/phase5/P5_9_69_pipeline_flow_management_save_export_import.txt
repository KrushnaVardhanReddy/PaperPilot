# Task 5.9.69: Pipeline Flow Management (Save, Multi-Flow Switcher, Export & Import)

Reference Spec: `specs/081-pipeline-flow-management-save-export-import/spec.md`
Checklist: `specs/081-pipeline-flow-management-save-export-import/task.md`

You are implementing multi-pipeline flow management, flow presets, and JSON export/import for PaperPilot's visual pipeline builder.

### Requirements:
1. **State & Persistence (`apps/desktop/src/lib/state/pipeline.svelte.ts`)**:
   - Define `SavedPipeline` interface (`id`, `name`, `description`, `steps`, `updatedAt`, `isPreset`).
   - Maintain `savedFlows` in `PipelineState`, initialized with out-of-the-box presets (Legal Discovery, Redact & Protect, Split & Watermark) and synced to `localStorage`.
   - Implement `loadFlow(flowId)`, `saveCurrentFlow(name, description)`, `deleteFlow(flowId)`.
   - Implement `exportFlowJson(flowId?)` and `importFlowFromJson(jsonString)`.

2. **UI Implementation (`apps/desktop/src/lib/components/pipeline/FlowSelector.svelte`)**:
   - Create a clean toolbar above the canvas featuring:
     - Flow dropdown selector.
     - "Save Flow" button with dialog for name/description.
     - "Export" button triggering `<flow-name>.json` download.
     - "Import" button with file picker reading and activating JSON flow.
     - "Delete" button for custom flows.

3. **Mounting**:
   - Integrate `FlowSelector` into `apps/desktop/src/lib/components/pipeline/PipelineView.svelte`.

4. **Testing**:
   - Verify with `pnpm check` and add automated Playwright e2e test verifying flow switching, export, and import.
