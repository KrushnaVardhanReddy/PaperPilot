### Step 2: Implementation Details (`paperpilot-pdf/src/operations/pdf_remove_signatures.rs`)

```rust
use lopdf::{Document, Object, Dictionary, ObjectId};
use paperpilot_core::error::PdfError;
use paperpilot_core::traits::{PdfDocument, PdfOperation};
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize, Default)]
pub struct PdfRemoveSignaturesOptions {
    #[serde(default = "default_true")]
    pub remove_empty_signature_fields: bool,
}

fn default_true() -> bool { true }
```

#### Removal Logic
1. Load PDF bytes with `Document::load_mem(input_bytes)`.
2. Inspect Catalog `/Root` $\rightarrow$ `/AcroForm`:
   - If `/AcroForm` exists (as direct dict or reference), inspect `/Fields` array.
   - Collect IDs of fields where:
     - The field dictionary has `/FT == /Sig` (Name object `b"Sig"`).
     - Or the field value `/V` references a dictionary with `/Type == /Sig`.
   - Remove these field references from the `/Fields` array.
   - If `/Fields` is now empty, remove `/AcroForm` from the catalog or clear `/SigFlags`.
   - Delete the identified signature objects from `doc.objects`.
3. Inspect all pages in `doc.get_pages()`:
   - For each page, inspect `/Annots` array if present.
   - Filter out any annotation references pointing to the deleted signature widgets or where `/Subtype == /Widget` and `/FT == /Sig`.
   - If `/Annots` is now empty, optionally remove the `/Annots` key.
4. Save cleaned document: `doc.save_to(&mut buf)`.
