# Task 5.9.72: Embed Pipeline Parity — Browse Button & Interactive Step Selection
# Base Branch: main
# Related Spec: specs/083-embed-pipeline-parity-and-step-customization/spec.md
# Priority: MEDIUM (Embed UX & Feature Parity with Desktop Pipeline)

## Objective
Bring the Web Embed Pipeline (`apps/embed`) to functional and UX parity with the Desktop visual pipeline builder:
1. **Explicit File Browsing**: Add a prominent, clickable `"Browse Files"` button and selected file preview chip into the embed pipeline dropzone.
2. **Interactive Tool & Step Selection**: When `data-allow-customization="true"` (or `allowCustomization: true`), allow users to dynamically add new steps (`+ Add Step`), choose from available tools, remove existing steps (`×`), and execute the pipeline via an explicit `"⚡ Run Pipeline"` button.

## 2. Interactive Step Selection & Customization (`apps/embed/src/Widget.svelte` & `apps/embed/src/api.ts`)
- Add props:
  - `allowCustomization: boolean = false`
  - `autoExecute: boolean = true`
- Read dataset attributes on mount:
  - `data-allow-customization="true"`
  - `data-auto-execute="false"`
- When `allowCustomization` is `true`:
  - Initialize mutable `$state` `pipelineSteps`:
    ```ts
    let customSteps = $state<PipelineStep[]>([]);
    $effect(() => {
      if (parsedPipeline && customSteps.length === 0) {
        customSteps = [...parsedPipeline];
      }
    });
    ```
  - For each step in the stepper, show a remove button (`✕`) when hovering or active, allowing users to remove a step from `customSteps`.
  - At the end of the stepper, add an `+ Add Step` button.
  - Clicking `+ Add Step` opens a lightweight inline tool selector dropdown/grid containing in-browser operations:
    - Rotate (`rotate`)
    - Watermark (`watermark`)
    - Compress (`compress`)
    - Extract (`extract_pages`)
    - Split (`split`)
  - Selecting a tool appends it with default parameters to `customSteps`.
- When `autoExecute` is `false` (or customization is active):
  - Instead of immediately auto-running on file drop, display a prominent button:
    ```svelte
    <button 
      class="pp-btn pp-btn-primary pp-btn-run" 
      disabled={droppedFiles.length === 0 || customSteps.length === 0 || pipelineStatus === 'running'}
      onclick={runVisualPipeline}
    >
      {pipelineStatus === 'running' ? 'Running...' : '⚡ Run Pipeline'}
    </button>
    ```
