## 2. `FlowSelector.svelte` Implementation
Create `apps/desktop/src/lib/components/pipeline/FlowSelector.svelte` positioned directly below the header in `PipelineView.svelte`:

1. **Toolbar Layout**:
   - Clean, glassmorphic top bar: `background: rgba(15, 23, 42, 0.6); border: 1px solid rgba(255, 255, 255, 0.08); border-radius: 8px; padding: 8px 16px; display: flex; align-items: center; justify-content: space-between; gap: 12px;`

2. **Flow Dropdown Selector**:
   - `<select class="input-field flow-select">` with grouped options:
     ```svelte
     <optgroup label="Standard Presets">
       {#each pipelineState.savedFlows.filter(f => f.isPreset) as flow}
         <option value={flow.id}>{flow.name} ({flow.steps.length} steps)</option>
       {/each}
     </optgroup>
     <optgroup label="My Saved Flows">
       {#each pipelineState.savedFlows.filter(f => !f.isPreset) as flow}
         <option value={flow.id}>{flow.name} ({flow.steps.length} steps)</option>
       {/each}
     </optgroup>
     ```
   - Changing selection calls `pipelineState.loadFlow(selectedId)`.
   - If user adds/edits steps, display `"— Custom / Unsaved Pipeline —"`.

3. **Action Toolbar Buttons**:
   - **`💾 Save Flow`**:
     - Disabled if `pipelineState.steps.length === 0`.
     - Opens `SaveFlowModal.svelte`.
   - **`⬇️ Export JSON`**:
     - Disabled if `pipelineState.steps.length === 0`.
     - Uses `pipelineState.exportFlowJson()`, creates a `Blob([json], { type: 'application/json' })`, and triggers browser download of `<flow-name>.json`.
   - **`⬆️ Import JSON`**:
     - Hidden `<input type="file" accept=".json" bind:this={fileInput} onchange={handleFileImport} style="display: none;" />`.
     - Reads the file text with `FileReader`, calls `pipelineState.importFlowFromJson(text)`, and triggers a toast notification.
   - **`🗑️ Delete Flow`** (visible only when an active custom flow is selected, hidden for presets):
     - Calls `pipelineState.deleteFlow(flowId)`.
   - **`✨ New`**:
     - Clears the canvas (`pipelineState.clearPipeline()`).
