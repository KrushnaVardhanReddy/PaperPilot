Create `paperpilot-mcp/tests/wave7_conversions_mcp_tests.rs`:
- Use in-memory `PaperPilotMcpServer::new(None).execute_call_tool(params)` to invoke tools with real fixtures and sandboxed output paths using `tempfile::tempdir()`.
- Test the following Conversion & Document Packaging tools:
  1. `pdf_to_html`: Convert PDF to standalone HTML. Assert output exists and contains `<html>` or `<!DOCTYPE`.
  2. `pdf_to_markdown`: Convert PDF to Markdown. Assert output exists and has text/headings.
  3. `pdf_to_json`: Extract document model to structured JSON. Assert output is valid JSON.
  4. `json_to_pdf`: Synthesize PDF from JSON layout model (`json_doc.json`). Assert output starts with `%PDF-`.
  5. `pdf_to_epub`: Convert PDF into EPUB container. Assert output exists.
  6. `pdf_to_pdf_a`: Convert PDF to archival PDF/A standard. Assert output exists.
  7. `pdf_comic_archive`: Convert PDF to CBZ comic book archive or vice versa. Assert output exists.
  8. `excel_to_json`: Parse `test.xlsx` into JSON records. Assert valid JSON.
  9. `excel_to_csv`: Convert `test.xlsx` into RFC 4180 CSV. Assert valid CSV.
  10. `pdf_dedup_streams`: Deduplicate identical XObject and font streams. Assert output exists.
  11. `pdf_invert_colors`: Invert document colors (dark mode/high contrast). Assert output exists.
  12. `pdf_linearize`: Linearize PDF for fast web view. Assert output exists.
  13. `pdf_repair`: Repair corrupted PDF syntax. Assert output exists and is valid.

- For each tool:
  - Print execution progress, latency (ms), and output size (e.g. `✓ pdf_to_html: 15420 bytes in 25ms`).
  - If any tool fails, log `✗ <tool_name>: <error message>` without halting the rest of the audit.
