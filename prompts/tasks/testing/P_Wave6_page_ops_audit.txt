- Test the following Page Operation & Imposition tools:
  1. `pdf_merge`: Merge `merge_a.pdf` and `merge_b.pdf`. Assert valid output PDF exists and size > 0.
  2. `pdf_merge_alternate`: Alternating merge of pages from two input PDFs. Assert output exists.
  3. `pdf_split`: Split `multi_page.pdf` by ranges (e.g. `"1-2"`). Assert output exists.
  4. `pdf_split_by_outline`: Split PDF based on document bookmarks/outline. Assert output exists.
  5. `pdf_split_scanned_book`: Split dual-page book scans down center spine. Assert output exists.
  6. `pdf_rotate`: Rotate pages by 90 degrees. Assert output exists and is valid PDF.
  7. `pdf_auto_rotate`: Automatically detect and correct orientation. Assert output exists.
  8. `pdf_crop`: Crop margins with bounding box coordinates. Assert output exists.
  9. `pdf_scale_pages`: Scale page dimensions (e.g. to A4 or custom factor). Assert output exists.
  10. `pdf_delete_pages`: Delete specific pages (e.g. page 2). Assert output exists.
  11. `pdf_reorder_pages`: Permute page order (e.g. `[2, 1]`). Assert output exists.
  12. `pdf_extract_pages`: Extract designated page subsets. Assert output exists.
  13. `pdf_nup`: N-Up layout imposition (e.g. 2 or 4 pages per sheet). Assert output exists.
  14. `pdf_booklet`: Booklet duplex imposition with automatic 4-page padding. Assert output exists.
  15. `pdf_posterize`: Posterize large page across multiple sheets. Assert output exists.
  16. `pdf_stitch_canvas`: Stitch multi-page PDF into single continuous vertical canvas. Assert output exists.

- For each tool:
  - Print execution progress, latency (ms), and output size (e.g. `✓ pdf_merge: 84200 bytes in 18ms`).
  - If any tool fails, log `✗ <tool_name>: <error message>` without halting the rest of the audit.
