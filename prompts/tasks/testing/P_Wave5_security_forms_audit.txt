Create `paperpilot-mcp/tests/wave5_security_forms_mcp_tests.rs`:
- Use in-memory `PaperPilotMcpServer::new(None).execute_call_tool(params)` to invoke tools with real fixtures and sandboxed output paths using `tempfile::tempdir()`.
- Test the following Security, Signature & Form tools:
  1. `pdf_watermark`: Watermark `fixtures/Get_Started_With_Smallpdf.pdf` with text `"CONFIDENTIAL"`. Check file creation and `%PDF-` header.
  2. `pdf_encrypt`: Encrypt `fixtures/Get_Started_With_Smallpdf.pdf` with user password. Check encrypted output exists.
  3. `pdf_decrypt`: Decrypt the newly encrypted PDF with the password. Check output exists and is readable.
  4. `pdf_sanitize`: Sanitize `fixtures/Get_Started_With_Smallpdf.pdf`. Check output exists.
  5. `pdf_redact`: Redact word `"Smallpdf"` from `fixtures/Get_Started_With_Smallpdf.pdf`. Check output exists.
  6. `pdf_read_form`: Read form field schema from `tests/e2e_fixtures/real/form.pdf`. Check success.
  7. `pdf_fill_form`: Fill form fields on `tests/e2e_fixtures/real/form.pdf`. Check output exists.
  8. `pdf_flatten`: Flatten annotations/form fields on `tests/e2e_fixtures/real/form.pdf`. Check output exists.
  9. `pdf_stamp`: Apply `tests/e2e_fixtures/real/img1.png` stamp onto `fixtures/Get_Started_With_Smallpdf.pdf`. Check output exists.
  10. `pdf_validate_signatures`: Validate signature structure on `fixtures/Get_Started_With_Smallpdf.pdf`. Check success.
  11. `pdf_remove_signatures`: Strip certificate signatures from `fixtures/Get_Started_With_Smallpdf.pdf`. Check output exists.
  12. `pdf_change_permissions`: Update owner/user permissions flags. Check output exists.
  13. `pdf_create_form_field`: Add a form field to `tests/e2e_fixtures/real/single_page.pdf`. Check output exists.
  14. `pdf_timestamp`: Add cryptographic timestamp token. Check execution result.

- For each tool:
  - Print execution progress, latency (ms), and output size (e.g. `✓ pdf_watermark: 73000 bytes in 12ms`).
  - If any tool fails, log `✗ <tool_name>: <error message>` without halting the rest of the audit.
