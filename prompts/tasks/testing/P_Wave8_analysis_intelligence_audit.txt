  6. `pdf_bates`: Apply legal Bates numbering to pages. Assert output exists.
  7. `pdf_header_footer`: Add dynamic header and footer running heads. Assert output exists.
  8. `pdf_classify_type`: Classify document type (e.g. invoice, contract, form). Assert classification result.
  9. `pdf_compare`: Compare two PDF documents for visual / content diff. Assert diff generated.
  10. `pdf_hash`: Compute cryptographic checksums (SHA-256) of document objects. Assert hash returned.
  11. `pdf_validate`: Validate PDF conformance against ISO standards. Assert validation report.
  12. `pdf_render`: Render PDF page to PNG image buffer. Assert PNG output exists and starts with PNG magic bytes `\x89PNG`.
  13. `pdf_rag_chunks`: Chunk document with layout boundaries for AI embeddings. Assert chunk array returned.
  14. `workspace_search`: Search indexed workspace files for keywords. Assert search results returned.
  15. `semantic_search`: Perform vector semantic query against indexed documents. Assert semantic hits returned.
