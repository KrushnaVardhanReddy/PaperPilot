# Task 115A: Implement UseCasesShowcase Component

## Objective
Create `UseCasesShowcase.svelte` in `apps/web/src/components/` and mount it inside `apps/web/src/App.svelte`.

## Requirements
1. Responsive grid/flex card layout showcasing the 6 curated use cases.
2. Glassmorphism dark cards with glowing hover highlights, persona badges, problem descriptions, and action CTA buttons.
3. Smooth action handler for each CTA (e.g. scroll to `#playground`, `#api-explorer`, `#embed-generator`, etc. or dispatch events).
4. Svelte 5 runes (`$state`, `$derived`, etc.), zero new NPM dependencies.
5. Strict TypeScript and CSS scoped styling matching existing PaperPilot design tokens.
