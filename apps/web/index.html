PaperPilot — 100% Private Client-Side PDF Tools in Pure Rust

Zero file uploads. Zero telemetry. 100% on-device WebAssembly execution.

The Modern Pure-Rust Alternative to Stirling PDF & iLovePDF

Unlike server-heavy Java alternatives (like Stirling PDF) that require 1–2 GB Docker containers, or closed cloud converters (like iLovePDF and Smallpdf) that upload your sensitive documents to remote servers, PaperPilot runs 100% on-device inside your browser using compiled WebAssembly. Your files never touch a remote server.

Core PDF & Document Operations

  • PDF Organization: Merge PDF, Split by Range, Burst Single Pages, Reorder Pages, Rotate, Crop, and Delete Pages.
  • Optimization & Repair: Pure-Rust Flate Stream Compression, Deduplicate Font Streams, Fast Web View (Linearize), Rebuild Damaged XREF Tables.
  • Document Conversions: PDF to Word (.docx), PDF to Excel (.xlsx), PDF to PowerPoint (.pptx), PDF to Markdown, PDF to HTML5.
  • Security & Privacy: Vector Redaction, Deep Sanitization, Password Encryption (AES-256), Digital Signatures (PKCS#7), PII Scanner.
  • AI & Layout Intelligence: Neural OCR Text Recognition, Multimodal JSON Layout Extraction, Table Matrix Extractor, Vector Semantic Search.
