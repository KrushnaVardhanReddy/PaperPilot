# Embed.js Quickstart

Integrate the full power of PaperPilot directly into your website with a simple 2-line HTML snippet.

## The Snippet

Add the following code to your HTML file where you want the PaperPilot widget to appear:

```html
<script src="https://cdn.usepaperpilot.com/embed.js"></script>
<div id="paperpilot-portal"></div>
```

That's it! The widget will initialize automatically and attach to the `#paperpilot-portal` element.
