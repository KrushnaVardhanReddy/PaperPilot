# CMS Integration

Integrating the PaperPilot widget into your Content Management System is easy.

## WordPress (Gutenberg)

1. Add a **Custom HTML** block to your page or post.
2. Paste the snippet:
   ```html
   <script src="https://cdn.usepaperpilot.com/embed.js"></script>
   <div id="paperpilot-portal"></div>
   ```

## Webflow

1. Add an **Embed** element from the Add panel.
2. Paste the snippet into the Custom Code editor.

## Shopify

1. In your Theme editor, add a **Custom Liquid** section.
2. Paste the snippet.

## Squarespace

1. Add a **Code** block to your page.
2. Ensure the format is set to HTML.
3. Paste the snippet and disable "Display Source".
