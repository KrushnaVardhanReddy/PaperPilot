# Desktop Installation

PaperPilot provides native installers for all major desktop operating systems.

## Windows

Download the `.msi` installer and double-click to install.

## macOS

Download the `.dmg` image, open it, and drag PaperPilot to your Applications folder.

## Linux

We offer both `.deb` and `.AppImage` packages.

*   **Debian/Ubuntu:** `sudo dpkg -i paperpilot_*.deb`
*   **AppImage:** Make it executable (`chmod +x paperpilot-*.AppImage`) and run it.
