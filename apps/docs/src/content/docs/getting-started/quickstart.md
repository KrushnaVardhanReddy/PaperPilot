# Quickstart

Welcome to PaperPilot! Get up and running in minutes with our versatile toolkit, available across three primary interfaces: Desktop, CLI, and In-Browser WASM.

## Desktop App

The Desktop application is powered by Tauri 2 and Svelte 5, providing a robust native experience without the bloat of Electron.

1.  Download the latest release for your OS.
2.  Install and launch.
3.  Drag and drop your PDFs to begin editing!

## Command Line Interface (CLI)

The headless CLI is perfect for scripting and automation, featuring stdin/stdout piping.

```bash
paperpilot-cli merge --input file1.pdf file2.pdf --output merged.pdf
```

## In-Browser WASM

For zero-installation and absolute privacy, use our in-browser WASM client.

1.  Visit our web app.
2.  All processing happens locally in your browser – your files never leave your device with ~50–100ms WASM Execution speeds.
